## Connectors & Integrations (`/connectors`) — 24 tools

Connect bank, accounting, payment, and operational systems so Headroom can auto-sync transactions, settlements, and business data. Stakeholders: ops, owner. Backend: `/api/connectors` only mints a connector ID on add (best-effort POST, falls back to `generateId()`); everything else is local. NOTE: be honest — every connector here is simulated/preview, not a live integration. No real bank, gateway, AA, GSTN, ERP, POS, payroll, CRM, or courier API is ever called. The top-level connectors store persists via `AppContext` (localStorage + debounced backend save); all the `#166+` depth tools use `useFeatureState` (local `featureData` namespace only).

Page-level (top section, `PROVIDERS` catalogue + active list):

- **Provider Catalogue & Connect/Setup** — pick a provider (AA Network, Finbox, Tally ERP, Zoho Books, QuickBooks, Razorpay, Stripe, PhonePe Business); `handleConnect` → either adds a Tally `pending` connector directly (webhookNote path) or opens a setup modal collecting per-provider fields (account name, mobile, webhook secret) → `handleSave` calls `persistConnector` (POST `/api/connectors`, returns id) then `addConnector` with status `pending`. → A connector row appears in Active Connections. _Persist: backend ID + live store._ _Class: Backend (ID mint only; consent/data flow Simulated)._
- **Active Connections list (sync / disconnect)** — lists connectors from store; per-row `handleSync` (1.4s fake delay → sets `lastSync`=now, status `connected`, toast "Sync triggered") and `handleDisconnect` (confirm → `deleteConnector`) → updated/removed row. _Persist: live store._ _Class: Simulated (sync is a timeout, no data pulled)._
- **Connected summary cards** — counts of Connected / Pending / Total over the store connectors → 3 stat tiles. _Persist: derived from live store._ _Class: KV (derived)._
- **AA Network explainer** — static informational panel (consent-based / RBI-regulated / real-time) describing India's Account Aggregator framework → read-only marketing copy. _Persist: none._ _Class: Indicative._

Depth tools (jump-nav `#166`–`#188` sections, each ends with an honest demo disclaimer):

- **Bank / UPI Feed Connector** (`#bank-upi-feed`) — inputs: Bank/FIP name (req), UPI handle → `startConsent` raises a `pending` AA consent; `approveConsent` flips to `active`; `syncNow` (1.2s delay) adds a random 8–47 simulated txns to a counter; `revoke`/`remove`. → feed list + Active/Total/Txns-pulled stats. _Persist: `connector-bank-upi-feeds`._ _Class: Simulated._
- **Payment-Gateway Reconciliation** (`#gateway-recon`) — inputs: pasted orders + gateway settlements (`reference, amount` per line) + ₹ amount tolerance → matches by reference (case-insensitive), classifies into matched / amount-mismatch / missing-settlement / orphan-payout, computes order vs settled totals and gap. → 4 stat tiles + mismatch table. _Persist: none (in-component `useState`, recompute via `useMemo`)._ _Class: Simulated (client-side math; no gateway call)._
- **E-commerce (Amazon / Flipkart) Sync** (`#ecom-sync`) — inputs: marketplace toggle (Amazon/Flipkart/Meesho) + pasted settlement CSV (`order_id, sku, qty, gross, fees`) → `parseEcomCsv` (optional header skip) computes net = gross − fees per row; `importBatch` saves a durable batch; remove batch. → gross/fees/net totals + batch list. _Persist: `connector-ecom-batches`._ _Class: Simulated (CSV import; no SP-API/Flipkart)._
- **Connector Health & Sync Monitor** (`#sync-monitor`) — operates over the live connectors store: derives health (healthy / stale >24h since sync / failing / pending); `simulateFailure` injects a random incident + sets status `error`; `retry` (1.1s) clears incident, sets `connected`+now. → 4 health-count tiles + per-connector rows. _Persist: `connector-sync-incidents` (incidents) + live store (status)._ _Class: Simulated._
- **Connector Catalog** (`#conn-catalog`) — browse static `CATALOG` (Shopify, WooCommerce, Cashfree, PayU, ICICI/HDFC Corporate API, Xero, SAP B1, Shiprocket, Google Sheets) with category filter; `connect` (0.9s) stores a connected-at flag; `disconnect` removes it. → catalogue grid with Connected badges. _Persist: `conn-catalog-connected`._ _Class: Simulated (flag only, no OAuth)._
- **Sync Schedule** (`#conn-schedule`) — per live connector: Auto-sync toggle + frequency (manual/hourly/daily/weekly) + hour-of-day; `nextRun` computes next fire time in-browser. → schedule rows with computed next-run. _Persist: `conn-schedules`._ _Class: Simulated (no background job runs)._
- **Field Mapping Studio** (`#conn-mapping`) — inputs: connector name + source field + target (one of 6 canonical Headroom fields: date/amount/description/counterparty/category/reference) → `addMapping`/`removeMapping`; flags unmapped canonical fields. → per-connector mapping list. _Persist: `conn-field-maps`._ _Class: Simulated (saved for reference; not applied to any import pipeline)._
- **Credential Vault** (`#conn-vault`) — inputs: connector + key name + secret → `add` stores masked credential; reveal/hide toggle, copy to clipboard, remove. → masked credential list. _Persist: `conn-credentials`._ _Class: Simulated (in-browser local state only; NOT encrypted/production-safe — explicit "never paste real live keys" warning)._
- **Webhook Registry** (`#conn-webhooks`) — inputs: label + URL (http(s) validated) + comma-separated events → `add` registers endpoint; `testPing` (1s) returns simulated 200 / 500 / timeout(0) at ~75% success; remove. → endpoint list with last status. _Persist: `conn-webhooks`._ _Class: Simulated (no real HTTP request)._
- **Sync History** (`#conn-history`) — input: connector select (live labels + Razorpay/Stripe/AA/Tally) → `record` appends a simulated run (success/partial/failed at ~60/20/20%, random record count), capped at 50; clear all. → timeline of runs + run/record totals. _Persist: `conn-sync-history`._ _Class: Simulated._
- **Tally / Busy ERP Agent** (`#conn-erp-agent`) — inputs: software (Tally Prime/ERP 9/Busy/Marg) + company + local port → `create` generates a `hr_agent_*` pairing token (copyable); `pair`/`heartbeat` (delay) set `paired`+lastBeat; push-vouchers / push-masters toggles; remove. → agent profile cards. _Persist: `conn-erp-agents`._ _Class: Simulated (token/heartbeat generated locally; no agent connects)._

- **Integration Cost Estimator** (`#conn-cost`) — inputs: per-source enable toggles + monthly txn volumes over 5 illustrative sources (AA fetch, gateway sync, marketplace import, GSTN pull, Tally agent) → computes monthly = platform fee + (volume × per-txn) and annualised. → per-source cost rows + monthly/annual tiles. _Persist: `conn-cost-enabled`, `conn-cost-volumes`._ _Class: Indicative (placeholder pricing, not commercial rates)._

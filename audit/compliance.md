# Compliance & Secretarial (`/compliance`) — 30 tools

One-stop statutory cockpit that derives every Indian SMB filing date, license, register and penalty from the firm profile + transactions, with per-record trackers persisted to the synced store. Stakeholders: CA, owner, ops. Backend: KV-synced via `useFeatureState` (writes to `store.featureData[key]` → localStorage + debounced backend push + cross-device live-sync; read-only roles gated).

Tabs are an array of 26 IDs (`overview` … `gst-turnover-recon`); the `overview` tab additionally renders 5 inline tools (Contract Expiry, MSME Checker, Labour-Law Checklist, ROC Filing Calendar, Insurance Calendar) → **30 distinct tools** below.

## Overview tab — derived calendar + 5 inline tools

- **Compliance Calendar (Next 6 Months + KPI strip)** — firm profile (`gstRegistered`, payroll-tagged txns), `computeFinancialSnapshot`, `store.obligations` → rolls 6 months of monthly statutory dates (TDS deposit 7th, GSTR-1 11th, GSTR-3B+payment 20th with net payable, PF/ESI 15th if payroll, advance-tax instalments 15th of Mar/Jun/Sep/Dec) + fixed annual ROC dates (MGT-7/7A 60d-of-AGM, AOC-4/AOC-4-XBRL 30d-of-AGM, LLP Form-11 30-Jun, LLP Form-8 30-Oct, DIR-3 KYC 31-Mar, MSME Form-1 30-Nov) + user obligations → sorted event list with day-countdown/overdue chips, cash-due-30d KPI, GST-payable KPI, est. annual tax KPI, and warnings (not-GST-registered banner, overdue-obligations banner). _Persist: none (computed; reads `store.obligations`)._ _Class: Backend (reads synced store)._
- **Cost of Filing Late (GST penalty slider)** — `lateDays` slider 1–90 × `snap.gstThisMonth.netPayable` → `gstLatePenalty` returns late fee ₹50/day + interest @18% p.a. + total. _Persist: none (transient slider)._ _Class: Indicative._
- **Advance Tax (FY) panel** — `snap.advanceTax` instalments → label, cumulative %, instalment amount, paid-window styling; note: 25% corporate rate on est. profit, §234C 1%/month. _Persist: none (computed)._ _Class: Backend (derived)._
- **Contract Expiry Tracker** — add Contract {name, counterparty, kind (Vendor/Customer/Employment/Lease/Service/NDA/Loan/Insurance/Other), expiry date, value, notes} → `differenceInDays(expiry)` buckets expired/urgent ≤30d/warning ≤90d, "expiring soon" badge count, sorted by expiry. _Persist: `contracts` (live store)._ _Class: Backend (KV)._
- **MSME / Udyam Registration Checker** — Plant&Machinery + annual turnover + Udyam no. + registered toggle → category rules (Micro ≤₹1cr P&M & ≤₹5cr T.O; Small ≤₹10cr & ≤₹50cr; Medium ≤₹50cr & ≤₹250cr; else Not-MSME) → category badge, threshold table with "← You", 8-item benefits list (PSL, CGTMSE collateral-free ≤₹10L, ECLGS subvention, 45-day MSMED protection, stamp duty, ISO/barcode subsidy, GeM preference, 3× bank-rate delayed-payment interest). _Persist: none (transient useState)._ _Class: Indicative._
- **Labour Law Compliance Checklist** — employee count (seeded 15 if payroll txns exist) → filters 11 acts by threshold (EPF≥20, ESI≥10, Bonus≥20, Gratuity≥10, MinWages≥1, PT≥1, Maternity≥10, Shops≥1, LWF≥1, Factories≥10, ContractLabour≥20, POSH≥10) → applicable list with risk badge (high/medium/low), frequency, description, done/total counter; checked-state is component-local (`Set`). _Persist: none (local checkbox Set; count transient)._ _Class: Indicative._
- **ROC / MCA Filing Calendar** — fixed FY-derived table → 8 filings (MGT-7/7A 60d-of-AGM, AOC-4 30d, ADT-1 15d, DIR-3 KYC 30-Sep, LLP Form-11 30-May, LLP Form-8 30-Oct, INC-20A 180d-of-incorp, MSME-1 Apr&Oct) with parsed-date urgency (overdue/Due Soon/Upcoming/Scheduled), entity, form, note. _Persist: none (static computed)._ _Class: Indicative._
- **Insurance Calendar** — add policy {name, type (Fire&Burglary/Shopkeeper/Marine/GroupHealth/GPA/D&O/Prof Indemnity/Vehicle/WC/Cyber/KeyMan/Other), insurer, premium, sum insured, renewal date, notes} → sorts by renewal, expired/urgent ≤30d status, "renewing soon" count, KPIs (count, total annual premium, renewing ≤30d). _Persist: `insurance-policies` (live store)._ _Class: Backend (KV)._

## ROC / MCA & Companies-Act tabs

- **ROC Filing Auto-Prep (AOC-4 / MGT-7)** — AGM date + entity type (private/public/small/OPC) + revenue (Σ positive txns) + snapshot (profit, cash) → form selection (small/OPC → MGT-7A, turnover ≥₹100cr → AOC-4 XBRL), due dates computed off AGM (AOC-4 +30d / OPC 180d-from-FY-end, annual return +60d, ADT-1 +15d), auto-filled filing data + ₹100/day-no-cap fee notes. _Persist: none (transient AGM/entity)._ _Class: Indicative (auto-filled figures derived from synced books)._
- **DIR-3 KYC & DPT-3 Tracker** — DIN-holder list {name, DIN, mode KYC-WEB vs e-form, done} + DPT-3 toggle + outstanding-deposit amount → KYC due 30-Sep (rolls to next yr if past, ₹5,000 reactivation), DPT-3 due 30-Jun (₹5,000 + ₹500/day); pending counter, deposit/exempted-loan reporting note. _Persist: `compliance-din-holders`, `compliance-dpt3-applies` (live store; exemptAmt transient)._ _Class: Backend (KV)._
- **Board / AGM Meeting Manager** — log meeting {kind Board/AGM/EGM/Committee, date, agenda, resolutions, minutes textarea, done} → Companies-Act 2013 statutory timelines table (≥4 board mtgs/yr gap ≤120d, 7-day board notice, AGM 9mo first/6mo subsequent gap ≤15mo, 21-clear-day AGM notice, minutes 30d, MGT-14 30d) with "action needed" flag when board count <4. _Persist: `compliance-meetings` (live store)._ _Class: Backend (KV)._
- **Statutory Registers** — seeded 7-register checklist {Members MGT-1, Directors&KMP Sec170, Charges CHG-7, RPT MBP-4, Share Transfers SH-6, Loans&Investments MBP-2, Deposits DPT-2} → toggle maintained + stamp updated-date, done/total counter. _Persist: `compliance-registers` (live store)._ _Class: Backend (KV)._
- **Shop & Establishment / Trade License Renewals** — generic `LicenseTracker` (seedAuthority "State Labour Dept") → add license {name, authority, number, expiry} → sorted by expiry, color bands (≤30d/≤60d/expired). _Persist: `compliance-shop-licenses` (live store)._ _Class: Backend (KV)._
- **FSSAI / Industry License Tracker** — same `LicenseTracker` (seedAuthority "FSSAI") → add/track licenses by expiry with countdown bands. _Persist: `compliance-industry-licenses` (live store)._ _Class: Backend (KV)._
- **Event-Based ROC Filing Tracker** — pick form (PAS-3, MGT-14, DIR-12, CHG-1, CHG-4, INC-22, SH-7, ADT-3) + event date → adds event-window (mostly 30d) → computes due date, filed/pending toggle, overdue counter, ₹100/day-no-cap + CHG-1 condonation note. _Persist: `comp-event-roc` (live store)._ _Class: Backend (KV)._
- **Director Disqualification Checker (Sec 164)** — add director {name, DIN} + tick 9 trigger flags (164(1)(a)–(h) unsound/insolvent/convicted/court-order/unpaid-calls/RPT-conviction/no-DIN-KYC; 164(2)(a)/(b) 3-yr no-filing / deposit-dividend default) → per-director disqualified-if-any-trigger badge with count. _Persist: `comp-dir-disqual` (live store)._ _Class: Indicative (self-assessment)._
- **Significant Beneficial Owner (SBO / BEN-2) Register** — add individual {name, PAN, direct %, indirect %} → SBO rule: indirect ≥10% OR (indirect >0 & total ≥10%) → SBO flag, BEN-2 due/filed toggle, pending counter; rejects holding >100%; BEN-1→BEN-2-30d note. _Persist: `comp-sbo-register` (live store)._ _Class: Indicative (fact-specific determination)._
- **Secretarial Standards Checklist (SS-1 / SS-2)** — 12 ICSI checklist items grouped SS-1 (board: 7d notice, quorum, 4 mtgs/120d, no 12-mo absence, minutes 30d, draft circ 15d) + SS-2 (general: 21-clear-day notice, explanatory statement, quorum 5/15/30, MGT-11 proxy 48h, attendance register, separate minute book 30d) → toggle done, % progress bar; §118(10)/MR-3 note. _Persist: `comp-secretarial-std` (live store, keyed map)._ _Class: Backend (KV)._

## Labour, tax & licensing tabs

- **Labour-Law Compliance Calendar** — fixed monthly/half-yearly recurrences → next due dates for PF/EPFO ECR (15th), ESI (15th), Professional Tax (~21st state), TDS-on-salary §192 (7th), Labour Welfare Fund (half-yearly Jun/Dec), with frequency + countdown. _Persist: none (static computed)._ _Class: Indicative._
- **Multi-Act Penalty Estimator** — act dropdown (ROC, late TDS deposit, late TDS return 234E, EPF/PF, ESI, GST) + amount + days delayed → per-act formula: ROC ₹100/day; TDS-deposit 1.5%/part-month §201(1A); TDS-return ₹200/day capped at TDS §234E; PF 12% §7Q + 5–25% §14B by delay slab; ESI 12% p.a.; GST ₹50/day + 18% p.a. → penalty + days + part-months. _Persist: none (transient)._ _Class: Indicative._
- **Compliance Health Score & Risk Heatmap** — seeded 7 weighted areas (GST 20%, TDS 15%, ROC 15%, PF/ESI/PT 15%, IncomeTax 15%, Licenses 10%, POSH 10%) cycled good/warning/bad → weighted score /100 (good=1, warning=0.5, bad=0), grade (Strong/Moderate/At-risk/Critical), areas-at-risk count, tappable heatmap tiles. _Persist: `compliance-health-areas` (live store)._ _Class: Backend (KV) self-rated._
- **Professional Tax — Multi-State Registration Tracker** — add state (8 PT states with max ₹2,500/yr + frequency info; lists 8 no-PT states) → per state track EC/RC obtained toggles + EC/RC numbers + PT-this-period amount → states tracked, registrations pending, total PT payable/period; rejects duplicate state. _Persist: `comp-pt-states` (live store)._ _Class: Backend (KV)._
- **POSH & Statutory Policy Tracker** — seeded 6-policy checklist {POSH policy ≥10 emp, IC constituted, annual report 31-Jan, training annual, code-of-conduct, complaints register} toggle done + IC-validity check (woman presiding + ≥50% women + external NGO member) → valid/incomplete verdict. _Persist: `compliance-posh-policies` (live store; IC checkboxes transient)._ _Class: Backend (KV)._

## Sector-licensing & disclosure tabs

- **Trademark / IP Renewal Tracker** — add asset {name, kind TM/Patent/Copyright/Design, reg no, class, reg date} → term rules (TM 10yr, Patent 20yr, Design 10yr, Copyright life+60 none) → computes renewal date + countdown, "renewing ≤6mo" count, lapsed badge. _Persist: `comp-ip-assets` (live store)._ _Class: Indicative._
- **Import-Export (IEC) Compliance Tracker** — IEC number + last-DGFT-update date + per-port AD-Code list {port, AD bank, registered toggle} → annual IEC-update window Apr–Jun (deadline 30-Jun, deactivation if missed), 3-item checklist (IEC obtained, updated this FY, AD-code at every port). _Persist: `comp-iec-number`, `comp-iec-updated`, `comp-iec-adcodes` (live store)._ _Class: Backend (KV)._
- **Environmental / Pollution Consent (CTE / CTO) Tracker** — add consent {kind CTE/CTO, category Red/Orange/Green/White, number, issued, valid-until} → category validity rules (Red 5yr, Orange 10yr, Green 15yr, White exempt) → sorted by validity, expired/≤90d bands, category color. _Persist: `comp-pollution-consents` (live store)._ _Class: Backend (KV)._
- **Fire / Safety NOC Tracker** — add record {premise, type Provisional/Final NOC/Fire Safety Cert, number, valid-until, mock-drill note} → sorted by validity, "renewing ≤60d" count, expired/≤60d bands, editable mock-drill field. _Persist: `comp-fire-noc` (live store)._ _Class: Backend (KV)._
- **CSR Applicability & Spend Tracker** — net worth + turnover (seeded Σ positive txns) + net profit (seeded snapshot) + CSR spent → Sec 135 applicability (net worth ≥₹500cr OR turnover ≥₹1,000cr OR net profit ≥₹5cr) → 2% obligation (of net profit proxy), spent, shortfall, progress bar, CSR-2/Schedule-VII unspent-transfer note. _Persist: none (transient; seeded from synced store)._ _Class: Indicative._
- **Related-Party Transaction (RPT) Register** — log {party, relation (8 options), nature, amount, basis Arm's-length/Not, board-approval toggle, date} → Sec 188/MBP-4 register, total value, awaiting-approval count, arm's-length badge, AOC-2/shareholder-approval note. _Persist: `comp-rpt-register` (live store)._ _Class: Backend (KV)._

## Master calendar & reconciliation tabs

- **Contract / Agreement Template Library** — pick template (NDA, Employment, MSA, Vendor/Supply) + counterparty → interpolates firm name + counterparty + today into 4 starter contract bodies → copy-to-clipboard. _Persist: none (transient; firm name from synced store)._ _Class: Preview (boilerplate generator, copy-only)._
- **Annual Compliance Master Calendar** — FY-scoped consolidation of all streams (GST/Income Tax/ROC-MCA/Labour/TDS) gated by `gstRegistered` + payroll → 17 rows: monthly TDS/GSTR-1/GSTR-3B/PF-ESI + advance-tax Q1–Q4 + tax audit 3CA/3CB-3CD + ITR 31-Oct + DPT-3/DIR-3-KYC/AOC-4/MGT-7 + GSTR-9/9C 31-Dec + MSME-1 H1/H2 → stream filter chips, countdown, copy-all to clipboard (TSV). _Persist: none (computed; reads synced firm profile/txns)._ _Class: Backend (derived) / Indicative dates._
- **MSME Form-1 — Delayed Payments to MSE Suppliers** — add due {supplier, Udyam no, invoice date, amount, paid toggle} → ages each, overdue beyond 45d, interest ≈ 3× bank rate (19.5% p.a. simple) → reportable amount, est. interest exposure, total tracked KPIs, current half-year period label, §43B(h) deduction note. _Persist: `comp-msme-form1` (live store)._ _Class: Indicative (simplified interest)._
- **GST vs Books Turnover Reconciliation (GSTR-9C prep)** — books turnover (Σ positive txns) + GSTR-1/3B turnover + adjustments (less exempt, less non-GST income, add unbilled) → adjusted books vs GST diff, % diff, status (reconciled <₹1 / minor ≤1% / material review / info) → line-by-line schedule + diff banner; GSTR-9C >₹5cr note. _Persist: `comp-gst-recon-gstr`, `comp-gst-recon-unbilled`, `comp-gst-recon-exempt`, `comp-gst-recon-nongst` (live store; books from synced store)._ _Class: Backend (KV) / Indicative recon._

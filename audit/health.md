## Financial Health (`/health`) — 18 tools

One composite financial-health score with 18 diagnostic tools that derive every ratio, distress signal and stress test live from the transaction snapshot. Stakeholders: owner, viewer, all (read-only roles see identical output; only the Fitness Trend writes state, gated for viewers). Backend: everything recomputes from `computeFinancialSnapshot(store)` (`@/lib/finance`) memoised on `store`; no health-specific server call — all assets/equity/EBIT are transaction proxies, the lone persisted artefact is the fitness-trend history in the synced `featureData` KV bag.

### Header / always-on panels (not in jump-nav, render above the 18 sections)

- **Composite Health Score + Lender-Ready badge** — `snap.health.score/grade` → `ScoreRing` (SVG ring, green ≥70 / yellow ≥45 / red); `lenderReady = score ≥ 65 && (dscr null || dscr ≥ 1.25)` toggles "Lender-ready / Below typical lender bar" pill. _Persist: live store._ _Class: Backend._
- **Score Profile radar** — `health.components` → Recharts `RadarChart` of each component's rounded score (axis = first word of label). _Persist: live store._ _Class: Backend._
- **What's dragging the score** — `health.components` sorted ascending, slice top-3 weakest → cards with score, `detail`, and a `fixPath`/`fixLabel` navigation CTA per component. _Persist: live store._ _Class: Backend._
- **Component Breakdown** — every `health.component` (liquidity, profitability, collections, leverage, growth, concentration, compliance) → row with `weight`% , `detail`, score-coloured bar (`barColor`) and fix-link to its module. _Persist: live store._ _Class: Backend._
- **Key Ratios vs Lender Benchmarks** — 12 ratios, each value vs target with ok/needs-attention and click-through path: Current Ratio (≥1.5x→/working-capital), Quick Ratio (≥1.0x), DSCR (≥1.25x→/debt), Interest Coverage (≥3x), Cash Conversion Cycle (≤45d), Net Margin 6mo (`grossMarginPct` ≥10%→/analytics), Runway (≥90d→/forecast), Net Working Capital (>₹0), Top-Customer Share (≤30%→/invoices), EBITDA Margin (computed `monthlyEbitda = monthlyNet + monthlyInterest + monthlyRevenue×1.5%`; ≥15%), Free Cash Flow Ratio (`opCashFlow = monthlyNet + monthlyDebtService`; ≥10%→/debt), Revenue Growth CMGR (≥3%/mo). _Persist: live store._ _Class: Backend (EBITDA/FCF inputs are proxy add-backs → Indicative)._
- **Snapshot strip** — 4 cards: Cash on Hand (/transactions), Open Receivables (/receivables), Debt Outstanding (/debt), Working-Capital Gap (/working-capital). _Persist: live store._ _Class: Backend._

### Jump-nav sections (iterating the `sections` array; 18 entries → 18 rendered `<section>` tools)

- **Distress (Z') — Altman Z' Score** (`#health-altman-z`) — inputs: snapshot proxies (estimatedFA=`monthlyRevenue×6`, totalAssets=cash+AR+inventory+FA, totalLiab=debt+AP+obligationsDue90, retainedEarnings=`max(0,monthlyNet×12)`, ebitAnnual=`(monthlyNet+monthlyInterest)×12`, bookEquity=assets−liab) → **Altman Z' for private SMBs**: `Z' = 0.717·X1 + 0.847·X2 + 3.107·X3 + 0.420·X4 + 0.998·X5` where X1=NWC/assets, X2=retained/assets, X3=EBIT/assets, X4=equity/liab (=3 if no debt), X5=revenue/assets → score + zone (>2.9 safe · 1.23–2.9 grey · <1.23 distress), per-factor weighted-contribution table, asset/liab/equity card. _Persist: none._ _Class: Indicative (real formula over transaction proxies)._
- **Stress Test — Liquidity Stress Test** (`#health-stress-test`) — inputs: 4 sliders (revDrop 0–80%, arDelay 0–100% receivables stuck, costRise 0–50%, bufferMonths 1–12) → stressedRevenue/expense/net, arShortfall=`AR×arDelay%`, monthlyInflowGap spread over 3-mo window, adjDailyBurn, stressedRunway=`floor(cash/adjDailyBurn)`, safetyFloor=`stressedExpense×bufferMonths`, breaches if cash<floor or runway<buffer×30 → survive/fail verdict, runway today vs under-shock, 6-row stressed P&L ledger. _Persist: none (transient `useState` sliders)._ _Class: Simulated._
- **Fitness Trend — Financial Fitness Trend** (`#health-fitness-trend`) — inputs: `snap.health.score`, top driver/drag (components sorted desc), `snap.months` revenue → records one `FitnessPoint {month,score,topDriver,topDrag}` per calendar month (capped 24), charts live recorded points over an estimated back-trend (today's score scaled by `month.revenue/latestRev`, clamped 0.4–1.2); delta over N months with trend icon; current-score / strongest-driver / biggest-drag cards + reverse-chron history table. _Persist: KV key `health-fitness-trend` (`useFeatureState`, synced featureData; viewer writes gated)._ _Class: Backend score + KV-persisted history (chart back-trend is Indicative)._
- **Liquidity — Liquidity Ladder** (`#health-liquidity-ladder`) — inputs: currentLiab=`max(1, AP+obligationsDue90+monthlyDebtService×12)`, currentAssets=cash+AR+inventory → 3 progressively stricter rungs: Current Ratio (assets/liab, target 1.5x), Quick Ratio acid-test ((cash+AR)/liab, 1.0x), Cash Ratio (cash/liab, 0.5x) → banded bars + currentAssets/currentLiab/NWC cards → /working-capital. _Persist: none._ _Class: Indicative (liabilities estimated)._
- **Solvency — Solvency & Coverage** (`#health-solvency`) — inputs: totalAssets (incl FA proxy), totalLiab, equity → 6 rows vs lender bands: Debt-to-Equity (≤2.0x, ∞ if no equity), Debt-to-Assets (≤50%), Equity Ratio (≥40%), Interest Coverage (≥3x), DSCR (≥1.25x), Debt÷Annual-Profit (≤3x) → `passes`/6 with solvent verdict (≥4) + assets/liab/equity cards → /debt. _Persist: none._ _Class: Indicative._
- **Efficiency — Efficiency & Turnover** (`#health-efficiency`) — inputs: annualRev/annualCogs, totalAssets → turns/yr + equivalent days: Asset Turnover (rev/assets, ≥1.0x, CCC days), Receivables Turnover (rev/AR, DSO≤45d), Inventory Turnover (cogs/inventory, DIO≤60d), Payables Turnover (cogs/AP, DPO 30–60d) → Good/Slow table → /working-capital. _Persist: none._ _Class: Indicative._
- **DuPont ROE — DuPont ROE Breakdown** (`#health-dupont`) — inputs: annualRev, annualNet, totalAssets, equity=`max(1,assets−liab)` → `ROE = NetMargin × AssetTurnover × EquityMultiplier`; three driver cards (margin = net/rev, turnover = rev/assets, multiplier = assets/equity) → combined ROE% (target ≥15%) + annual-net/equity/assets cards. _Persist: none._ _Class: Indicative._
- **Runway Gauge — Cash-Runway Gauge** (`#health-runway-gauge`) — inputs: `snap.runwayDays`, monthlyNet → months=runwayDays/30 (∞ if ≥999 CF-positive), dailyBurn, semicircle SVG gauge (0–12mo, green ≥6 / yellow ≥3 / red) + band copy; cash / daily-burn / monthly-net / runway-days cards → /forecast. _Persist: none._ _Class: Backend._
- **Early Warning — Distress Early-Warning Checklist** (`#health-early-warning`) — inputs: snapshot fields → 8 live red-flag tests: negative op cash flow, runway<90d, DSCR<1.25x, current ratio<1.0x, >40% receivables overdue (`overdueReceivable/AR`), customer concentration>40%, CCC>75d, negative NWC → triggered-count maps to All-clear (0) / Early-warning monitor (≤2) / red-flags intervene (>2); each card click-throughs to its module. _Persist: none._ _Class: Backend (overdue/topCustomer proxies → Indicative)._
- **CF Coverage — Cash-Flow Coverage** (`#health-cf-coverage`) — inputs: opCash=`monthlyNet+monthlyDebtService`, taxAccrual=`max(0,estAnnualProfit)×25%/12` → 3 layered coverage tests: Interest coverage (opCash/interest, ≥3x), Debt-service coverage (opCash/EMI, ≥1.25x), Debt+tax coverage (opCash/(EMI+tax), ≥1x) → `passing`/3, banded bars, op-cash/fixed-claims/tax-accrual cards → /debt. _Persist: none._ _Class: Indicative (tax accrual estimated)._
- **Margin Stability — Margin Stability Score** (`#health-margin-stability`) — inputs: per-month net margin from `snap.months` (rev>0) → mean, SD, **coefficient of variation** `cv = sd/|mean|` → `score = round(clamp(100 − cv×100))` (≥60 steady); best/worst month, range, mini bar chart of monthly margins; needs ≥2 months. _Persist: none._ _Class: Backend._
- **Growth Quality — Cash vs Accrual** (`#health-growth-quality`) — inputs: revenueGrowthPct (CMGR), opCash, arMonths=`AR/monthlyRevenue`, cashConv=`opCash/monthlyRevenue` → 3 tests: growth positive, cashConv ≥5%, arMonths ≤1.5 → passes/3 maps to high/mixed/low-quality verdict; op-cash/cash-conversion/AR-months cards → /receivables. _Persist: none._ _Class: Backend (opCash is proxy)._
- **Expense Discipline — Expense Discipline Trend** (`#health-expense-discipline`) — inputs: per-month expense/revenue ratio from `snap.months` → first vs last delta (improving if <−1, worsening if >1), best-month ratio, **cost leakage** = `max(0,(lastRatio−bestRatio)/100 × lastRevenue)`; coloured bar chart (red ≥100% / yellow ≥90% / green) + latest/best/trend/leakage cards → /analytics; needs ≥2 months. _Persist: none._ _Class: Backend._
- **Resilience — Overall Resilience Index** (`#health-resilience`) — inputs: runwayDays, grossMarginPct, dscr, topCustomerPct → 4 pillars blended: cash buffer (runway/180d, 35%), profit cushion (margin×5, 25%), leverage headroom (dscr/1.25×60+25, 25%), diversification (100−(topCustomer−15)×2, 15%) → `score = round(weighted)` with ScoreRing + A+–D grade and resilient/moderate/fragile band; each pillar links to its module. _Persist: none._ _Class: Indicative._
- **Quick Ratio — Quick-Ratio Gauge** (`#health-quick-ratio-gauge`) — inputs: `snap.quickRatio` → 0–2x dial with 1.0x safety marker, band (healthy ≥1 / tight ≥0.7 / strained); optional "Why it matters" toggle; quick-ratio/current-ratio/cash cards → /working-capital. _Persist: none (transient `showWhy` useState)._ _Class: Backend._
- **Debt Burden — Debt-Burden Index** (`#health-debt-burden`) — inputs: dsrPct=`monthlyDebtService/monthlyRevenue`, dscr, interestCoverage → 3 strains blended: debt-service-vs-revenue (100−dsr×4, 40%), DSCR headroom (dscr/1.25×60+25, 35%), interest coverage (ic/3×70+15, 25%) → `score = round(weighted)` (100 if debt-free) with ScoreRing/grade and light/moderate/heavy band → /debt. _Persist: none._ _Class: Backend._
- **Cash Buffer — Cash-Buffer Months** (`#health-cash-buffer`) — inputs: cash, monthlyExpense, monthlyNet → months=`cash/monthlyExpense`, burnMonths=`cash/(−monthlyNet)` (null if CF-positive) → `score = clamp(months/6×100)`, bar with 3-month floor marker, comfortable ≥6 / adequate ≥3 / thin band; cash/expense/months-covered/at-current-burn cards → /forecast. _Persist: none._ _Class: Backend._
- **Revenue Mix — Revenue-Diversification Index** (`#health-revenue-diversification`) — inputs: `snap.customerHhi`, topCustomerPct → **Herfindahl** inverted: `score = round(100 − (hhi−1000)/9000 × 100)`, effective customers = `10000/hhi` → ScoreRing/grade, well-spread ≥70 / some-concentration ≥45 / concentrated band; top-share (≤30%) / HHI / effective-customers / diversification cards → /invoices. _Persist: none._ _Class: Backend._

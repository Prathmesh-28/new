## Vendors & Procurement (`/vendors`) — 26 tools

End-to-end vendor & procurement workbench: directory + AP/MSME compliance, PO/requisition/RFQ lifecycle, payment optimisation, vendor TDS, and spend/risk analytics. Stakeholders: ops, finance. Backend: derives a vendor master from live `store.transactions` (`amount < 0 && counterparty`) + `store.obligations` + `store.bankAccounts`; tool-built records persist via `useFeatureState` into `store.featureData` (synced "app" KV namespace → localStorage + backend KV). The "Schedule Payment" modal writes a real cash obligation via `addObligation`; no payout rail is invoked (gated).

Tab array (26): directory, aging, msme, po, three-way, vendor-tds, kyc-vault, early-pay, pay-run, spend-analysis, dup-vendor, requisition, vendor-score, rfq, advances, debit-notes, pay-forecast, blanket-po, concentration, stmt-recon, msme-interest, savings, form16a, rebate, watchlist, pay-mode.

- **Directory** — live expense txns (negative, with counterparty) → groups by counterparty; per vendor computes totalSpend, txnCount, avgPayment, last payment date/category, this-month vs last-month spend → trend (up if thisMonth > 1.05×lastMonth, down if < 0.95×); search + category filter + sortable table; summary cards (vendor count, total spend, this-month spend, recurring = txnCount ≥ 2) → vendor table with "Schedule" action. _Persist: live store (derived, read-only)._ _Class: Backend._
- **Schedule Payment (modal)** — vendor + amount (default avgPayment) + future date + optional note → validates amount > 0 → `addObligation({type:"other", dueDate, amount})` so it flows into cash forecast/runway. _Persist: live store (obligations)._ _Class: Backend._
- **AP Aging** — `store.obligations` of type other/payroll/tax → daysOverdue = today − dueDate → bucket (current ≤0, 1–30, 31–60, 60+); bucket summary cards (amount + count) + sorted ageing table with status chip. _Persist: live store (obligations).` _Class: Backend._
- **MSME 45-Day** — obligations of type other/loan → daysSinceDue → classifies breach (>45d), at-risk (31–45d), safe (1–30d), upcoming (≤0); per MSMED Act 2006: >45d flags "Breach — ITR disclosure", 30–45d shows "pay within 45−n days"; summary cards with amounts. _Persist: live store (obligations)._ _Class: Backend._
- **Purchase Orders** — vendor (datalist of known vendors) + dates + multi-line items (desc/qty/rate) + notes → auto PO number `PO-YYYY-NNNN`, poTotal = Σ qty×rate; lifecycle status select draft→sent→received→closed→cancelled; cards: open POs, open value (sent+received), total committed (≠cancelled). _Persist: KV `vendor-purchase-orders`._ _Class: KV._
- **3-Way Match** — per line: PO qty/rate, GRN qty received, invoice qty/rate, tolerance% → flags GRN≠PO qty, invoice≠GRN qty, price variance |invRate−poRate|/poRate×100 > tolerance; overBilled = invQty×invRate − grnQty×poRate; cards: lines, flagged, over-billed exposure (Σ positive overBilled). _Persist: KV `vendor-three-way-match`._ _Class: KV._
- **Vendor TDS Ledger** — vendor + section (194C 2%/194C-ind 1%/194J 10%/194J-tech 2%/194Q 0.1%/194I-rent 2%/194I-land 10%/194H 5%) + gross + date → TDS = round(gross×rate/100), net payable preview; deposited toggle; cards: total deducted, deposited, pending; feeds quarterly 26Q. _Persist: KV `vendor-tds-ledger`._ _Class: KV._
- **Onboarding / KYC** — vendor name + PAN/GSTIN/IFSC (regex-validated on save) + MSME Udyam + bank acc + email → kycComplete = PAN∧GSTIN∧IFSC valid ∧ bankAcc ≥6 chars; cards: vendors on file, KYC complete X/N, MSME registered; masks account to last 4. _Persist: KV `vendor-kyc-vault`._ _Class: KV._
- **Early-Pay Discount** — per offer: invoice amount, discount%, discount days, net days + global cost-of-capital → effAnnual = disc%/(100−disc%)×365/(netDays−discDays)×100; savings = amt×disc%; carryCost = amountPaidEarly×coc%×period/365; netBenefit = savings−carryCost; worthIt = effAnnual > coc; cards: offers worth taking, net benefit. _Persist: KV `vendor-early-pay-offers` (cost-of-capital is local)._ _Class: KV._
- **Pay-Run Scheduler** — obligations (other/payroll/tax/loan) due within horizon (7/15/30/60/90d) → checkbox select into a dated run; runTotal = Σ selected; available = Σ bank balances; shortfall = runTotal − available; cards: run total, items selected, overdue in run, after-run balance; "Schedule" toasts warning if shortfall (no disbursement — gated). _Persist: KV `ven-pay-run-selected` (selection); reads live obligations + bankAccounts._ _Class: KV._
- **Spend Analysis** — live txns → spend by vendor ranked; total; concentration threshold (default 25%) flags vendors ≥threshold of total; top-5 share; long-tail vendors <2% each + consolidation suggestion; cards + share bars + risk/consolidation alert banners. _Persist: none (threshold is local; derived from live txns)._ _Class: Backend._
- **Duplicate Detector** — normalises vendor names from live txns (lowercase, strips pvt/ltd/llp/inc/co/&/punctuation) → groups names sharing a normalised key (length ≥2, >1 member); ranks by combined spend; "Not a duplicate" dismiss; cards: duplicate sets, vendors involved, spend at risk of fragmentation. _Persist: KV `ven-dup-dismissed` (dismissals); derived from live txns._ _Class: Backend._
- **Requisition → PO** — requester + item + qty + est unit cost + need-by + justification → auto `PR-YYYY-NNN`, status pending→approved→converted / rejected; approvedVal = Σ estCost×qty of approved; cards: pending approval, approved value, total; convert toasts to raise PO in PO tab. _Persist: KV `ven-requisitions`._ _Class: KV._
- **Performance Review** — vendor (datalist) + 1–5 sliders on on-time/quality/price/support + notes → score = mean of four, period = current MMM yyyy; cards: vendors reviewed, avg score, under-performers (<3); highlights top performer; star display. _Persist: KV `ven-performance-reviews`._ _Class: KV._
- **RFQ Comparison** — item + qty + N quotes (vendor/unit price/lead days/payment term days) → weighted score: price 50% (minPrice/price), lead 30% (minLead/lead), terms 20% (term/maxTerm); ranks descending, recommends top; order total = unitPrice×qty. _Persist: KV `ven-rfq-item`, `ven-rfq-qty`, `ven-rfq-quotes`._ _Class: KV._
- **Advances Tracker** — vendor + amount + date + purpose → record advance; "Adjust vs bill" knocks down balance (adjusted = min(amount, adjusted+amt)); cards: total advanced, adjusted, outstanding (Σ amount−adjusted); progress bar per advance. _Persist: KV `ven-advances`._ _Class: KV._
- **Debit / Return Notes** — vendor + amount + reason (return/rate-diff/shortage/damage/discount) + date → auto `DN-YYYY-NNN`, status open↔adjusted; openCredit = Σ open; per-vendor open-credit netting hint; cards: open notes, credit owed to you, total raised. _Persist: KV `ven-debit-notes`._ _Class: KV._
- **Payables Forecast** — buckets 0–30/31–60/61–90d: scheduled = Σ obligations (other/payroll/tax) due in window; recurring run-rate = (90-day spend on vendors paid ≥2×)/3 per month, added to each bucket; total = scheduled+runRate; 90-day total in footer; CSV export. _Persist: none (derived from live obligations + txns)._ _Class: Backend._
- **Blanket PO Drawdown** — vendor + annual total value + valid-till → umbrella PO; "Draw" release (amount + note) validated against remaining = totalValue − Σreleases (blocked if exceeds); cards: blanket POs, total committed, drawn to date; consumed% bar + expiry flag + release log. _Persist: KV `ven-blanket-pos`._ _Class: KV._
- **Concentration Risk** — live txns → spend by vendor & by category; totalShare = spend/total, catShare = spend/categoryTotal; flags totalShare ≥ threshold (slider 10–60%, default 30) or catShare ≥60% as single-source; HHI = Σ totalShare² (≥2500 highly / ≥1500 moderately / else diversified); cards + ranked table (top 30). _Persist: KV `ven-concentration-threshold` (threshold only); derived from live txns._ _Class: Backend._
- **Statement Recon** — vendor (datalist) + pasted statement lines (parses last number per line as amount) + tolerance → greedy match each statement amount to an unused ledger entry (|diff| ≤ tol) for that vendor; outputs matched, on-statement-only (unbooked), in-ledger-only, balance difference = stmtTotal − ledgerTotal. _Persist: none (transient; reads live txns ledger)._ _Class: Backend._
- **MSME Interest 43B(h)** — per due: vendor + amount + acceptedOn + global RBI bank rate (default 6.5%) → penal annualRate = 3×bankRate; overdueDays = max(0, daysHeld−45); months = overdueDays/30; compound interest = amt×((1+annualRate/12)^months − 1) (Sec 16 MSMED, non-deductible Sec 23/43B(h)); cards: tracked principal, dues past 45d, est interest; total in footer. _Persist: KV `ven-msme-dues`, `ven-msme-bank-rate`._ _Class: KV._
- **Savings Tracker** — vendor + type (negotiation/early-pay/consolidation/avoided/rebate) + baseline + final (final ≤ baseline enforced) + note → saved = baseline−final; cards: total saved, saved this year (FY-year filter), avg savings rate = totalSaved/totalBaseline; per-entry %. _Persist: KV `ven-savings-entries`._ _Class: KV._
- **Form 16A Tracker** — vendor + PAN + quarter (Q1–Q4) + FY + TDS amount → status cycle pending→downloaded→issued (15-day issuance deadline, ₹100/day penalty); cards: certificates, awaiting issue (≠issued), total TDS covered. _Persist: KV `ven-f16a-certs`._ _Class: KV._
- **Rebate Tracker** — vendor + purchase threshold + rebate% → ytdPurchase seeded from live spend-by-vendor (refreshable); earned = ytdPurchase≥threshold ? ytdPurchase×rate/100 : 0; cards: active slabs, rebate accrued; progress bar to threshold. _Persist: KV `ven-rebate-deals` (slabs); ytd seeded/refreshed from live txns)._ _Class: KV._
- **Watchlist / Blacklist** — vendor + level (watch/hold/blacklist) + reason → flag record with date; cards: flagged vendors, blacklisted, on watch/hold; meant to warn before raising a PO. _Persist: KV `ven-watchlist-flags`._ _Class: KV._
- **Payment-Mode Mix** — live txns → classifyMode from description+counterparty keywords (upi/@ → UPI; neft/rtgs/imps → NEFT; chq/cheque → Cheque; cash/atm → Cash; card/pos → Card; else NEFT) → count/total/% per mode, sorted; warns if cash share >15% (Sec 40A(3) ₹10,000 per-payment disallowance); bars + grand total. _Persist: none (derived from live txns)._ _Class: Backend._

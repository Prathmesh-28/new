## Suppliers (`/suppliers`) — 21 tools

Supplier-side procurement cockpit: pay invoices early, score/rank vendors, plan reorders, manage rate contracts, verify MSME status, and reconcile GST/quality/cost across the supply base. Stakeholders: ops. Backend: `/api/suppliers` + KV.

> Persistence note: all "KV" tools use `useFeatureState(<key>)`, which writes to `store.featureData[<key>]` in the "app" KV namespace — localStorage immediately, then debounced to the backend and synced across the user's devices. Only Early-Pay calls live backend endpoints.

- **Early-Pay** (`EarlyPaySection`) — loads offers from `GET /api/suppliers/marketplace` (supplier_name, invoice_amount, early_pay_discount %, days_early, due_date, precomputed saving); "Pay Early" → `POST /api/suppliers/pay-early {offer_id}`, marks paid client-side, toasts saving → stat cards (open offers, total payable = Σ invoice_amount, savings available = Σ saving of unpaid) + per-offer pay-today amount (invoice − saving). _Persist: live backend (`/api/suppliers/marketplace`, `/api/suppliers/pay-early`); paid set is in-memory only._ _Class: Backend._
- **Scorecard** (`SupplierScorecard`) — inputs: name, quality % (0–100), OTIF % (0–100), price index (100=market, clamped ≥1), responsiveness 1–5 → composite = quality·0.35 + OTIF·0.35 + priceScore·0.20 + respScore·0.10, where priceScore = clamp(0–100, 200−priceIndex) and respScore = resp/5·100; grade A≥85 / B≥70 / C≥55 / D<55; rows ranked desc by composite → ranked table + avg composite + top supplier. _Persist: KV `supplier-scorecards`._ _Class: KV._
- **Reorder Point** (`ReorderPointTracker`) — inputs: item, avg daily use, lead-time days, safety stock, on-hand → ROP = avgDailyUse·leadTime + safetyStock; days-cover = onHand/avgDailyUse; suggested order qty = max(0, ROP + avgDailyUse·leadTime − onHand); flags rows where onHand ≤ ROP as "Reorder" → table + counts (tracked / below ROP / healthy). _Persist: KV `supplier-reorder-points`._ _Class: KV._
- **Rate Contracts** (`RateContractManager`) — inputs: supplier, item, rate, UoM (unit/kg/litre/metre/box/dozen/tonne), valid-from, valid-to → status engine: validTo<today=Expired, validFrom>today=Upcoming, daysLeft≤30=Expiring Nd, else Active → table + counts (contracts / expiring ≤30d / expired). _Persist: KV `supplier-rate-contracts`._ _Class: KV._
- **MSME Verify** (`MsmeVerificationBatch`) — inputs: supplier, Udyam no. (regex `UDYAM-XX-00-0000000`), category (micro/small/medium/not-msme/pending), outstanding ₹, invoice date; "Verify pending" sets pending→micro if Udyam format valid else not-msme → Sec 43B(h): days-outstanding from invoiceDate; micro/small with outstanding>0 and >45 days flagged "Disallowed"; stats: batch size, protected (micro+small) count, at-risk amount = Σ outstanding of breaching rows. _Persist: KV `supplier-msme-batch`._ _Class: KV. (Udyam is format-check only, not a live portal lookup — Indicative on the verification itself.)_
- **Terms Optimizer** (`PaymentTermsOptimizer`) — inputs: supplier, invoice amount, discount %, discount days, net days, + global cost-of-capital % → annualised yield = d/(100−d) · 365/(net−disc) · 100; saving = invoice·d/100; verdict "Pay early" when yield ≥ CoC; stats: terms tracked, worth-early count, discount captured = Σ saving of worth-taking. _Persist: KV `sup-terms-optimizer` (rows) + `sup-terms-coc` (CoC, default 14)._ _Class: KV._
- **Price Trend** (`PriceTrendTracker`) — inputs: supplier, item, quoted price, quote date → groups by supplier+item, sorts by date, change % = (last−first)/first·100, sorted desc → table (first/latest/change/quotes/last date) + counts (tracked lines / prices rising / quotes logged). _Persist: KV `sup-price-trend`._ _Class: KV._
- **Lead-Time Var** (`LeadTimeVarianceAnalyzer`) — inputs: supplier, PO ref, promised days, actual days → per-supplier: mean slip (actual−promised), σ (std dev of slips), on-time % (actual≤promised); rating Reliable (σ≤2 & on-time≥80%) / Erratic (σ>5 or on-time<50%) / Watch; sorted desc by σ → stats table. _Persist: KV `sup-leadtime-variance`._ _Class: KV._
- **Alt Suppliers** (`AltSupplierShortlist`) — inputs: item, supplier, price, lead days, min order qty → groups by item, flags cheapest ("Best ₹") and fastest ("Fastest") per item, single-source (<2 options) flagged as risk; sorted by price asc → per-item tables + counts (items with options / single-sourced / total options). _Persist: KV `sup-alt-shortlist`._ _Class: KV._
- **Concentration** (`ConcentrationRisk`) — inputs: supplier, annual spend → Pareto: share = spend/total, cumulative %, HHI = Σ(share²); concentrated when top-vendor share >30% or HHI >2500 (warning banner) → ranked table with share bar + cumulative; stats (total spend / top share / HHI). _Persist: KV `sup-concentration`._ _Class: KV._
- **GRN 3-Way** (`GrnThreeWayMatch`) — inputs: PO ref, supplier, PO/GRN/invoice qty, PO/invoice rate, rejected qty, + global rate-tolerance % → match: qtyOk = invQty ≤ grnQty, rateOk = |invRate−poRate|/poRate·100 ≤ tol, reject % = rejected/grnQty·100, clean = qtyOk & rateOk; over-billed = Σ(invRate−poRate)·invQty for rate-fail rows → Pass/Hold table + counts (receipts / clean matches / over-billed ₹). _Persist: KV `sup-grn-match` (rows) + `sup-grn-tolerance` (tol, default 2)._ _Class: KV._
- **Negotiation** (`NegotiationPrepSheet`) — inputs: supplier, annual spend, current/target/walk-away rate + editable checklist (5 seeded prep items, add/toggle/delete) → target discount = (cur−tgt)/cur·100; annual saving = spend·(cur−tgt)/cur when tgt<cur; ready when all checklist items done → stat cards + checklist. _Persist: KV `sup-nego-supplier`, `sup-nego-spend`, `sup-nego-current`, `sup-nego-target`, `sup-nego-walk`, `sup-nego-checklist`._ _Class: KV._
- **Pay Priority** (`PaymentPriorityPlanner`) — inputs: supplier, amount due, due date, early-pay discount %, MSME checkbox → priority score: overdue 60+min(40,−dtd); due≤7d 35−2·dtd; else max(0,20−dtd/5); +50 if MSME & dtd≤5 (43B(h) clock); +discount·6 if discount & not overdue; sorted desc → ranked table + stats (total due / overdue amount / MSME urgent ≤5d count). _Persist: KV `sup-pay-priority`._ _Class: KV._
- **GST-2B Match** (`Gst2bMatchStatus`) — inputs: supplier, GSTIN (regex-validated, optional), ITC in books, ITC in GSTR-2B, + global ₹ tolerance → diff = book−2B; |diff|≤tol=Matched, diff>tol="Not in 2B" (vendor unfiled, ITC blocked), 2B>book="Excess in 2B"; ITC at-risk = Σ(book−2B) of "Not in 2B" rows → table + stats (total book ITC / matched count / at-risk ₹). _Persist: KV `sup-gst2b-match` (rows) + `sup-gst2b-tolerance` (tol, default 1)._ _Class: KV. (User-entered 2B figures, not a live GST-portal pull — Indicative on the reconciliation source.)_
- **Quality PPM** (`QualityPpmTracker`) — inputs: supplier, units received, units rejected, period (month), + global target PPM → per-supplier aggregate: PPM = rejected/received·1,000,000, reject %; flags suppliers above target; sorted desc by PPM → table + stats (suppliers / above-target count / worst PPM). _Persist: KV `sup-quality-ppm` (rows) + `sup-quality-target-ppm` (target, default 5000)._ _Class: KV._
- **Credit Util** (`CreditPeriodUtilization`) — inputs: supplier, granted credit days, avg actual pay days, monthly purchase ₹ → utilization % = avgPay/granted·100; unused float = (monthlyPurchase/30)·max(0, granted−avgPay); verdict Over-terms (avgPay>granted) / Paying-early (util<70%) / Well-used; sorted desc by unused float → table + stats (suppliers / unused free credit Σ / over-running count). _Persist: KV `sup-credit-util`._ _Class: KV._
- **Landed Cost** (`LandedCostCompare`) — inputs: supplier, item, qty, unit price, freight total, duty %, insurance total → goods = qty·unitPrice; duty = goods·duty%; landed total = goods+duty+freight+insurance; landed/unit = total/qty; groups by item, flags cheapest landed ("Best landed"), flips counter = items where cheapest-sticker ≠ cheapest-landed → per-item tables + stats (items / quotes / flips). _Persist: KV `sup-landed-cost`._ _Class: KV._
- **Contract Calendar** (`ContractExpiryCalendar`) — inputs: supplier, contract/SOW title, annual value, notice-period days, expiry date → days-to-expiry; status Expired (<0) / Notice window (≤noticeDays) / Renew soon (≤90d) / Nd left; value-at-risk = Σ annualValue of contracts in notice window; sorted by expiry asc → table + stats (contracts / in-notice count / value at risk). _Persist: KV `sup-contract-calendar`._ _Class: KV._
- **Terms Benchmark** (`PaymentTermsBenchmark`) — inputs: supplier, category, credit days they give, annual spend → per-category avg credit days; gap = creditDays − catAvg; working-capital upside = Σ(|gap|·annualSpend/365) over below-peer suppliers; sorted asc by gap → table (their terms / cat avg / gap / verdict Push-for-more vs At/above-peers) + stats (suppliers / below-peer count / WC upside). _Persist: KV `sup-terms-benchmark`._ _Class: KV._
- **Risk Spread** (`RiskDiversification`) — inputs: supplier, region/country, annual spend, single-source checkbox → region HHI = Σ(regionShare²) (0–1), top-region share %, single-source count; concentrated when top-region ≥50% or HHI ≥0.5 (warning banner) → spend-by-region bars + supplier table + stats (top region share / region HHI / single-source count). _Persist: KV `sup-risk-diversification`._ _Class: KV._
- **EOQ Check** (`EoqCheck`) — inputs: item, annual demand, cost per order, unit cost, holding cost % p.a. (default 20), supplier MOQ → EOQ = √(2·D·S/H) with H = unitCost·holding%; order qty = max(EOQ, MOQ); orders/yr = demand/orderQty; annual cost = (D/q)·S + (q/2)·H; flags MOQ-bound (MOQ>EOQ) vs Optimal → table + stats (items / MOQ-above-EOQ count / total annual cost). _Persist: KV `sup-eoq-check`._ _Class: KV._

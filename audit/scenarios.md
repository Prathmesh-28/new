# Scenario Planning (`/scenarios`) — 21 tools

A tabbed "what-if" workbench that models hiring, pricing, funding, FX, cost and demand shocks against the SMB's live ledger and a Monte-Carlo cash forecast. Stakeholders: owner, finance. Backend: KV-synced (reads the shared `store` — transactions/invoices — via `AppContext`; no scenario state is persisted, all inputs are component-local React state).

Tab array (`ScenarioTab`, 21 entries): planner, price-sim, headcount, dilution, breakeven, revenue-shock, cost-cut, product-launch, supplier-hike, payment-terms, marketing-roi, capex, debt-vs-equity, client-loss, salary-hike, inventory-buildup, fx-shock, automation-roi, churn-impact, capacity-expansion, cost-inflation. Each renders exactly one tool component below.

- **Cash Planner** (`planner`, default tab) — preset/custom events (revenue, expense, hire, loan, deal; signed monthly impact, start month, duration) + 4 quick presets (Hire 2, Land ₹20L deal, Take ₹10L loan, Lose top client) → events mapped to forecast-engine `Scenario[]` (custom recurring monthly amount, start date = today + startMonth×30d, duration = months×30d) → both base and scenario run through the REAL `runForecast` Monte-Carlo engine (`store`, horizon 180d, 600 sims, pinned seed 1337 so base vs scenario differ only by the scenario delta) → 6-month P50 base vs P50 scenario area chart with P10 downside line, runway P50 (base/scenario), 6-month ending cash, scenario difference, viability/cash-crunch verdict; copy-to-clipboard share summary + "see credit options" deep-link to `/credit`. _Persist: none (events are local state; forecast reads KV store)._ _Class: Backend (Monte-Carlo forecast engine over live ledger)._
- **Price-Change Profit Simulator** (`price-sim`) — price/unit, cost/unit, current units, price-change %, elasticity (|%vol/%price|) → new price = p×(1+chg); volume factor = max(0, 1−chg×e); contribution profit before vs after = (price−cost)×units; revenue, margin %, profit-change table → before/after comparison + verdict on whether the price move lifts or cuts contribution profit. _Persist: none (local state)._ _Class: Indicative (linear-elasticity assumption, fixed costs held constant)._
- **Headcount / Hiring Scenario** (`headcount`) — cash on hand (auto from ledger sum), # hires, avg salary/mo, employer load %, added revenue/mo → fully-loaded per hire = salary×(1+load); new monthly cost; base burn vs scenario burn = (cost+newCost)−(rev+addRev); runway = cash÷burn → added cost, burn before/after, runway after, before/after table + 6-month-safety-line verdict. _Persist: none (cash/rev/cost derived live from `store.transactions`, last-90d annualised)._ _Class: Backend (live ledger) + Indicative (straight-line burn)._
- **Funding-Round Dilution** (`dilution`) — pre-money (₹Cr), amount raised (₹Cr), post-round ESOP %, founder % before → post = pre+raise; investor % = raise÷post; ESOP top-up created pre-money (dilutes existing holders); founder after = (1−investorPct)×founderPre − esop; founder dilution in pts → post-money, investor stake, founder after, dilution + post-round cap-table bar (founders/investor/ESOP/other). _Persist: none (local state)._ _Class: Indicative (single-round, single-class, % ownership; no liquidation prefs/waterfall — defers to Cap-Table tools)._
- **Break-even & Margin of Safety** (`breakeven`) — fixed cost/mo, price/unit, variable cost/unit, actual/expected units → contribution = P−V; BE units = ⌈F÷contribution⌉; BE revenue = F÷contribution%; margin of safety units/revenue/% vs actual; profit at actual = A×contribution−F → BE units, BE revenue, margin of safety %, profit at actual + CVP table and above/below-BE verdict. _Persist: none (local state)._ _Class: Indicative (single-product CVP)._
- **Revenue-Shock / Recession Stress Test** (`revenue-shock`) — cash, monthly revenue, monthly cost (all auto from ledger), revenue drop %, variable-cost share %, safe-runway months → shocked rev = rev×(1−drop); variable cost shrinks with revenue, fixed cost held; shock burn & runway; cost-cut needed = max(0, shockedCost − (shockedRev + cash÷safety)) → revenue after shock, burn, runway, cost-cut-to-survive + normal vs shocked table and survival verdict. _Persist: none (live `useLiveMonthly()` from `store.transactions`; inputs local)._ _Class: Backend (live ledger) + Indicative (first-order linear cost flex)._
- **Cost-Cut Savings Simulator** (`cost-cut`) — cash, monthly cost, monthly revenue (auto from ledger) + checklist of 6 SMB levers each sized as % of current cost with pain rank (SaaS 4%, travel 6%, marketing 12%, contractors 10%, rent 9%, payroll 18%) → toggled savings summed; new cost, new burn, new runway = cash÷burn; runway gain vs base → monthly/annual savings, new cost, runway after cuts + savings verdict. _Persist: none (live ledger; toggles + inputs local)._ _Class: Backend (live ledger) + Indicative (lever percentages are illustrative)._
- **New-Product-Launch Model** (`product-launch`) — upfront launch cost, peak monthly revenue, contribution margin %, months-to-ramp, cannibalization %, horizon (capped 36) → S-curve ramp frac = 1−e^(−2.2t/ramp); per-month net contribution = revenue×margin×(1−cann); cumulative cash from −upfront → payback month, cumulative cash at horizon, total contribution, peak monthly margin + cumulative-cash area chart (crosses zero at payback) and profitability verdict. _Persist: none (local state)._ _Class: Indicative (S-curve + cannibalization assumptions; fixed overheads not re-charged)._
- **Supplier Price-Rise Impact** (`supplier-hike`) — selling price/unit, affected input cost/unit, other variable cost/unit, supplier rise %, monthly units → new input = IC×(1+rise); margin hit/unit = IC×rise; annual profit hit = hit×Q×12; pass-through price = P + hit (restores rupee margin), pass-through % → new input cost, margin hit/unit, annual profit hit, pass-through price + before/after table and absorb-vs-pass verdict. _Persist: none (local state)._ _Class: Indicative (only affected input rises; demand held at higher price)._
- **Payment-Terms Cash Impact** (`payment-terms`) — monthly revenue, monthly cost (auto), DSO now/new, DPO now/new, working-capital interest % → daily rev/cost = annual÷365; cash from faster DSO = ΔDSO×dailyRev; cash from slower DPO = ΔDPO×dailyCost; cash freed = sum; interest saved = freed×rate; cash-conversion cycle = DSO−DPO → cash from DSO, cash from DPO, total cash freed, annual interest saved + CCC now-vs-after and direction verdict. _Persist: none (live ledger for rev/cost; days/rate local)._ _Class: Backend (live ledger) + Indicative (one-time balance-sheet shift)._
- **Marketing-Spend ROI Scenario** (`marketing-roi`) — spend, cost-per-lead, lead→customer %, AOV, contribution margin %, extra lifetime orders → leads = S÷CPL; customers = leads×conv; first revenue = customers×AOV; LTV revenue ×(1+repeat); CAC = S÷customers; first-order ROAS; LTV:CAC; net first/LTV profit = margin − spend → customers, CAC, first-order ROAS, LTV:CAC + first-order vs LTV table and three-state profitability verdict. _Persist: none (local state)._ _Class: Indicative (funnel assumptions; no discounting)._
- **Capex: Buy vs Loan vs Lease** (`capex`) — asset cost, life (years), salvage %, loan rate %, lease rent/mo, tax %, depreciation % (WDV) → depreciation tax shield over life (WDV loop); BUY net = A − salvage − deprShield; LOAN net = A + flat interest(A×r×yrs) − interestShield − salvage − deprShield; LEASE net = totalLease − leaseShield → three option cards (lowest-cost highlighted) + component breakdown table (gross cash out, tax shield, salvage, net cost) and recommendation. _Persist: none (local state)._ _Class: Indicative (flat loan interest, no time-value discounting)._
- **Debt-Raise vs Equity-Raise** (`debt-vs-equity`) — capital needed, loan rate %, tenor (years), tax %, pre-money (₹Cr), expected exit (₹Cr) → DEBT: reducing-balance EMI, total interest, interest tax shield, debt net cost = interest − shield; EQUITY: investor % = amount÷post-money, founder kept, equity cost at exit = exit×investorPct → loan EMI/mo, debt net cost, equity given up %, equity cost at exit + term-loan vs equity table and which-is-cheaper verdict (deep-references Funding-Dilution tool). _Persist: none (local state)._ _Class: Indicative (EMI exact; equity "cost" contingent on assumed exit)._
- **Top-Client Loss Impact** (`client-loss`) — lost monthly revenue (auto-suggested = top customer's invoiced share × live monthly revenue), variable-cost share %, cash on hand (auto) → ranks customers by total invoiced (`store.invoices`); top share; margin lost = lostRev×(1−varShare); new rev/cost/burn/runway; replacement customers needed = ⌈top.total ÷ avg of other customers⌉; concentration flag at ≥25% → revenue concentration %, margin lost/mo, runway after loss, customers to replace + now vs after-loss table and concentration-risk verdict. _Persist: none (reads live `store.invoices` + `useLiveMonthly()`; overrides local)._ _Class: Backend (real AR list + live ledger) + Indicative (linear margin/runway)._
- **Salary-Hike Affordability** (`salary-hike`) — current payroll/mo (auto-suggested = 55% of monthly cost), headcount, average hike %, employer load %, cash on hand (auto), contribution margin % → added monthly = payroll×hike×(1+load); added annual; per-head; new burn & runway; revenue lift needed = addedMonthly÷margin and lift % → added cost/mo, added cost/yr, avg per head, runway after hike + before/after table and affordability (6-month line) verdict. _Persist: none (live ledger for cost/cash; hike inputs local)._ _Class: Backend (live ledger) + Indicative (across-the-board hike)._
- **Inventory Build-up Cash Impact** (`inventory-buildup`) — monthly COGS (auto-suggested = 60% of monthly cost), days-inventory now/target, carrying cost %/yr, bulk discount %, cash on hand (auto) → daily COGS = annual÷365; cash locked = ΔDIO×dailyCOGS; carrying cost = locked×carry; bulk saving = COGS×12×disc; net annual = bulkSaving − carrying; cash after; affords-it check (locked ≤ cash) → cash locked, carrying cost/yr, bulk saving/yr, net annual benefit + now vs after-build-up table and three-state verdict (can't afford / pays off / carry exceeds saving). _Persist: none (live ledger for COGS/cash; days/rates local)._ _Class: Backend (live ledger) + Indicative (one-time cash lock + annualised carry/saving)._
- **FX-Rate Shock (Exporters / Importers)** (`fx-shock`) — USD revenue/mo, USD cost/mo, INR per USD now, rate move % (− = ₹ strengthens), contribution margin % → new rate = rate×(1+shock); net USD exposure = rev−cost (natural hedge from USD costs); monthly ₹ swing = net×(newRate−rate); annual swing; margin impact = swing×margin; exposure at risk = |net|×rate → net USD exposure, new rate, monthly/annual ₹ swing + rate-now vs rate-new table and favourable/adverse hedge verdict. _Persist: none (local state)._ _Class: Indicative (single-rate sensitivity; no forward/option premium pricing). [Note: multi-currency money rails are a deferred/non-faked area per memory; this tool is a calculator only.]_
- **Automation-Investment ROI** (`automation-roi`) — upfront cost, recurring cost/mo, hours saved/mo, fully-loaded cost/hour → gross saving = hours×wage; net saving = gross − recurring; payback mo = upfront÷net; annual net; 3-year net = net×36 − upfront; 3-yr ROI % → labour value freed, net saving, payback period, 3-year ROI + 12/24/36-month cumulative cost/saving/net table and worth-it verdict. _Persist: none (local state)._ _Class: Indicative (assumes freed hours convert to real savings)._
- **Churn-Increase Impact** (`churn-impact`) — active customers, revenue/customer/mo (ARPU), current monthly churn %, churn increase (pts) → avg lifetime = 1÷churn; LTV = ARPU÷churn; extra lost/mo = n×Δchurn; MRR after 12mo = ARPU×n×(1−churn)^12; MRR gap = base12 − after12; severe if gap > 10% of MRR → avg lifetime after, LTV after, extra lost/mo, MRR gap by mo 12 + current-vs-higher-churn table and retention-leverage verdict. _Persist: none (local state)._ _Class: Indicative (geometric-decay; no acquisition/discounting)._
- **Capacity-Expansion Model** (`capacity-expansion`) — expansion capex, added units/mo (at full), expected utilisation %, price/unit, variable cost/unit, added fixed cost/mo → real units = units×util; contribution = P−V; added revenue = realUnits×P; added profit = realUnits×contrib − fixed; payback mo = capex÷addProfit; break-even units = fixed÷contrib and break-even utilisation % → added revenue, added profit, payback, break-even utilisation + 50/70/90/100% utilisation sensitivity table (current util highlighted) and worth-it (payback ≤36mo) verdict. _Persist: none (local state)._ _Class: Indicative (steady-state; no ramp-up/financing cost/demand risk)._
- **Cost-Inflation Passthrough** (`cost-inflation`) — price/unit, input cost/unit, cost inflation %, passthrough %, units/mo → new cost = C×(1+infl); cost rise; new price = P + costRise×pass; full passthrough price = P + costRise and full hike %; margins: old, new (partial pass), absorb-fully; profit before vs after = margin×q; protects-margin check (new ≥ old − 0.5% of P) → new price, price hike %, margin after, profit change + four-strategy table (before / absorb fully / pass X% / full passthrough) and margin-protection verdict (references Price-Change Profit tool for elasticity). _Persist: none (local state)._ _Class: Indicative (holds volume constant; variable cost only)._

Count: 21 tools.

## GST & Indirect Tax (`/gst`) — 52 tools

A single GST/indirect-tax workbench for an Indian SMB: compute liability, file-prep returns (GSTR-1/3B/9/9C), reconcile ITC against GSTR-2B, run dozens of section-accurate calculators (RCM, Rule 42/43, Sec 17(5), Rule 89(5), cess, advances, cross-charge, etc.), and track compliance deadlines/exposures. Stakeholders: owner, finance, CA. Backend: `/api/gst` (calendar, returns, liability, verify) + KV-synced via `store.featureData` (the `useFeatureState` hook persists to localStorage, debounce-pushes to backend, and live-syncs across devices) and the live `store` (firm/invoices/transactions).

### Tools

- **GSTR-3B Calculator** (`calculator`) — Server-side liability compute: picks month/year → `GET /api/gst/liability?month&year` returns `output_tax`, `input_tax_credit`, `net_liability`, plus a Table 3.1-style breakdown (taxable turnover, output CGST/SGST, ITC CGST/SGST). "Save as GSTR-3B Draft" does `POST /api/gst/returns {return_type:"GSTR-3B"}` (de-dupes by period) and routes to Returns. Implements the GSTR-3B net-liability identity (output − ITC). _Persist: backend `/api/gst/liability` + `/api/gst/returns`._ _Class: Backend._

- **GST Ledger** (`ledger`) — 12-month electronic-credit-ledger simulation via `gstLedger(store, rate, 12)`: per month shows taxable sales, output tax, input credit, net, ITC carry-forward, cash payable; surplus months (input>output) accumulate ITC c/f that offsets later cash — mirrors the portal's credit-ledger carry-forward. Summary strip totals output/input/cash/carry. Rate from `firm.gstRate ?? 18`. _Persist: live store (derived from `store` transactions/invoices)._ _Class: Indicative._

- **GSTR-1 — Outward Supplies** (`gstr1`) — Builds B2C/B2B outward summary from `store.invoices` filtered to selected month: per invoice taxable = amount, CGST = SGST = round(taxable × (rate/2))/100, total = taxable+CGST+SGST. KPIs (invoice count, taxable turnover, output CGST+SGST, gross). CSV export (`GSTR1-<Mon>-<Yr>.csv`). Splits the firm rate into equal CGST/SGST halves; IGST/HSN B2B-B2C splits flagged as needing GSP. _Persist: live store (`store.invoices`)._ _Class: Indicative._

- **Returns** (`returns`) — Read-only register of computed returns from `GET /api/gst/returns` (loaded on mount): period, type, output tax, ITC, net liability, status (filed/draft chip), GSTN ARN. Populated by the Calculator's save action. _Persist: backend `/api/gst/returns`._ _Class: Backend._

- **GSTR-2B Reconciliation / 2B Match** (`match`) — Upload GSTR-2B JSON (`parse2BJson`) + purchase register xlsx/csv (`parseRegisterRows`), then `reconcile(reg, 2B)` matches by GSTIN+invoice. Summary: ITC at risk (not in 2B), mismatched tax, available-unclaimed (only in 2B), matched ITC. Line table with status meta (missing_in_2b / mismatch / missing_in_books / matched), capped at 200 rows on screen; full CSV export (`gstr2b-reconciliation.csv`). Implements Rule 36(4) 2B-match gating. _Persist: none (in-memory uploads; recon state held in component)._ _Class: Backend (client-side compute on user-uploaded portal files)._

- **Calendar** (`calendar`) — Due-date list from `GET /api/gst/calendar`: each row label + due date + penalty note; computes days-left, color-codes urgent (≤7d) / soon (≤30d) / overdue ("Nd late"). _Persist: backend `/api/gst/calendar`._ _Class: Backend._

- **E-Way Bill Estimator** (`eway`) — Inputs invoice value, distance, ODC flag, exempt/cancelled flag. Rule: required iff value > ₹50,000 and not exempt; validity = max(1, ceil(distance / (ODC ? 20 : 200) km/day)); expiry = today + validity days (date-fns). Shows required Yes/No, validity, expiry, formula. Implements e-way-bill ₹50,000 threshold + 200 km/day (20 km ODC) validity rule. _Persist: none (transient useState)._ _Class: Indicative._

- **RCM Register** (`rcm`) — Reverse-charge tracker. Quick-fill chips for 10 notified RCM categories (legal/advocate 18%, GTA 5%, sponsorship, security, rent-a-cab/motor-vehicle 5%, OIDAR import 18%, director services, unregistered-dealer, insurance agent, works-contract 12%). Add entry → RCM tax = round(amount × rate/100); ITC claimable = same amount (same-month credit for business use). Register table + CSV (`RCM_Register.csv`), totals for tax and ITC. Implements RCM (Sec 9(3)/9(4)) self-liability + matching ITC. _Persist: none (rcmEntries on useState; not useFeatureState)._ _Class: Indicative._

- **HSN / SAC Code Lookup** (`hsn`) — Static 47-row HSN/SAC table (goods + services) with standard rates (0/3/5/12/18/28); search by code or description; rate chips colour-coded; labels HSN vs SAC. Reference only — flags concessional/exempt/state notifications as needing portal verification. _Persist: none (search term on useState; data is a const)._ _Class: Indicative._

- **Verify GSTIN** (`verify`) — Validates a 15-char GSTIN via `GET /api/gst/verify?gstin=`; returns valid flag, state, state code, PAN, source. When `source === "format"` it explicitly discloses it only checked structure + check digit offline (no live trade-name/active status), never fabricating data. Keeps a recent-verifications history (last 10) with re-verify; "why verify" ITC-risk guidance. Implements GSTIN structure/check-digit validation. _Persist: none (result + history on useState)._ _Class: Backend (offline format check; live status deferred)._

- **ITC Optimizer** (`itc`) — From negative (purchase) transactions, groups by month, estimates ITC = round(amount × 0.18/1.18) (assumes 18% inclusive). Ages each month into Current / 1–3 mo / >3 mo / Lapsed(>2yr) buckets; flags "urgent" (>3 mo) and lapsed ITC. Implements Sec 16(4) 2-year ITC-claim time limit. Includes a Sec 17(5) blocked vs eligible quick-reference. _Persist: live store (`store.transactions`)._ _Class: Indicative._

- **GSTR-9 Annual Return Builder** (`gstr9`) — Aggregates current-FY (Apr–Mar) transactions: outward taxable (positive txns), output tax @18%, inward purchase, ITC = round(inward × 0.18/1.18), net payable / excess credit. Part II Table 4 + Part III Table 6/7 cards, net-position banner, monthly breakdown, CSV export (`GSTR9-FY..`). Notes Dec-31 due date and ₹5cr → 9C audit trigger. Implements GSTR-9 table structure (4A/4B/9, 6B/6C/7). _Persist: live store (`store.transactions`)._ _Class: Indicative._

- **LUT Tracker** (`lut`) — Letter of Undertaking (Form GST RFD-11) register: ref no, FY, filed date, export type (goods/services/both); auto-derives active/expired by FY-end (Mar 31). Shows active-LUT banner, days-to-expiry, ≤45-day renewal warning, LUT-vs-Bond-vs-IGST guidance. Implements RFD-11 annual-FY LUT validity for zero-rated exports without IGST. _Persist: `useFeatureState("lut-register")`._ _Class: KV._

- **GST Refund Tracker** (`refund`) — Refund-claim register (auto ref `RFD-#####`): type (Export-LUT / Inverted Duty / Excess Cash Ledger / IGST on Export / Deemed Export / Other), period, amount, status workflow (Draft→Filed→Acknowledged→Processing→Approved→Credited / Deficiency / Rejected), filed date, notes. Totals claimed/credited/in-progress. Rule 91/92 timeline reference (RFD-02 ≤15d ack, 7-day 90% provisional for exports, RFD-06 final 60d + interest). _Persist: `useFeatureState("gst-refunds")`._ _Class: KV._

- **Composition Scheme Checker** (`composition`) — Eligibility: annualised revenue (auto from txns or manual) vs ₹1.5cr cap. Three rate cards (Manufacturer/Trader 1%, Restaurant 5%, Service-provider CSCS 6% capped ₹50L). Estimates saving = turnover×18% − turnover×1%. Pros/cons + Sec 10 notes (no ITC, no inter-state, CMP-02 opt-in, excluded goods). Implements Sec 10 composition thresholds/rates. _Persist: none (useState only)._ _Class: Indicative._

- **QRMP Suitability** (`qrmp`) — Checks annualised turnover vs ₹5cr QRMP cap; compares monthly filing (24/yr, GSTR-1 by 11th, 3B by 20th) vs QRMP (~13/yr: IFF 13th M2, PMT-06 25th M1/M2, GSTR-3B 22nd/24th M3). - **TDS under GST (Sec 51)** (`tdsgst`) — Tracks GST-TDS deducted by govt/PSU deductors: contract value × 2% (1% CGST + 1% SGST / 2% IGST); toggle credited-in-2B vs pending; totals deducted/pending. - **GST Notice Reply Templates** (`notice`) — 4 fill-in templates (SCN GSTR-1 vs 3B mismatch — Sec 61/Rule 99; non-filing of 3B — Sec 46/122; Sec 73 short-payment demand; excess-ITC/blocked-credit — Sec 16(2)/Rule 36) that interpolate GSTIN/period/amount; copy-to-clipboard. - **GSTR-3B Auto-Prep** (`gstr3b-prep`) — From selected month's transactions: outward gross (revenue) → taxable = round(gross/(1+rate)), output tax = gross−taxable; inward gross (expense) → ITC similarly; net cash = max(0, output−ITC), ITC carry = max(0, ITC−output). - **Multi-GSTIN Consolidator** (`multi-gstin`) — Register per-state GSTIN (auto-state from first 2 digits), output tax, ITC, cash ledger; net payable per unit = max(0, output−ITC−cash); totals across registrations.

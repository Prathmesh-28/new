# Privacy & Consent (`/privacy`) — 32 tools

A single control centre for DEPA/Account-Aggregator consents, DPDP Act 2023 compliance, data-rights tracking and breach response. Stakeholders: owner, CA, admin. Backend: `/consent` partial + KV (all 32 tabs persist via `useFeatureState` browser KV keyed `priv-*`; no server writes — Overview note points backend consent toggles / export / deletion to Settings → Privacy & Data).

- **Overview** — reads all `priv-*` KV stores (aa, dpdp, dsr, shares, breaches, hygiene) → derives 4 cards (active AA consents, DPDP consents logged + live, open DSRs, hygiene-weighted DPDP readiness %) and dynamic red/yellow alert banners (unnotified reportable breaches, AA consents expiring ≤30d, unsigned DPAs, open DSRs) with jump-to-tab links + static obligations panel → dashboard. _Persist: reads live KV stores (no own key)._ _Class: KV (read-only aggregation)._
- **AA Consent Register** — FIP, Account Aggregator, purpose, scope, validity months → records DEPA consent (status active, expiry = today + months×30); `useMemo` reconciles active→expired against live clock without mutating storage; revoke / re-grant / delete → register table. _Persist: `priv-aa-consents`._ _Class: KV._
- **DPDP Consent Log** — data subject, purpose, collection channel (select) → logs grant (granted=true) with collected-on date; mark-withdrawn sets withdrawnOn; counts total/granted/withdrawn → defensible consent register. _Persist: `priv-dpdp-log`._ _Class: KV._
- **Permissions Matrix** — party/app name → adds row with per-category access toggles (bank, gst, pan, invoices, payroll) for data-minimisation review → field-level access grid. _Persist: `priv-perms`._ _Class: KV._
- **Access / Erasure (Data-Rights Tracker)** — subject, request type (access/erasure/correction/portability), note → logs DSR with 30-day SLA clock; computes days-due vs raisedOn+30; status dropdown (open/in_progress/fulfilled/rejected); delete → request tracker with overdue flags. _Persist: `priv-dsr`._ _Class: KV._
- **Retention Policy** — category, retain years, legal/business basis → adds retention rule (seeded with 4 statutory defaults: books 8y, GST 6y, marketing 2y, logs 1y) → retention table ("Until purpose ends" if 0y). _Persist: `priv-retention` (default-seeded)._ _Class: KV._
- **Sharing Registry (Third-Party)** — recipient, data shared, purpose, DPA-signed checkbox → registers processor with shared-on date; toggle DPA signed/missing; counts + warns on unsigned DPAs → recipient registry. _Persist: `priv-shares`._ _Class: KV._
- **Consent Expiry (Calendar)** — reads AA register live → filters active/expired, computes days-to-expiry, sorts ascending → expiry timeline with past/urgent(≤7d)/soon(≤30d) colour pills. _Persist: reads `priv-aa-consents` (none own)._ _Class: KV (read-only)._
- **Privacy Hygiene** — 10 weighted DPDP-control checkboxes (high/medium/low) → toggles; computes done count + readiness % (feeds Overview) → checklist with progress bar. _Persist: `priv-hygiene`._ _Class: KV._
- **Data Inventory (Personal-Data Map)** — element, sensitivity (low/med/high), location, purpose → catalogues data asset (seeded 3 defaults); also surfaces live store counts (transactions/invoices/orders) + high-sensitivity count → inventory table. _Persist: `priv-inventory` (default-seeded); live counts from AppContext store._ _Class: KV + Backend (live store reads)._
- **Breach Log** — description, records affected, severity (low/med/high) → logs incident; toggle DPB-notified / subjects-notified; sums affected + indicative exposure (high-severity records × ₹5,000 hardcoded) + pending-DPB count → notification register. _Persist: `priv-breaches`._ _Class: KV (exposure = Indicative)._
- **Policy Generator** — firm name, email, officer + email, purposes, third-parties, retention statement → `buildPolicy()` assembles 8-section plain-English DPDP privacy notice; copy-to-clipboard → generated notice text. _Persist: `priv-policy-firm`._ _Class: KV._
- **Cookie Consent (Configurator)** — toggle analytics/marketing/preferences (necessary locked on), banner text, reject-all + granular checkboxes → builds banner config JSON; compliance check (rejectAll && granular); copy JSON → developer config + preview. _Persist: `priv-cookie-cfg`._ _Class: KV._
- **DPA Checklist** — vendor name + 11 DPA-clause checkboxes → toggles; computes coverage %; reset for next vendor → checklist with score. _Persist: `priv-dpa-checklist` (vendor name local-state only)._ _Class: KV._
- **Grievance Officer (Register)** — officer name/email/phone + per-grievance complainant/subject → logs grievance with 30-day SLA; status dropdown (open/in_progress/resolved); flags overdue → officer record + grievance register. _Persist: `priv-grievance-officer` + `priv-grievances`._ _Class: KV._
- **Consent Rate (Dashboard)** — reads DPDP log live → computes active-consent rate, totals, live/withdrawn, and per-channel rate breakdown → KPI cards + per-channel bars. _Persist: reads `priv-dpdp-log` (none own)._ _Class: KV (read-only)._
- **Classification (Matrix)** — element + tier (public/internal/confidential/sensitive) → classifies (auto-fills required-handling text from CLASS_HANDLING map; seeded 4 defaults); inline tier dropdown re-derives handling → classification table. _Persist: `priv-classification` (default-seeded)._ _Class: KV._
- **Staff Training (Log)** — employee, role, valid months → records training (expiry = trainedOn + months×30); renew resets date; counts trained/valid/needs-refresh → training register with valid/expired status. _Persist: `priv-training`._ _Class: KV._
- **Penalty Estimator** — toggle 5 DPDP penalty-schedule gaps (statutory caps ₹50cr–₹250cr) + likelihood % → sums headline max exposure and likelihood-weighted exposure → two exposure cards. _Persist: `priv-penalty-gaps` (likelihood local-state)._ _Class: KV (figures Indicative)._
- **Localization (Checklist)** — 8 data-localisation checkboxes → toggles; computes confirmed % → checklist with progress bar. _Persist: `priv-localization`._ _Class: KV._
- **Marketing Opt-in (Consent Register)** — contact, channel (Email/SMS/WhatsApp/Phone/Push), opted-in checkbox → records preference with updated-on; toggle opt-in/out (re-stamps date); counts in/out → marketing register. _Persist: `priv-marketing-consent`._ _Class: KV._
- **SAR SLA Timer** — reads DSR store live → filters open/in_progress, computes days vs raisedOn+30, sorts → KPI cards (open/due-in-7d/overdue) + per-request countdown bars with progress %. _Persist: reads `priv-dsr` (none own)._ _Class: KV (read-only)._
- **RoPA Register** — activity, data categories, subjects, lawful basis (select), recipients, retention → records processing activity; CSV export (RFC-escaped, downloaded as `ropa-<date>.csv`) → RoPA table. _Persist: `priv-ropa`._ _Class: KV._
- **Data-Flow Map** — source, target, leg type (internal/processor/external), data carried, encrypted checkbox → maps a data hop; warns on unencrypted external flows → flow list with kind/encryption pills. _Persist: `priv-dataflow`._ _Class: KV._
- **Consent Receipt (Generator)** — subject, purpose, data items, lawful basis (select) → generates timestamped consent receipt (ID `CR-<base36>`, fiduciary from live store firm name) listing DPDP rights; copy + download `.txt` → receipt preview. _Persist: none (in-memory `useState`; firm name from AppContext store)._ _Class: Backend (firm read) + Preview (no record kept)._
- **DPIA Wizard** — project name + 8 weighted screening questions → computes weighted score/14 and risk band (≥8 high / ≥4 medium / else low); save outcome to register; delete → screening tool + saved-outcomes register. _Persist: `priv-dpia` (answers + project local-state until saved)._ _Class: KV._
- **Cross-Border Log** — overseas recipient, country, data, safeguard (SCCs/intra-group/consent/none) → logs transfer with logged-on; warns on unsafeguarded ("None / under review") transfers → cross-border register. _Persist: `priv-xborder`._ _Class: KV._
- **Vendor Risk (Scorecard)** — vendor name + 6 per-vendor control checkboxes (DPA, localisation, ISO/SOC2, deletion/export, no recent breach, least-access) → scores each vendor x/6 → % and risk band (≥5 low / ≥3 medium / else high) → per-vendor scorecards. _Persist: `priv-vendor-risk`._ _Class: KV._
- **Withdrawal Handler** — reads DPDP log (live grants) + sharing registry → "Process withdrawal" flips the consent-log entry (granted=false, withdrawnOn) AND auto-generates one notify-task per registry processor; tick tasks done → withdrawal action + downstream propagation checklist. _Persist: writes `priv-dpdp-log`, reads `priv-shares`, writes `priv-withdraw-tasks`._ _Class: KV._
- **Breach Triage** — records-affected estimate + 4 factor toggles (sensitive, financial, identifiable, contained) → computes severity score/8 (record-volume tiers + factor weights, contained subtracts) → severity band (≥5 high / ≥3 medium / else low) + notification-duty advice. _Persist: none (all `useState`)._ _Class: Indicative (advisory; advises logging in Breach Log)._
- **Purge Scheduler** — category (datalist from retention policy), last-touched date → schedules purge (years pulled from matching retention rule); mark-purged; computes due-date (lastDataDate + years×365) and status (overdue/due-soon/within-retention/purged) → purge schedule table. _Persist: `priv-purge`, reads `priv-retention`._ _Class: KV._
- **Lawful Basis (Advisor)** — pick scenario (6 hardcoded: marketing/order/employment/legal/list-sharing/minor) → maps to recommended basis + tone (green/yellow/red) + note; copy basis note for RoPA (uses live firm name) → advisory card. _Persist: none (`useState`; firm name from AppContext store)._ _Class: Indicative (static decision aid)._

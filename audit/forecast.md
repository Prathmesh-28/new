## Cash-Flow Forecast (`/forecast`) — 24 tools

Cash-flow planning workspace: a probabilistic 90-day projection plus 23 specialised forecasting/planning tools (run-rate, AR/AP timing, seasonality, capex, GST, runway) for an Indian SMB. Stakeholders: owner, finance, CA. Backend: deterministic client-side `forecastEngine` (Monte-Carlo, unit-tested) + `finance.ts` aggregates; durable records via the synced `store.featureData` KV bag (localStorage + backend sync).

- **Probabilistic Forecast (main tab / `runForecast` + `generateForecast`)** — store (transactions, bank balances, active scenarios) + slow-month slider (0–100% revenue) + burn-inflation slider (80–150%) → Monte-Carlo engine produces P10/P50/P90 paths with scenarios + revenue/burn factors baked into both bands; derives risk strip (breach probability, expected time-to-pressure, Cash-Flow-at-Risk 95%, likely runway P50/P10), a 45-day-early pressure alert, and an obligation-marker overlay. "Generate" persists the BASE (no-scenario) forecast for the dashboard; the page chart recomputes live. _Persist: `store.forecast` (KV, base only) + `slowPct`/`burnFactor` live UI state._ _Class: Backend._
- **Scenarios manager** — name, type (new_hire / contract_won / loan_draw / custom), amount, start date → stored scenario list; active scenarios fold into the Monte-Carlo forecast and the Best/Base/Worst tool. Toggle active / delete. _Persist: `store.scenarios` (live store)._ _Class: Backend._
- **Cash Obligations manager** — name, amount, due date → obligation list rendered as red reference lines on the main chart and scheduled into 13-week / AR-AP tools. Auto-adds a `GSTR-3B` tax obligation (last-month revenue × firm GST rate, due 20th) on forecast generation if GST-registered. _Persist: `store.obligations` (live store)._ _Class: Backend._
- **Ask AI (forecast insight)** — current balance, monthly burn, P10 runway, active scenario → POST `/api/ai/ask` with a cash-advisor system prompt → 3–4 sentence explanation + 2 suggestions; falls back to a "check ANTHROPIC_API_KEY" message on error. _Persist: none._ _Class: Backend (LLM)._
- **Remind me (obligations)** — upcoming obligations → schedules on-device notifications 1 day before each due date via `scheduleReminders` (native only); cancels prior IDs first. _Persist: OS notification store (device)._ _Class: Backend (native)._
- **Notify me (overdue invoices)** — invoices marked overdue or past due date → schedules immediate on-device reminders per invoice (native only). _Persist: OS notification store (device)._ _Class: Backend (native)._
- **13-Week Rolling Cash Forecast (#76)** — bank opening balance + trailing-90-day variable run-rate (weekly base in/out, transfers excluded) + open invoices (collected the week their due-date falls in, overdue→week 0) + dated obligations + active-loan EMIs (every ~4 weeks from next payment date) → 13 weekly rows of inflow/outflow/net/closing, totals, lowest weekly close, and a safety threshold = firm `safetyThresholdDays` × daily burn; rows breaching the buffer are flagged red. _Persist: none (live recompute)._ _Class: Indicative._
- **Receivables-Driven Inflow Projection (#77)** — open invoices: each invoice's expected collection date (due-date + slip; healthy 7d, overdue 7 + 0.3×daysOverdue capped 45d) × pay-probability (current 92%; overdue logistic decay 0.85 − daysOverdue/250, floor 20%) → expected-value rows bucketed by month, gross vs probability-weighted chart, gross/expected/at-risk totals. Empty state if no open invoices. _Persist: none._ _Class: Indicative._
- **Seasonality Detector (#78)** — transaction history (transfers excluded) grouped by calendar month → per-month revenue/expense indexed to the average of active months (=100), peak/trough revenue month, seasonality strength from coefficient-of-variation (Strong >0.35 / Moderate >0.15 / Weak). Needs ≥3 distinct active months. _Persist: none._ _Class: Indicative._
- **Best / Base / Worst Projection (#79)** — active scenarios + optimism slider (5–40%) + pessimism slider (5–50%) → re-runs `runForecast` three times (best: +optimism revenue / leaner burn; base: 1×/1×; worst: −pessimism revenue, floor 0.4× / +pessimism burn), plots P50 of each over 90 days, with ending-cash + runway per line. _Persist: none (live UI sliders)._ _Class: Backend._
- **Cash Buffer / Minimum-Balance Alert (#80)** — base `runForecast` result + user-set floor (defaults to engine `thresholdCash` ≈ 14-day burn, rounded ₹1L) → first day P10 and P50 paths dip below the floor, worst-case low, breach risk %; green/red verdict and floor-overlay chart. _Persist: `forecast-min-balance-floor` (KV)._ _Class: Backend._
- **Revenue Forecast (#81)** — trailing-3-month average revenue run-rate × monthly growth (seeded from firm CMGR via `cmgr`, clamped −10..20, overridable −10..20%) over a 3–24 month horizon → projected monthly revenue line (actual vs projected) and horizon total. _Persist: `fc-rev-growth-pct` (KV); horizon live UI._ _Class: Indicative._
- **Expense Forecast (#82)** — trailing-6-month average outflow per category (expense / payroll / tax / loan; transfers & inflows excluded) × single annual-inflation dial (0–20%) compounded across a 3–24 month horizon → per-category base table + projected monthly total expense, horizon total. _Persist: none (inflation & horizon live UI)._ _Class: Indicative._
- **Headcount-Cost Forecast (#83)** — current payroll run-rate (trailing-3-month payroll average) + planned-role roster (title, monthly cost, count, start month) → 12-month people-cost ramp (each role adds from its start month), fully-loaded month-12 cost, planned-hire count. _Persist: `fc-planned-roles` (KV); add-form fields live UI._ _Class: Indicative._
- **Burn-Rate & Zero-Cash Date (#84)** — trailing-6-month average net (negated → burn) × burn-change dial (−50..+50%) against current bank cash → months of runway, straight-line zero-cash date, cash-depletion chart (≤18 months); red alert if runway <6 months. _Persist: none (burn-adj live UI)._ _Class: Indicative._
- **Monthly Cash-Bridge Waterfall (#85)** — direct-method `monthlyCashFlow` ledger for a chosen month (slider over last 6) → waterfall: opening → receipts → suppliers → payroll → taxes → financing → closing, plus opening/operating-net/financing-net/closing stat cards. Empty state if no cash-flow data. _Persist: none (month-index live UI)._ _Class: Backend._
- **AR / AP Timing Forecast (#86)** — open invoices (by due-week) vs obligations + active-loan EMIs (every ~4 weeks) over 13 weeks → weekly receivables/payables/net, totals, count of "tight" weeks (AP > AR); paired bar chart + table with negative-net weeks flagged red. _Persist: none._ _Class: Indicative._
- **Fixed vs Variable Cost Projection (#87)** — trailing-6-month outflows split into fixed (payroll / loan / tax / `isRecurring`) vs variable, variable scaled by an activity dial (40–160%) → 12-month stacked fixed/variable chart, total/month, fixed-share % with high-operating-leverage flag (>70%). _Persist: none (activity live UI)._ _Class: Indicative._
- **Break-Even Cash Date (#88)** — trailing average revenue/expense + monthly revenue-growth assumption (−5..15%) → 24-month monthly-net + cumulative-cash projection, pinpointing the month net first turns positive; "already positive" / "24+ months" edge cases with a red warning if never reached. _Persist: none (growth live UI)._ _Class: Indicative._
- **Rolling 12-Month P&L Forecast (#89)** — trailing-3-month revenue/expense run-rates grown by separate revenue (CMGR-seeded, overridable −10..20%) and expense (−5..10%) dials → 12-month revenue/expense/net/cumulative table + chart, 12-mo totals and net margin. _Persist: none (both growth dials live UI)._ _Class: Indicative._
- **Capex / Funding Plan (#90)** — capex items (name, amount, month 1–12, loan-funded %) + trailing-6-month net run-rate against current cash → 12-month cash projection net of self-funded outlays, lowest projected cash, cash-safest month, below-zero breach warning. _Persist: `fc-capex-items` (KV); add-form fields live UI._ _Class: Indicative._
- **Owner Draw / Dividend Planner (#91)** — trailing-6-month net run-rate × draw-% dial (0–100%, never drawn from a loss) against current cash, keeping a `safetyThresholdDays`×daily-burn reserve floor → safe monthly/annual draw, 12-month buffer projection, red/green verdict on whether the draw erodes the floor. _Persist: `fc-owner-draw-pct` (KV)._ _Class: Indicative._
- **Credit-Sale Aging Forecast (#92)** — open invoices bucketed by days overdue (Current / 1–30 / 31–60 / 61–90 / 90+) × bucket collection-probability curve (92% → 80 → 60 → 42 → 25%) → gross vs expected per bucket, total/overdue outstanding, expected-to-collect. Empty state if no open credit sales. _Persist: none._ _Class: Indicative._
- **Forecast Accuracy Tracker (#93)** — walk-forward back-test: predict each month's revenue as its trailing-3-month average vs actual → MAPE, bias (over/under-forecast), 0–100 accuracy score with A–D grade, predicted-vs-actual chart + per-month error table. Needs ≥2 testable months. _Persist: none._ _Class: Backend._
- **Product / Service Mix Forecast (#94)** — product lines (name, units/month, unit price, MoM unit growth −20..30%) → bottom-up 12-month revenue projection (units compounded by growth × price), month-1 + 12-mo revenue, top-line concentration % with >60% red flag. _Persist: `fc-products` (KV); add-form fields live UI._ _Class: Indicative._
- **Weekly Cash Calendar** — opening-cash input + recurring expense run-rate (÷4.3 → weekly out) vs invoices due each week over 8 weeks → running balance, lowest weekly balance, weeks-in-deficit, 8-week net swing; balance chart + per-week breakdown. _Persist: `fc-weekly-opening-cash` (KV)._ _Class: Indicative._
- **Vendor Payment-Timing Forecast** — scheduled vendor payments (vendor, amount, due-in-days 0–180) → 6-month outflow profile bucketed by due month, total committed, heaviest payment month; monthly outflow bar chart. _Persist: `fc-vendor-payments` (KV); add-form fields live UI._ _Class: Indicative._
- **GST Payment Forecast** — trailing-6-month average revenue × firm GST rate (default 18%) × revenue-growth dial (−10..20%) → 6-month projected monthly GST outflow (due 20th), next-month GST, 6-month total. Gated: "not GST registered" empty state unless `firm.gstRegistered`. _Persist: `fc-gst-rev-growth` (KV)._ _Class: Indicative._
- **Runway with Pipeline** — trailing-6-month burn (avgExp − avgRev) against current cash + pipeline deals (name, value, win %) → risk-weighted inflow (value × win%) layered in to extend base runway; cash, burn, base runway vs with-pipeline runway, weighted uplift. _Persist: `fc-pipeline-deals` (KV); add-form fields live UI._ _Class: Indicative._

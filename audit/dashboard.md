# Dashboard (`/dashboard`) — 31 tools/widgets

One-sentence purpose: the home screen — a single-scroll stack of cash-flow, P&L, receivables, alerts and goal widgets, each computed live from the shared store. Stakeholders: all. Backend: KV-synced (reads live store via `useApp()`; durable picks/goals persist via `useFeatureState`; treasury banner is the only HTTP-backed widget).

> Layout note: this page is one vertical scroll of cards (not tabs). The four StatCards, the eight quick-action tiles and the breach banner are header chrome above the widget stack. Many widgets render `null` when their underlying data is empty.

Bullet per widget/tool:

- **Forecast breach warning banner** — top-of-page red banner: runs `runForecast(store).risk` (Monte-Carlo) memoised on the store; shows only when `probBreachByDay[min(44,len-1)] ≥ 0.5`; displays `probBreach%`, expected days-to-breach, P10 worst-case runway; click → `/forecast`. _Persist: none._ _Class: Backend (compute) / derived from KV store._
- **Header actions (Add Account / Import CSV / Add Transaction)** — three buttons; Add Account always shown, Import + Add Transaction only when `bankAccounts.length > 0`; all disabled in `isReadOnly` (client view). Open the respective modals. _Persist: writes to live store on submit._ _Class: Backend._
- **Onboarding wizard** — 4-step checklist (add bank account, import 3+ transactions, generate forecast, run credit pre-qual) with progress bar; `done` computed from store counts; dismissible. Shows hint card at 3/4 done; hidden when all done, dismissed, or read-only. _Persist: `localStorage hr_onboarding_dismissed`._ _Class: KV (steps from store; dismissal local)._
- **Empty state** — dashed-border CTA shown when `bankAccounts.length === 0 && transactions.length === 0`; single "Add Bank Account" button. _Persist: none._ _Class: KV (store-derived gate)._
- **StatCards ×4 (Total Balance / Monthly Burn / Cash Runway / Unread Alerts)** — animated count-up cards: balance = Σ account balances; burn = `monthlyBurn(transactions)`; runway = `runwayDays(...)`; unread = `alerts.filter(!isRead)`. Balance/Burn show MoM delta (rev/burn % vs last month); each click navigates (transactions/forecast/alerts). Note: Total Balance card mislabels delta — it shows `revDelta` (revenue MoM), not a balance delta. _Persist: live store._ _Class: KV._
- **Quick-actions row (8 tiles)** — static deep-link grid: Fin Health, Working Capital, Analytics, CFO Brief, Budgets, Compliance, Receivables, Operations → navigate to respective routes. _Persist: none._ _Class: KV (nav only)._
- **Cash This Week** — 7-day forward bar pairs (expected inflow vs outflow): inflow = avg of same day-of-week over last 4 weeks; outflow = `monthlyBurn/30`, weekends ×0.3; net shown per day in ₹K; current balance in header. _Persist: live store._ _Class: Indicative (heuristic projection from patterns)._
- **Priority actions (SmartActionsPanel)** — ranks up to 3 actions by hard-coded urgency: cash-crunch (<30d runway), chase overdue invoices, unread alerts, high-burn-vs-balance, plus a default "review sector benchmarks"; each deep-links. Returns `null` if none. _Persist: live store._ _Class: Indicative (rule-based prioritization)._
- **Treasury auto-sweep banner** — `GET /api/treasury/analysis` → shows idle cash (₹L) and `annual_yield_at_65` if idle ≥ ₹50K; "Enable Auto-Sweep" → `POST /api/treasury/sweep-enable` (queues enrollment, toast); dismissible. Carries `<PreviewBadge capability="treasurySweep" />`. _Persist: `localStorage hr_treasury_dismissed`._ _Class: Preview (PreviewBadge; sweep is queued, not executed) + Backend (analysis API)._
- **Business Health Score** — collapsible donut (0–100) = avg of 4 sub-scores, each banded with thresholds: Cash Health (runway), Revenue Trend (this-vs-last-month rev MoM), Debt Coverage (balance vs 6×EMI / activeLoans), Compliance (unread-alert count). Overall labeled Healthy/Needs Attention/At Risk. _Persist: none (open state is local useState)._ _Class: Indicative (scoring heuristic over KV data)._
- **Morning Brief Card** — greeting + condensed digest list: yesterday's net close, cash-on-hand + runway, today's movements, recurring payments due today, statutory items due today (`getUpcomingTaxDates` filtered to `isToday`), high-priority vs unread alerts; "all clear" line when nothing pending; links to alerts + compliance calendar. _Persist: live store._ _Class: Indicative (digest synthesis)._
- **My KPI Board (KpiWidgetBuilder)** — owner pins metrics from an 8-item catalog (balance, burn, runway, revenueMtd, netMtd, alerts, topBank, accounts); "Customize" toggles chips; renders pinned values live. _Persist: `useFeatureState("dashboard-kpi-board")` (KV-synced), default `[balance,runway,revenueMtd,alerts]`._ _Class: KV._
- **Daily Cash Position (DailyCashSnapshot)** — 4 summary tiles (opening/current balance, money in/out today, net today) + per-account breakdown of today's movements (count, +in/−out, balance). _Persist: live store._ _Class: KV._
- **Goal & Target Tracker (GoalTracker)** — user adds revenue/profit/balance goals with label + target; live progress bars compare actual (MTD rev, MTD net, or balance) vs target; achieved badge at ≥100%; add/remove. _Persist: `useFeatureState("dashboard-goals")` (KV-synced)._ _Class: KV._
- **Overdue Invoices** — `store.invoices` filtered `status≠paid && dueDate<today`, ranked by amount; shows count, total outstanding, top 5 (customer, invoice no., days late); "Chase all" + rows → `/receivables`. Returns `null` if none. _Persist: live store._ _Class: KV._
- **Due in the next 7 days (UpcomingDuesWidget)** — timeline merging open invoices due within 7d (inflow) + recurring outflows projected onto the next-7-day window by day-of-month (outflow); sorted by date, header shows total +in/−out; rows deep-link. Returns `null` if empty. _Persist: live store._ _Class: Indicative (recurring outflows are projected, not actual dated rows)._
- **Recent Activity** — latest 8 transactions across all accounts (newest first); in/out icon, description/counterparty, category + date, signed amount; "View all" → `/transactions`. Returns `null` if no transactions. _Persist: live store._ _Class: KV._
- **This Month · Mini P&L** — current-month cash-basis income statement: revenue minus payroll/opex/tax/loan/other (by category), net profit/loss, net-margin %; "Details" → `/analytics`. _Persist: live store._ _Class: KV._
- **Where the Money Goes (SpendByPayeeDonut)** — all-time outflow donut: top 5 counterparties (fallback category/"Other") + aggregated "Other", center shows total out, legend with %. Returns `null` if no outflows. _Persist: live store._ _Class: KV._
- **Cash Trend · 30 days (CashTrendSparkline)** — back-cast daily closing balance: walks backward from current balance subtracting each day's net flow; area chart in ₹K + 30-day change %. _Persist: live store._ _Class: Indicative (reconstructed/back-cast estimate, not recorded daily balances)._
- **Net Cash Flow · 6 months (NetCashFlowTrend)** — signed bar chart of monthly net (inflow−outflow) over 6 months in ₹K; subtitle shows cash-positive months count + avg; "Details" → `/analytics`. Returns `null` if all zero. _Persist: live store._ _Class: KV._
- **Biggest Movers · spend (ExpenseMoversWidget)** — per-category outflow change this month vs last; top 5 by |delta|, shows was→now and ±% (or "new"); "Review" → `/spend`. Returns `null` if no movers. _Persist: live store._ _Class: KV._
- **Customer Payment Status (CustomerPaymentStatus)** — donut of invoices split paid / pending (due) / overdue with counts + amounts; center shows total invoice count; "Receivables" → `/receivables`. Returns `null` if no invoices. _Persist: live store._ _Class: KV._
- **Days of Cash (CashGaugeWidget)** — half-circle gauge of days-of-cash = `balance/burn*30` (capped 180 for sweep, ∞ if no burn), colored Critical/Watch/Comfortable; plus MTD savings-rate bar = `(in−out)/in`; "Forecast" → `/forecast`. _Persist: live store._ _Class: Indicative (gauge framing) / KV._
- **Inflow by Weekday (WeekdayInflowWidget)** — 7-bar (Mon-first) total inflow per weekday over all history; highlights strongest day, tooltip shows amount + payment count. Returns `null` if no inflow. _Persist: live store._ _Class: KV._
- **Top Vendors · this month (TopVendorsWidget)** — current-month largest outflow payees (counterparty/description/category fallback), top 5 horizontal bars; "All" → `/transactions`. Returns `null` if none. _Persist: live store._ _Class: KV._
- **Invoice Status (InvoiceStatusWidget)** — paid/due/overdue stacked bar + 3 stat tiles (count + amount each), total in bar; "Open" → `/receivables`. Returns `null` if no invoices. _Persist: live store._ _Class: KV._
- **Burn Trend · 6 months (BurnTrendWidget)** — area chart of total monthly outflow (₹K) over 6 months + MoM % vs prior month; "Review" → `/spend`. Returns `null` if all zero. _Persist: live store._ _Class: KV._
- **Receivables vs Payables (ReceivablesVsPayablesWidget)** — working-capital snapshot: receivable = Σ open invoices; payable = Σ outflows that are recurring-or-this-month in [payroll, loan, tax, expense]; two bars + net position. Returns `null` if both zero. _Persist: live store._ _Class: Indicative (payable definition is heuristic, mixes recurring + this-month)._
- **Credit rescue CTA** — red banner shown when `0 < runway < 45`; "See rescue options" → `/credit`. _Persist: live store gate._ _Class: KV._
- **N-Day Cash Forecast (CashForecastChart)** — area chart of `store.forecast` P10/P50/P90 (₹L), 30/60/90-day segmented toggle, toggleable series legend; shown only if `forecast.length > 0`, else a placeholder pointing to `/forecast`. _Persist: live store (forecast array)._ _Class: Backend (forecast engine output)._
- **Monthly burn by category + This-month-vs-last + Revenue concentration + Tax calendar + Bank Accounts + Recent Alerts (inline panels)** — six inline cards: burn-by-category bars (payroll/expense/loan/tax/transfer); inflow/outflow/net this-vs-last MoM table; revenue concentration (top 5 sources, >40% triggers orange risk note with runway-impact estimate; shown if ≥2 sources); Tax calendar (`getUpcomingTaxDates` GSTR-3B/TDS/Advance-Tax with days-left urgency + estimated GST from last-month revenue × `firm.gstRate`); Bank Accounts list with share bars + Add; Recent Alerts (top 5, click marks read via `markAlertRead`). _Persist: live store; alert read-state writes to store._ _Class: KV; tax calendar = Indicative (standard statutory dates + GST estimate)._

Modals (triggered, not always-on widgets): **AddAccountModal**, **AddTransactionModal**, **TransactionImportModal** — write new accounts/transactions to the live store on submit. _Class: Backend (KV writes)._

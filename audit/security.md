## Security & Fraud (`/security`) — 30 tools

First line of defence against payment fraud (double-pays, BEC bank reroutes, ghost vendors, structuring) running self-checks on the live ledger and invoices. Stakeholders: owner, finance, CA. Backend: KV-synced (scans live transactions/invoices from AppContext store; manual registers persisted via `useFeatureState`/KV). NOTE: heuristics — flag "suspects, confirm" (every tab ends with the disclaimer "These are heuristic flags — suspects, not verdicts").

> The `overview` tab (#0) is a non-tool summary dashboard: σ-outlier count, duplicate count (same payee+amount ≤7d), new payees (first-seen ≤30d), total scanned, plus a static "what this module does" card. _Persist: none._ _Class: Indicative._

- **Anomaly Scanner** — outflows + sensitivity σ slider (1–4, default 2) → mean/σ of \|amounts\|, z-score per payment, flag \|z\|≥σ (anomaly scan, σ-outlier) → table of outlier payments sorted by \|z\| with deviation in σ. _Persist: none (live store)._ _Class: Indicative._
- **Duplicate Payments** — outflows + window slider (1–30d, default 7) → group by payee+rounded amount, flag groups with any consecutive pair ≤window (duplicate detection); estimates recoverable exposure = amount×(count−1) → suspect groups with rows. _Persist: none (live store)._ _Class: Indicative._
- **Round-Trip Detector** — outflows/inflows + window (3–90d, default 30) + amount tolerance (0–50%, default 20%) → match each out to a later in from same counterparty within window and within ±tol% (round-trip/circular flow) → out↔back pairs with % returned. _Persist: none (live store)._ _Class: Indicative._
- **New-Payee Watch** — outflows + lookback slider (7–120d, default 30) → first-seen date per payee, flag those first paid ≤lookback (new-payee watch) → table: first paid, payments since, total. _Persist: none (live store)._ _Class: Indicative._
- **Vendor Bank Change** — manual vendor + account + IFSC (datalist of known payees) → on save, compare to stored record; if account/IFSC differs, mark `lastChangedAt` and warn (vendor bank-change / BEC detection) → register with Stable/Changed status. _Persist: KV `sec-vendor-banks`._ _Class: KV._
- **Monitoring Rules** — user-defined no-code rules (field amount/payee/description; op gt/lt/contains; value; enable toggle) → match each outflow against active rules → flagged txns with triggered rule tags. _Persist: KV `sec-monitoring-rules`._ _Class: KV._
- **Access Review Log** — manual entries (person, role, scope, status active/suspended, lastReviewed) → flag grants not reviewed >90d (segregation/stale-access); mark-reviewed/suspend toggles → register + stale banner. _Persist: KV `sec-access-log`._ _Class: KV._
- **Fraud Risk Score** — txns + invoices → weighted rollup of 4 signals: outlier payments >2σ (w8,max5), duplicate suspects same payee+amt ≤7d (w12,max4), round-number payments %=multiples of 10k (w0.4,max100), invoices missing numbers (w5,max6) → 0–100 score, band Low/Elevated/High (fraud score) + signal breakdown. _Persist: none (live store)._ _Class: Indicative._
- **Suspicious Invoices** — store.invoices → flag missing invoice#, duplicate invoice#, round amount (≥10k & %10k==0), sequence gap (numeric suffix jump >1) → invoices to review with reason tags. _Persist: none (live store)._ _Class: Indicative._
- **Security Checklist** — 10 fixed hygiene controls (2FA, maker-checker, vendor verify, access review, recon, unique pw, device lock, backups, least-priv, incident plan), user toggles → completion % + band color. _Persist: KV `sec-hygiene`._ _Class: KV._
- **Off-Hours Payments** — outflows → flag those dated Saturday/Sunday via `getDay()` (off-hours/weekend) → table + total, weekend-day labelled. _Persist: none (live store)._ _Class: Indicative._
- **Benford's-Law Audit** — \|outflow amounts\|≥1 → leading-digit distribution vs Benford expected %, χ² statistic (8 d.o.f.); verdict insufficient(<50)/normal(≤15.51)/elevated(≤20.09)/high(>20.09) (Benford's-law χ²) → per-digit bars with deviation flags. _Persist: none (live store)._ _Class: Indicative._
- **Payment Velocity** — outflows + window (1–14d, default 3) + min count (2–10, default 3) → per-payee densest run within window, flag runs ≥minCount (velocity burst/mule/salami) → bursts with count, span, total. _Persist: none (live store)._ _Class: Indicative._
- **Under-Limit Splitting** — outflows + approval limit (₹, default 100000) + band % (1–25%, default 10) → payments in [limit×(1−band%), limit); detect per-payee multiple just-under payments ≤7d apart (structuring/under-limit splitting) → just-under table + split banner. _Persist: KV `sec-approval-limit` (limit only); band/list live._ _Class: KV (input) / Indicative (analysis)._
- **Dormant Reactivation** — all txns per counterparty + dormancy slider (60–540d, default 180) → consecutive gaps ≥threshold (dormant-account reactivation) → reactivation events with idle gap. _Persist: none (live store)._ _Class: Indicative._
- **Expense-Policy Flags** — expense-category outflows vs editable policy (per-txn cap default 50000, flag-weekend toggle, restricted keywords) → flag over cap / weekend / keyword hit → expenses to review with violation tags. _Persist: KV `sec-expense-policy`._ _Class: KV._
- **Duties Separation** — manual payee+creator+approver entries (datalist of payees) → flag where creator==approver (segregation of duties) → register + conflict banner. _Persist: KV `sec-sod-map`._ _Class: KV._
- **Vendor Dedupe** — distinct outflow vendor names → normalize (strip pvt/ltd/llp etc + non-alnum), flag identical-after-normalise or Levenshtein distance 1–2 with maxLen≥4 (near-duplicate vendor) → duplicate-pair table with reason. _Persist: none (live store)._ _Class: Indicative._
- **Refund Anomalies** — txns matching /refund\|reversal\|chargeback\|return/ or revenue-category negatives → flag ≥3 refunds to one party, round-number refund (≥10k & %10k==0), revenue reversal (refund-abuse heuristics) → refund entries with reason tags + total. _Persist: none (live store)._ _Class: Indicative._
- **Recurring-Charge Watch** — outflows where `isRecurring` per payee → first vs latest amount change %, new if first ≤60d; flag price creep ≥15% (recurring-charge/subscription leakage) → run-rate, new count, creep count, per-payee table. _Persist: none (live store)._ _Class: Indicative._
- **Fake-ITC Risk** — manual supplier+GSTIN register (datalist of payees) → screen each: malformed GSTIN (15-char regex), invalid state code (not 1–38), same GSTIN across multiple vendors (fake-ITC GSTIN) → risk-marker table + banner. _Persist: KV `sec-vendor-gstins`._ _Class: KV._
- **IP / Device Allowlist** — manual entries (label, kind ip/device, value with IPv4/CIDR validation, trusted/revoked toggle) → maintain allowlist register (attack-surface reduction; no automatic scan) → table. _Persist: KV `sec-ip-allowlist`._ _Class: KV._
- **Data-Export Audit** — manual export log (who, dataset dropdown, rows, reason, PII checkbox) → counts: total, last 30d, containing PII → append log (DPDP/exfiltration trail). _Persist: KV `sec-export-audit`._ _Class: KV._
- **Key Rotation** — manual credentials (name, lastRotated date, intervalDays default 90) → age vs interval → state overdue/soon(≤14d)/ok; mark-rotated action (credential-rotation reminder) → table + overdue banner. _Persist: KV `sec-key-rotation`._ _Class: KV._
- **Cash Spike Monitor** — txns matching /cash\|atm\|withdrawal\|deposit/ + large-cash threshold (₹, default 200000) → monthly cash totals, flag months >1.5× mean, list single cash txns ≥threshold (AML cash-spike) → monthly bars + big-single table. _Persist: KV `sec-cash-threshold` (threshold only); analysis live._ _Class: KV (input) / Indicative (analysis)._
- **Sensitive-Action Log** — manual privileged-action log (actor, action dropdown: limit change/bank edit/grant/revoke/rotate/export/delete/other, detail) → counts total + last 7d → append log (privilege-abuse trail). _Persist: KV `sec-action-log`._ _Class: KV._
- **Round-Amount Flags** — outflows + round step slider (1k–50k, default 10k) + min-amount slider (5k–500k, default 25k) → flag \|amount\| ≥min and %step==0 (round-amount heuristic) → table + total. _Persist: none (live store)._ _Class: Indicative._
- **Payroll-vs-Vendor Bank** — manual employee name+salary account (dup-account guard) → normalize names, flag any vendor whose name equals/contains/is-contained-by an employee name (ghost-vendor / self-payment) → collision banner + staff table. _Persist: KV `sec-staff-banks`._ _Class: KV (register) / Indicative (name-match)._
- **New-Account Over Limit** — outflows + amount threshold (10k–500k, default 50000) + first-payment window (1–60d, default 14) → flag payments ≥threshold made ≤window days after a payee's first-ever payment (large-payment-to-new-account / invoice redirection) → high-risk table. _Persist: none (live store)._ _Class: Indicative._
- **Control Self-Assessment** — 8 fixed control questions (dual approval, bank verify, recon, access review, segregation, backups, MFA, petty cash) answered yes/partial/no → maturity score (yes=1, partial=0.5), band Weak/Developing/Strong, gap list → live score + gaps. _Persist: KV `sec-control-csa`._ _Class: KV._

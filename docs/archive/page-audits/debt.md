# Debt Management (`/debt`) — 25 tools

Single consolidated cockpit for every business loan — amortisation, prepayment/refinance maths, covenant & coverage monitoring, and capital-structure planning. Stakeholders: owner, finance. Backend: KV-synced — every tool reads the live `store.activeLoans` (id, lender, outstanding, rate, monthlyEmi, principal) and several read `computeFinancialSnapshot(store)` (revenue/net/interest/DSCR/ICR); user inputs and a few settings persist via `useFeatureState` KV keys. All maths is computed client-side from `@/lib/finance` (`emi`, `amortizationSchedule`, `totalInterest`, `prepaymentImpact`, `irr`) plus a local `remainingMonths()` solver; nothing is sent to a server. There are **22 tab tools** in the tab array; the **Overview** tab additionally renders **3** distinct embedded analysis tools (counted below).

> Note: the EMI-mode/structure/strategy radio toggles inside individual tools (e.g. _reduce tenure vs reduce EMI_, _avalanche vs snowball_, _step-up vs step-down_, _interest-only vs balloon_, _EMI vs bullet_, _buy vs lease_, _reset EMI vs hold EMI_) are mode switches **within** a single tool, not separate tools — mentioned once here and not enumerated per option.

## Overview tab (`overview`)

- **Debt KPI Strip** — reads `store.activeLoans` + snapshot → shows Total Outstanding, Monthly Debt Service (with pure-interest split), Weighted Avg Rate, and DSCR (green/red vs the 1.25x lender bar) → 4 KPI cards. _Persist: live store._ _Class: KV._
- **Active Loans Table** — per loan: outstanding, rate, EMI, % paid off (`(principal−outstanding)/principal`), and Est. Interest Left (`totalInterest` over `remainingMonths`); click selects a loan to analyse → sortable-style table feeding the embedded analysers. _Persist: live store._ _Class: KV._
- **Amortisation Chart** — selected loan's `amortizationSchedule(outstanding, rate, remainingMonths)` → stacked Principal/Interest area chart + next-12-month schedule table (opening/EMI/interest/principal/closing). _Persist: live store (read-only)._ _Class: KV._
- **Prepayment Simulator (embedded)** — lump-sum slider (10k → outstanding) on the selected loan → `prepaymentImpact()` reducing-balance, same-EMI → interest saved, months cut, new payoff term. _Persist: none (local slider)._ _Class: Indicative._
- **Refinance Check (embedded)** — new-rate slider (8% → current) for the same remaining term → `totalInterest` at old vs new rate, new EMI (`emi`), lifetime saving; CTA to run a lender auction (`/lenders`). _Persist: none (local slider)._ _Class: Indicative._

## Tab tools

- **Loan Amortisation & Prepayment Simulator** (`amortise`, #86) — principal/rate/tenure/prepay-amount/prepay-month inputs (one-click prefill from any active loan) + tenure-vs-EMI prepay mode → from-scratch reducing-balance schedule, re-cast with a one-time prepayment (reduce tenure keeps EMI; reduce EMI keeps tenure) → monthly EMI, total interest, interest saved, months cut / new term, 24-month schedule with prepay column. _Persist: none._ _Class: Indicative._
- **DSCR / Interest-Coverage Tracker** (`dscr`, #87) — snapshot-derived NOI (monthly net + interest add-back, annualised) → DSCR (NOI ÷ debt service), ICR (EBIT-proxy ÷ interest), Debt/NOI leverage, annual NOI; user adds covenant rows (name/metric/operator/threshold) and each is flagged OK/Breach against live metrics. _Persist: live store (metrics) + KV `debt-covenants` (covenant list)._ _Class: KV._
- **Debt Consolidation / Refinance Comparator** (`refinance`, #88) — refinance amount (auto = total outstanding) + user-added lender offers (rate/tenure/processing%/other fees) → per offer: EMI, lifetime interest, fees, all-in cost, and effective APR via `irr()` of net-disbursal-vs-EMI cashflows; ranks offers, marks BEST, compares to current weighted blended cost. _Persist: live store + KV `debt-refi-offers`._ _Class: KV._
- **Moratorium & Restructuring Re-cast Modeller** (`moratorium`, #89) — pick loan or manual P/R/N + moratorium months, tenure extension, restructured rate, capitalise-interest toggle → accrued interest in holiday (`P·((1+r)^m−1)`), re-cast principal, new EMI, extra lifetime interest, total months to close → before/after comparison. _Persist: live store (loan read); none for inputs._ _Class: Indicative._
- **Debt Schedule / Repayment Ladder** (`schedule`, #90) — merges all loans into one forward calendar over a 12–60mo horizon → combined EMI, interest, principal, outstanding and active-loan count per month; detects roll-off months (freed cash); step/area chart + month-by-month table. _Persist: live store + KV `debt-ladder-horizon`._ _Class: KV._
- **Interest-Cost Optimizer (avalanche vs snowball)** (`optimizer`, #91) — monthly surplus budget + strategy → simulates paying all minimum EMIs then routing surplus to highest-rate (avalanche) or smallest-balance (snowball) loan first, rolling to next as each closes → total interest, interest saved vs EMI-only, debt-free month, ranked attack order with per-loan close month, and which strategy wins. _Persist: live store + KV `debt-optimizer-budget`._ _Class: KV._
- **Weighted-Average Cost of Debt (WACD)** (`wacd`, #92) — all loans → blended rate `Σ(rate×outstanding)/Σoutstanding`, monthly/annual interest bill, costliest loan; per-loan weight, contribution-to-WACD (bps), monthly interest and its share, flagging above-blend loans; bar chart vs blend. _Persist: live store._ _Class: KV._
- **Foreclosure / Pre-closure Charges Calculator** (`foreclosure`, #93) — pick loan + penalty% (of outstanding) + optional 18% GST toggle + other charges → interest saved by closing now (`totalInterest` over remaining), penalty + GST + other = total cost, net benefit, and break-even penalty% → pays-off / cheaper-to-continue verdict. _Persist: live store + KV `debt-foreclosure-penalty`._ _Class: Indicative._
- **Balloon / Bullet Repayment Planner** (`balloon`, #94) — amount/rate/tenure + interest-only (100% bullet) or partial-amortisation (balloon %) mode → monthly payment (interest on full balance + EMI on amortising slice), balloon due at maturity, interest over term, extra interest vs fully-amortising loan, 12-month schedule + refinancing-risk warning. _Persist: none._ _Class: Indicative._
- **Step-Up / Step-Down EMI Planner** (`stepemi`, #95) — pick loan or manual P/R/N + direction (up/down) + annual step% → solves base EMI so PV of all stepped payments = principal (keeps tenure), schedules per-year EMI, total interest vs flat EMI; EMI-by-year table + delta-vs-flat. _Persist: live store (loan read); none for inputs._ _Class: Indicative._
- **Interest-Subsidy / Subvention Estimator** (`subsidy`, #96) — pick loan or manual P/R/N + scheme (interest subvention / CLCSS capital subsidy / MUDRA) + subvention% or eligible capex + CLCSS% → subvention benefit (`grossInterest·min(1,sub/rate)`), effective post-subsidy rate, CLCSS capital subsidy (capped ₹15L on ₹1Cr eligible), total benefit. _Persist: live store (loan read) + KV `debt-subvention-pct`._ _Class: Indicative._
- **Loan Against FD / Securities Estimator** (`lasf`, #97) — asset type (FD ≤90% LTV / shares-MF ≤50% LTV) + asset value + yield + draw% + tenure → sanction limit, drawn amount & EMI, loan interest (FD rate +2% or ~10.5% LAS), yield kept on pledged asset, and net carry cost (interest − yield). _Persist: none._ _Class: Indicative._
- **Gold-Loan Estimator** (`gold`, #98) — net grams + purity (24/22/18K) + 24K ₹/gram + LTV (≤75% RBI cap) + loan rate + tenure + EMI-vs-bullet structure → pledged gold value (`grams·purityFactor·rate`), eligible loan, monthly EMI or interest-only, total interest (+ bullet principal); auction/top-up risk warning. _Persist: none._ _Class: Indicative._
- **Equipment Finance vs Lease Comparator** (`equip`, #99) — asset cost + loan rate + down% + term + residual% + monthly lease rental → buy path (down + EMI×N − residual kept = net cost of ownership) vs operating lease (rental×N = net cost), side-by-side cards with CHEAPER badge + verdict. _Persist: none._ _Class: Indicative._
- **Interest-Rate Reset (Repo / MCLR) Impact** (`reset`, #100) — bps slider (−200…+200) + reset-EMI (hold tenure) vs hold-EMI (reset tenure) mode → per loan: new rate, new EMI or new term, EMI/term delta, extra lifetime interest; combined EMI change, total extra interest, months added / loans repriced. _Persist: live store + KV `debt-reset-bps`._ _Class: Indicative._
- **Group Exposure / Loan-Stacking Tracker** (`stacking`, #101) — all loans + snapshot revenue → FOIR (total EMI ÷ monthly income, ~50% cap), debt ÷ annual revenue, active-lender count (stacking flag at 4+), top-lender concentration; per-lender exposure table + over-leverage verdict. _Persist: live store._ _Class: KV._
- **Working-Capital Demand Loan / OD-CC Calculator** (`wcdl`, #102) — sanctioned limit + avg utilisation% + rate + commitment% (on idle) + renewal fee → avg drawn/idle balance, monthly & annual interest on drawn only, commitment fee, all-in annual cost, effective rate on drawn, and savings vs a fully-drawn term loan. _Persist: none._ _Class: Indicative._
- **Interest-Coverage (ICR) Trend & Rate-Shock** (`icr`, #103) — snapshot OCF (net + debt service add-back) + shock slider (0…+500bps) → ICR (OCF ÷ interest, aim ≥3x), pre-debt cash flow, annual interest, shocked ICR at +Nbps with extra interest/yr; ICR-vs-bps area-curve + breach warning (<2x). _Persist: live store + KV `debt-icr-shock-bps`._ _Class: KV._
- **Debt-Maturity Profile** (`maturity`, #104) — buckets each loan's `remainingMonths` into 0–12m/1–2y/2–3y/3–5y/5y+ windows → outstanding, loan count and share% per bucket; bar chart highlighting any >40% window as a refinancing "wall" + laddering verdict. _Persist: live store._ _Class: KV._
- **Prepayment-Penalty vs Interest-Saved** (`prepaypenalty`, #105) — lump-sum + penalty% → per loan: applied amount (capped at outstanding), interest saved via `prepaymentImpact`, penalty (`applied·pen%`), net benefit; ranks loans by net payback, flags worth-it, recommends best target. _Persist: live store + KV `debt-prepay-penalty-pct`._ _Class: KV._
- **Debt-to-Equity Target Planner** (`gearing`, #106) — net worth/equity input + target D/E slider (0.5–3x) → current D/E (total debt ÷ equity), debt allowed at target, repay-needed (if over-geared) or borrowing headroom, or equity-to-inject alternative; covenant-cap warning. _Persist: live store + KV `debt-de-equity`._ _Class: KV._

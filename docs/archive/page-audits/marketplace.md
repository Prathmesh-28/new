## E-commerce & ONDC (`/marketplace`) — 32 tools

Reconcile marketplace payouts (Amazon, Flipkart, Meesho, ONDC, D2C/Shopify), surface true per-SKU margin, and stay GST-compliant in one ledger. Stakeholders: sales, ops, owner. Backend: KV-synced (all persistence via `useFeatureState` localStorage-backed keys; no server API).

- **Overview** — reads KV state from settlement, SKU & RTO tabs → recomputes net payout (`Σ orderValue−fees−refunds−tcs`), total RTO loss, count of SKUs below break-even (`skuNet<0`), channel count → 4 KPI cards + 10 jump-to-tool cards + TCS/Sec-52 advisory. _Persist: reads `mkt-settlement-lines`, `mkt-sku-rows`, `mkt-rto-rows`._ _Class: KV._
- **Settlement Recon** — paste Amazon/Flipkart CSV (`orderId,orderValue,fees,refunds,tcs`) + optional expected bank credit → header auto-detect & parse, per-line & total net payout (`gross−fees−refunds−tcs`), variance vs expected (matched if `|Δ|<1`, else shortfall/excess) → KPI cards + reconciled/mismatch banner + line table. _Persist: `mkt-settlement-lines`._ _Class: KV._
- **Fee Calculator (Commission)** — channel + selling price, referral %, closing fee, shipping fee, ad %, GST-on-fees % → `referral=price×ref%`, `feeBase=referral+closing+shipping+ad`, `feeGst=feeBase×gst%` (ITC-claimable), `totalFee`, `netRealisation=price−totalFee`, effective fee % (red if >30%) → per-order economics breakdown. _Persist: none (local useState)._ _Class: Indicative._
- **Return / RTO Loss** — SKU, channel, type (rto/return), order value, COGS, forward/reverse freight, event count → `rtoLossOf = (fwdFreight+revFreight)×count` (RTO & return both modeled as freight bleed; goods recovered) → total loss, units lost, avg loss/unit, table. _Persist: `mkt-rto-rows`._ _Class: KV._
- **Sales Consolidator** — per-channel orders, gross sales, fees, returns (re-add overwrites channel) → `net=gross−fees−returns`, totals, per-channel net mix % → KPI cards + table. _Persist: `mkt-channel-sales`._ _Class: KV._
- **Payout Calendar** — channel, cycle days, last payout date, pending amount (re-add overwrites) → `next=lastPayout+cycleDays`, `daysAway=ceil((next−today)/day)`, sorted soonest-first, total locked → due/overdue/Nd badges + table. _Persist: `mkt-payout-cfg`._ _Class: KV._
- **TCS u/s 52** — operator, net taxable sales, month → `tcsCollected = sales×1%` (0.5% CGST + 0.5% SGST per Sec 52, GSTR-8), per-row Matched/Unmatched toggle; totals + reconciled/claimable sum (only reconciled rows) → cards + table. _Persist: `mkt-tcs52`._ _Class: KV._
- **Listing P&L / SKU** — SKU, channel, price, COGS, fees %, ad/unit, shipping, return rate %, units sold → `skuNet = price−cogs−fees(price×feesPct)−ad−shipping−returnProvision(price×returnPct%×0.5)`, margin %, total profit (`net×units`); negative rows highlighted → table. _Persist: `mkt-sku-rows`._ _Class: KV._
- **Channel Compare** — reads `mkt-channel-sales` (no input) → per-channel `net`, margin % (`net/gross`), fee load (`fees/gross`), AOV (`gross/orders`), sorted by margin desc → best/weakest banners + horizontal margin bars. _Persist: reads `mkt-channel-sales`._ _Class: KV._
- **ONDC Readiness** — toggle 8 checklist steps (GST, PAN/bank, catalog+HSN, FSSAI, seller-app, logistics, returns policy, floor-price) → completion % bar; 100% shows go-live banner. _Persist: `mkt-ondc-checklist`._ _Class: KV._
- **Ad ROAS** — ad spend, sales from ads, gross margin % → `ROAS=sales/spend`, `ACoS=spend/sales%`, `breakEvenACoS=grossMargin%`, `profitAfterAd=sales×gm%−spend`, profitable if `ACoS≤breakEvenACoS` → KPI cards + profitable/loss banner. _Persist: none (local useState)._ _Class: Indicative._
- **Target-Margin Price** — COGS, referral %, fixed fee, shipping, target net margin %, output GST % → back-solve `basePrice=(cogs+ship+fixed)/(1−ref−margin)`, buyer MRP `=basePrice×(1+gst)`, referral amt, profit/unit; infeasible if `1−ref−margin≤0` → result cards. _Persist: none (local useState)._ _Class: Indicative._
- **Inventory Sync** — SKU + warehouse + per-channel listed qty (Amazon/Flipkart/Meesho/ONDC; re-add overwrites by SKU) → `listed=Σchannels`, oversell flag if `listed>warehouse` → total WH, total listed, oversell-risk count + in-sync/oversold table. _Persist: `mkt-inventory-sync`._ _Class: KV._
- **FBA Fee Estimator** — actual weight, L/W/H cm, pick&pack, storage ₹/cu.ft/mo, months stored, units → `volWeight=L×W×H/5000`, `billed=max(actual,vol)`, `slabs=ceil((billed−0.5)/0.5)`, `weightHandling=40+slabs×20`, `storage=(L×W×H/28316.8)×rate×months`, `perUnit`, total `×units` → fee breakdown (explicitly "indicative"). _Persist: none (local useState)._ _Class: Indicative._
- **PPC Allocator** — total monthly budget + campaign name/weight rows → per-campaign `share=weight/Σweight`, `alloc=budget×share` → weighted bars + % split. _Persist: `mkt-ppc-rows` (budget itself is local useState, not persisted)._ _Class: KV._
- **Repricing Sim** — COGS, fees %, current/new price, min margin %, units@current, elasticity → `netUnit(p)=p−p×fees−cogs`, `floorPrice=cogs/(1−fees−minMargin)`, breach if `new<floor`, demand `newUnits=u0×(1−pricePct×elasticity)`, `profitΔ=newProfit−curProfit` → floor banner + projection cards. _Persist: none (local useState)._ _Class: Simulated._
- **Rating Tracker** — SKU, channel, rating (0–5), # reviews → review-weighted avg `Σ(rating×reviews)/Σreviews`, total reviews, count below 4.0★ (buy-box risk); sub-4.0 rows flagged → cards + healthy/at-risk table. _Persist: `mkt-review-rows`._ _Class: KV._
- **GSTR-8 Recon** — operator, month, TCS per books, TCS in GSTR-8 → `diff=gstr8−books`, matched if `|diff|<1`, else under/over-reported; totals + mismatch count → cards + status table. _Persist: `mkt-gstr8-rows`._ _Class: KV._
- **Refund Cost** — SKU, type (refund/returnless/replacement), order value, refund amt, lost-goods/replacement COGS, count → `refundCostOf`: returnless=`refund+replCogs`, replacement=`replCogs+refund`, refund=`refund`; ×count → total cost, events, returnless subtotal + table. _Persist: `mkt-refund-rows`._ _Class: KV._
- **Listing Quality** — toggle 8 checks (title, 7+ images, 5 bullets, A+ content, video, HSN/GST, backend search terms, buy-box price band) → score % bar; <100% shows "fix before scaling ads" nudge. _Persist: `mkt-listing-quality`._ _Class: KV._
- **COD vs Prepaid** — total orders, COD share %, AOV, gross margin %, COD RTO %, prepaid RTO %, RTO cost/order → split orders, per-segment `rtos=cnt×rtoRate`, `net=delivered×grossMargin−rtos×rtoCost`, net/order each; total net + prepaid-vs-COD gap insight. _Persist: none (local useState)._ _Class: Simulated._
- **Buy-Box Win Rate** — SKU, channel, listing views, buy-box wins (capped at views), your price, lowest price → per-row `winRate=wins/views`, `gap=yourPrice−lowest`; blended rate `Σwins/Σviews` (color-banded 80/50) → cards + win%/gap table. _Persist: `mkt-buybox-rows`._ _Class: KV._
- **Reserve Release** — channel, held amount, held-on date, release-in days → `release=heldOn+releaseDays`, `daysAway`, sorted soonest; total held + releasing-within-7-days sum → released/Nd badges + table. _Persist: `mkt-reserve-rows`._ _Class: KV._
- **Chargeback Ledger** — order ID, channel, reason (preset list), amount, raised-on; per-row status select (open/won/lost) → open exposure `Σopen.amount`, lost written-off sum, `winRate=won/settled%` → cards + ledger table. _Persist: `mkt-chargeback-rows`._ _Class: KV._
- **Bundle COGS** — component rows (name, unit COGS, qty) + bundle price, fees %, shipping → `totalCogs=Σcogs×qty`, `fees=price×feesPct`, `netMargin=price−totalCogs−fees−shipping`, margin % → component list + margin breakdown. _Persist: none (components are local useState)._ _Class: Indicative._
- **Break-even Price** — COGS, fees %, shipping, ad/unit, return %, target margin % → `breakEven=(cogs+ship+ad)/(1−fees−return×0.5)`, `targetPrice=(cogs+ship+ad)/(1−fees−return×0.5−target)`; invalid if `denomTgt≤0` → break-even + target-margin price cards. _Persist: none (local useState)._ _Class: Indicative._
- **Festival Planner** — event name/date, projected units, AOV, discount % → `projGmv=units×AOV×(1−disc)`; 7-task template auto-dated as `eventDate+dueOffset` with days-away/late badges, toggle + reset; readiness % → GMV/readiness cards + dated checklist. _Persist: `mkt-festival-name`, `mkt-festival-date`, `mkt-festival-tasks` (units/AOV/discount are local useState)._ _Class: KV._
- **Cash-Cycle Cost (Holding)** — channel, monthly GMV, payout-lag days, borrowing APR % (re-add overwrites) → `dailyGmv=GMV/30`, `lockedCapital=dailyGmv×payoutDays`, `annualCost=locked×APR%`; totals → capital-locked + annual-cost cards + table. _Persist: `mkt-holding-rows` (APR is local useState)._ _Class: KV._
- **Coupon ROI (Promo)** — promo name, discount spend, baseline units, promo units, margin/unit → `incrUnits=max(0,promo−baseline)`, `incrMargin=incrUnits×margin`, `netGain=incrMargin−spend`, `roi=netGain/spend` → spend/net cards + per-promo table. _Persist: `mkt-promo-roi`._ _Class: KV._
- **Conversion Tracker** — listing/ASIN, sessions, orders → per-row `cvr=orders/sessions`, blended `Σorders/Σsessions`; flag rows `cvr<0.6×blended` → blended card + flagged CVR table. _Persist: `mkt-conversion-rows`._ _Class: KV._
- **Return Rate / SKU** — SKU, delivered, returned → per-row `rate=returned/delivered`, sorted worst-first; portfolio `ΣreturnedΣdelivered` (color-banded 20%/10%) → rate card + table. _Persist: `mkt-return-rate-rows`._ _Class: KV._
- **Fee Reconciliation** — order/settlement ID, expected fee, charged fee, tolerance % → `diff=charged−expected`, `overcharged` if `diff>expected×tol%` (or `diff>0` when expected=0); net variance + disputable-overcharge sum → cards + overcharged/OK table. _Persist: `mkt-fee-recon-rows`._ _Class: KV._

## Working Capital (`/working-capital`) — 24 tools

One-sentence purpose: turn the SMB's live ledger (DSO/DIO/DPO, AR/inventory/payables/cash) into cash-conversion-cycle diagnostics, bank-finance sizing (drawing power, MPBF/Tandon), and discount-vs-borrow / factoring-vs-OD funding decisions. Stakeholders: owner, finance. Backend: KV-synced (`store` snapshot drives every tool; a handful of input parameters persist via `useFeatureState` → `store.featureData`, localStorage + debounced backend sync; all other inputs are transient `useState`).

All tools derive from `computeFinancialSnapshot(store)` (DSO, DIO, DPO, CCC, AR, inventory, payables, cash, overdue AR, monthlyExpense, monthlyRevenue, currentRatio, quickRatio, netWorkingCapital, workingCapitalGap, obligationsDue90) — i.e. read live from the synced store, not re-persisted.

- **Overview (Working-Capital Snapshot + Financing + Simulators)** — store snapshot + `agingBuckets(invoices)`, `financingOptions(gap, AR)`, `earlyPayAnnualizedReturn(disc,days)`, `paymentTermsSuggestions(store)` → KPI strip (CCC=DSO+DIO−DPO, DSO/DIO/DPO), funding-gap callout (gap ≈ months×opex), cycle bar visual, AR-ageing chart, early-pay APR table (discount/(1−discount)×365/days; worth if >18%), financing-options table ranked by effective annual cost, cash-release simulator (15d DSO / 10d DIO / 10d DPO each freeing days/30 × monthlyExpense), terms-negotiator (per-party cash impact), WC ratios (current/quick/NWC/cycle-funding). _Persist: live store (derived; no writes)._ _Class: Indicative._
- **CCC Dashboard** — `peerKey` select (5 sector medians) + snapshot legs → CCC=DSO+DIO−DPO; deterministic 6-month back-projection (factor 1.18→1.0, DPO inverse), vs-peer delta, cash impact = (your CCC − peer CCC) × daily opex; per-leg you-vs-peer table. _Persist: none (peerKey transient)._ _Class: Indicative._
- **Inventory Days Optimizer** — `targetDio`, `carryPct` (default 22) → daily COGS = inventoryValue/DIO; targetInventory = dailyCOGS×target; cashReleased = inventory − target; annualCarrySaving = released×carry; redeploy rows (14% OD / 18% discounting / carry). _Persist: none._ _Class: Simulated._
- **Payables Trade-off (Payables-Stretch vs Early-Pay Discount)** — `spend`, `discPct`, `discDays`, `netDays`, `stretchTo`, `borrowPct` → earlyApr = earlyPayAnnualizedReturn (discount-vs-borrow); discountSaved = spend×disc; stretch cashHeld = spend/30×extraDays, stretchValue; verdict: take discount if APR > cost of capital, else stretch (with MSME 43B(h) caution). _Persist: none._ _Class: Indicative._
- **OD/CC Utilisation & Drawing-Power Tracker** — `limit`, `drawn`, `stockMargin` (25), `debtorMargin` (40) → drawing power = inventory×(1−sMargin) + AR×(1−dMargin); effectiveLimit = min(sanctioned, DP); utilisation%, headroom, overdrawn flag, DP-shortfall warning, drawing-power build-up table. _Persist: none._ _Class: Indicative._
- **WC Gap & Funding (Funding-Need Quantifier)** — `marginPct` (25) → currentAssets = inventory+AR; WC gap = max(0, CA − payables); ownMargin = gap×margin; permissibleBankFinance = gap − ownMargin (Tandon II); funding-mix bar; cross-check vs cycle gap; `financingOptions` table on bank-finance need. _Persist: none (marginPct transient)._ _Class: Indicative._
- **Trade-Cycle Optimizer** — `tDso`, `tDio`, `tDpo` sliders → targetCCC = DSO+DIO−DPO; daysSaved = current CCC − target; cashFreed = daysSaved × daily opex; verdict band. _Persist: none._ _Class: Simulated._
- **Discount vs Borrow (Dynamic Discounting)** — `invoiceAmt`, `discPct`, `daysEarly`, `borrowPct` → apr = earlyPayAnnualizedReturn; discountSaved = amt×disc; borrowCostToPayEarly = amt×borrow×early/365; netBenefit; take if APR > borrow rate. _Persist: none._ _Class: Indicative._
- **Seasonal WC Planner** — `peakLift` (25) over fixed 12-month Indian demand index → scaled = idx + (idx−1)×lift; monthly WC = baseWC×scaled; peak/trough/extra-line-at-peak; year bar chart vs base line. _Persist: none._ _Class: Simulated._
- **Net WC Trend** — snapshot → deterministic 6-month back-projection of NWC = AR+inventory−payables (factor 1.2→1.0, AP inverse); MoM change, NWC % of annual revenue, cash tied up; multi-line component chart. _Persist: none._ _Class: Indicative._
- **Cash Locked in WC** — snapshot → gross = AR+inventory; netLocked = gross − payables; releasable = all overdue AR + 20% inventory + 15% payables (term extension); component bars with levers. _Persist: live store (derived)._ _Class: Indicative._
- **AR Acceleration (Receivables Acceleration Planner)** — `discPct`, `uptakePct` (40) + `agingBuckets` → per-bucket recovery rates [0.95,0.85,0.7,0.5,0.3], pullForward = amount×rate; discountCost = AR×uptake×disc; netCashPulled; daysShortened = net ÷ daily opex; bucket action table. _Persist: none._ _Class: Indicative._
- **Liquidity Ratios Tracker** — snapshot (cash, AR, inventory, payables, obligationsDue90) → currentRatio = CA/CL, quickRatio = (cash+AR)/CL, cashRatio = cash/CL (CL = payables + dues≤90d); target bars (1.5/1.0/0.5x); component table. _Persist: live store (derived)._ _Class: Indicative._
- **MPBF (Tandon)** — `otherCa`, `otherCl` (both KV-persisted) → CA = inventory+AR+otherCa; WC gap = CA − (payables+otherCl); Method I MPBF = gap − 25%×gap (CR≈1.17); Method II MPBF = CA − OCL − 25%×CA (CR≈1.33); implied NWC + current ratios; Method-I-vs-II table. _Persist: KV — `wc-mpbf-other-ca`, `wc-mpbf-other-cl`._ _Class: KV._
- **Stock Statement (Stock & Book-Debt Generator)** — `stockMargin` (25), `debtorMargin` (40), `excludeOver90` (yes), `creditors` (all KV) → paidStock = inventory − creditors; eligibleStock = paidStock×(1−sMargin); eligibleDebtors (excl >90d via overdue) ×(1−dMargin); drawingPower = sum; copy-to-clipboard for bank submission. _Persist: KV — `wc-stockstmt-stock-margin`, `wc-stockstmt-debtor-margin`, `wc-stockstmt-excl90`, `wc-stockstmt-creditors`._ _Class: KV._
- **Debtor Financing (Bill-Discounting Eligibility)** — `advancePct` (80, KV), `discountRatePct` (13, KV), `tenorDays`, `processingPct` → eligible = AR − overdue; advance = eligible×advance; interestCost = advance×rate×tenor/365; processingCost; effectiveAnnualCost = total/advance×365/tenor; days-of-runway. _Persist: KV — `wc-debtorfin-advance`, `wc-debtorfin-rate` (tenor/processing transient)._ _Class: KV._
- **Creditor Stretch (Creditor-Stretch Impact)** — `extraDays`, `msmeSharePct` (30) → dailyPurchases = payables/DPO; cashFreed = dailyPurchases×extraDays; newDPO, newCCC; MSME 43B(h) risk if newDPO>45 (msmeAtRisk = payables×share); annualSaving = freed×14%. _Persist: none._ _Class: Indicative._
- **WC Turnover** — snapshot → annualRevenue = monthlyRevenue×12; NWC = AR+inventory−payables; turnover = revenue/NWC; WC per ₹ sales; efficiency band (≥6/≥4/≥2.5/<2.5); leaner-by-10-days scenario. _Persist: live store (derived)._ _Class: Indicative._
- **Factoring vs OD** — `need`, `tenorDays`, `odRatePct` (14), `factorRatePct` (12), `factorFeePct` (1), `recourse` → odCost = amt×odRate×tenor/365; factorCost = amt×factorRate×tenor/365 + amt×fee; effective annualised each; cheaper-of verdict + recourse note. _Persist: none._ _Class: Indicative._
- **Operating Cycle Breakdown** — snapshot → operatingCycle = DSO+DIO; supplierFunded = min(DPO, cycle); selfFunded = max(0, cycle−DPO); supplierCover%; selfFundedCash = daily opex × selfFunded; segment bars. _Persist: live store (derived)._ _Class: Indicative._
- **Current-Ratio Planner** — `targetRatio` (1.5) → ratio = CA/CL (CA = cash+AR+inventory, CL = payables+dues≤90d); Lever A extraAssets = target×CL − CA; Lever B paydown = CL − CA/target; meets-target headroom. _Persist: none._ _Class: Indicative._
- **Terms Gap (Supplier vs Customer)** — snapshot → termsGap = DSO − DPO; gapCash = daily opex × |gap|; favourable if ≤0 (free float) else cash you bridge; DSO/DPO rows. _Persist: live store (derived)._ _Class: Indicative._
- **WC Efficiency Score** — snapshot → composite 0–100 of four 0–25 sub-scores: CCC (0d→25, 90d→0), receivables quality (0%→25, 40% overdue→0), supplier-credit cover (DPO ÷ operating cycle ×25), current ratio (1.5x→25, 0.5x→0); grade Excellent/Healthy/Average/Strained; driver bars. _Persist: live store (derived)._ _Class: Indicative._

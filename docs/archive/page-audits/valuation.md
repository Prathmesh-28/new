# Valuation & Cap Table (`/valuation`) — 23 tools

One-sentence purpose: Turn the firm's live financials into a defensible valuation range (multiples + DCF) and a full suite of fund-raising / cap-table / equity calculators so a founder can model dilution, term-sheet mechanics, ESOP economics and investor returns. Stakeholders: owner, investor. Backend: KV-synced (live financial snapshot from `store` via `computeFinancialSnapshot`; only the Dilution Waterfall persists records via `useFeatureState` → `store.featureData` KV).

Section quick-nav lists 20 anchor entries; the page also renders three always-on top-of-page tools (headline KPI strip, assumptions sliders + method chart, DCF table, dilution panel) before the navigable sections — 23 distinct tools total below.

## Always-on top tools (not in the anchor nav)

- **Indicative Valuation Range (headline + assumptions + method chart)** — inputs: live `annualRevenue` (3-mo avg revenue × 12), `baseFcf` (max(monthlyNet,0)×12), industry default multiple (`INDUSTRY_MULTIPLES`, fallback 3x), user sliders revenue-multiple (0.5–15x), DCF annual growth (0–100%), discount/risk rate (10–40%) → computation: `multipleVal = annualRevenue × multiple`; `dcf.enterpriseValue` via `dcfValuation` (5-yr explicit FCF growth then discounted, plus 4% perpetual-growth terminal value, terminal cap at discount−1%); blended midpoint = (multipleVal + DCF EV)/2; football-field range low = min(×, DCF)×0.85, high = max(×, DCF)×1.15. Warns + uses 10%-of-revenue FCF proxy if not yet FCF-positive → output: KPI cards (annual revenue, indicative valuation + range, implied multiple, raised-so-far from confirmed `capitalInvestments`), horizontal bar chart by method, football-field range bar. _Persist: none (live store snapshot; slider state local useState)._ _Class: Indicative._
- **5-Year DCF Table** — inputs: same DCF assumptions (baseFcf proxy, growth, discount) → computation: per-year projected FCF, discount factor (pv/fcf), present value; terminal value at 4% perpetual growth discounted back; enterprise value = Σ PV + terminal PV (`dcfValuation`) → output: year-by-year table with terminal-value and enterprise-value rows. _Persist: none (live)._ _Class: Indicative._
- **Dilution at this Valuation** — inputs: blended-midpoint pre-money, amount-to-raise slider (₹5L–₹5Cr, seeded from active/draft `capitalRaise.targetAmount`) → computation: `dilution(preMoney, raise)` → postMoney = pre + raise, investorPct = raise/post, founderRetainedPct = 100 − investorPct; flags >25% investor stake as aggressive → output: pre/post-money + investor-stake cards, founder-retained note, nav buttons to `/capital` and `/credit`. _Persist: none (live + local slider)._ _Class: Indicative._

## Navigable section tools

- **Comparable-Company Multiples** (#109) — inputs: sector select (`SECTOR_MULTIPLES` rev & EBITDA low/high bands per industry), annual revenue, annual EBITDA (auto-filled from run-rate), basis toggle revenue/EBITDA → computation: low/mid/high = input × sector multiple band (mid = average of low & high) → output: low/mid/high value cards + bar chart; 20–35% private-company liquidity-discount caveat. _Persist: none (local useState)._ _Class: Indicative._
- **Berkus / Scorecard (Pre-Revenue)** (#110) — inputs (Berkus): five risk-reduction factor sliders (idea/prototype/team/relationships/rollout, ₹0–₹5L each); inputs (Scorecard): regional-median pre-money + seven weighted factor sliders (0–200% vs median) → computation: Berkus pre-money = Σ factor values (₹25L cap); Scorecard = median × Σ(weight × score/100) → output: Berkus or Scorecard pre-money valuation card. _Persist: none (local useState)._ _Class: Indicative._
- **DCF Sensitivity / Tornado** (#111) — inputs: live DCF base (FCF, growth, discount), assumption-swing slider (±5–50%) → computation: re-runs `dcfValuation` flexing each driver (FCF growth rate, discount rate inverse, base-year FCF) by ±swing, computes high−low range per driver, sorts by impact → output: base EV + sorted tornado bars (downside red / upside green). _Persist: none (live + local slider)._ _Class: Indicative._
- **409A-style FMV for ESOP** (#112) — inputs: equity value (from blended midpoint), fully-diluted shares, liquidation-preference stack, DLOM slider (0–50%) → computation: commonEquity = max(0, equity − pref); adjustedCommon = commonEquity × (1−DLOM); FMV/share = adjustedCommon/shares; raw/share = equity/shares → output: common-equity, after-DLOM, FMV/share (409A), undiscounted/share cards; appraiser/strike-price disclaimer. _Persist: none (local useState; equity seeded from live midpoint)._ _Class: Indicative._
- **VC Method — Exit-Value Backsolve** (#vc-method) — inputs: round size (seeded from raise), exit EV/Revenue multiple, investor target return (x), years-to-exit (2–10), revenue CAGR to exit (0–120%) → computation: exitRevenue = baseRev × (1+CAGR)^years; exitValue = exitRevenue × exitMultiple; post-money today = exitValue/targetReturn; investorOwnership = raise/postMoneyToday; pre-money = post − raise; implied IRR = (exitValue/postToday)^(1/years)−1 → output: exit value, post-money/pre-money today, investor stake cards + implied annual IRR. _Persist: none (local; revenue from live snapshot)._ _Class: Indicative._
- **First-Chicago Method** (#first-chicago) — inputs: best/base/worst-case valuations (seeded ×2.5 / ×1 / ×0.3 of midpoint), best & base probability sliders (worst = remainder) → computation: expected = Σ(value × probability)/100 → output: per-scenario contribution rows + expected (probability-weighted) valuation. _Persist: none (local; seeded from live midpoint)._ _Class: Indicative._
- **Runway → Next-Round Planner** (#runway-planner) — inputs: cash-in-bank (live `snap.cash`), net monthly burn (live, from negative monthlyNet else ₹5L), time-to-close-raise slider (2–9 mo), safety-buffer slider (0–6 mo) → computation: runwayMonths = cash/burn; startInMonths = max(0, runway − closeTime − buffer); cashAtClose = cash − burn×(start+close); status ok/soon/urgent → output: current-runway, start-raising-in, cash-at-close cards + colored status banner. _Persist: none (live + local sliders)._ _Class: Indicative._
- **Dilution Waterfall** (#dilution-waterfall) — inputs: editable list of rounds (name, pre-money, raise; seeded Seed + Series A from live midpoint), add/remove rounds → computation: walks rounds, per round post = pre+raise, newInvestorPct = raise/post, founderPct compounds × (1−newInvestorPct); final founder ownership after all rounds → output: editable table (post-money, new stake, founder-after per round) + final founder-ownership card; warns below 50%. _Persist: `featureData["val-dilution-waterfall"]` (KV-synced via `useFeatureState`)._ _Class: Backend (KV)._
- **Option-Pool Shuffle** (#pool-shuffle) — inputs: pre-money, round size, target-pool % (0–25% of post-money), pre/post-money timing toggle → computation: investorPct = raise/post; pre-money pool dilutes founders only (poolFromFounders = poolPct); post-money pool shared (poolPct × (1−investorPct)); founderPct = 100 − investor − poolFromFounders; investorEff adjusted in post case → output: founder/investor/option-pool stake cards + who-pays-for-pool note. _Persist: none (local; seeded from live midpoint & raise)._ _Class: Indicative._
- **Convertible-Note Cap / Discount Converter** (#note-converter) — inputs: note principal, valuation cap, next-round pre-money, shares-before-round, discount %, interest %/yr, months → computation: accrued interest = inv × rate × months/12; roundPrice = pre/shares; discountPrice = roundPrice × (1−disc); capPrice = cap/shares; conversion price = lower (better for noteholder); shares issued = (principal+interest)/finalPrice; post-conversion ownership → output: principal+interest, round/conversion price-per-share, shares-to-noteholder cards; flags whether cap or discount won. _Persist: none (local; cap/pre seeded from live midpoint)._ _Class: Indicative._
- **ESOP Grant Value Calculator** (#esop-grant) — inputs: options granted, total fully-diluted shares, strike price/share, equity value (live midpoint), exit-growth multiplier (1–20x) → computation: pricePerShare = equity/total; grossNow = options × price; exerciseCost = options × strike; netNow = max(0, gross − cost); ownership% = options/total; exitPrice = price × exitX; netAtExit = max(0, options × exitPrice − cost) → output: ownership, gross-value-today, net-of-exercise, net-at-exit cards + perquisite-tax note. _Persist: none (local; equity from live midpoint)._ _Class: Indicative._
- **Founder Vesting Schedule** (#vesting-schedule) — inputs: founder shares under vesting, vest length (mo), cliff (mo), months-elapsed slider → computation: vestedNow = 0 before cliff else min(total, total×elapsed/totalMonths); vestedPct; unvested; milestone schedule (cliff + yearly checkpoints + full-vest) → output: vested-now / vested-% / unvested cards, progress bar with cliff marker, milestone table; pre-cliff forfeiture warning. _Persist: none (local useState)._ _Class: Indicative._
- **Rule of 40 Score** (#rule-of-40) — inputs: revenue growth % (live growth) + profit/EBITDA margin % (live net/revenue margin) → computation: score = growth + margin; passes if ≥40; impliedMultiple = clamp(2 + score×0.18, 0.5–14); impliedVal = annualRevenue × multiple → output: pass/below score banner (green/yellow/red bands) + implied EV/Revenue and implied valuation cards. _Persist: none (live snapshot + local inputs)._ _Class: Indicative._
- **Liquidation-Preference Stack** (#liq-pref-stack) — inputs: exit/sale value (live midpoint), preferred capital invested, investor ownership %, preference multiple slider (1–3x), participating/non-participating toggle → computation: pref = invested × multiple; non-participating = min(exit, max(pref, exit×ownership)); participating = min(exit, pref + (exit−pref)×ownership); founderProceeds = exit − investor; investor return-x; breakeven exit = pref/ownership → output: preference-amount, investor-proceeds, founder/common, investor-return-x cards + proceeds split bar + regime explanation. _Persist: none (local; exit seeded from live midpoint)._ _Class: Indicative._
- **Secondary-Sale Capital-Gains Tax** (#secondary-tax) — inputs: shares sold, cost/share, sale price/share (seeded from midpoint), holding-period slider (1–60 mo), high-income surcharge select (0/10/15/25%) → computation: gain = max(0, proceeds − costBasis); long-term if >24 mo; baseRate = 12.5% LTCG (unlisted, post-Jul-2024) else 30% STCG; effectiveRate = baseRate × (1+surcharge) × 1.04 cess; tax = gain × rate; net = proceeds − tax → output: gross-gain, effective-rate, tax-payable, net-in-hand cards + CA-confirm disclaimer. _Persist: none (local; sale price from live midpoint)._ _Class: Indicative._
- **Down-Round & Anti-Dilution Impact** (#down-round) — inputs: last-round post-money (live ×1.2), prior investor ownership %, new-round pre-money (live ×0.6), new round size, protection toggle none/weighted-average/full-ratchet → computation: isDown if newPre < prevPost; drop %; newInvestorPct = raise/newPost; naive old-investor % = prevOwn × (1−newInvestorPct); weighted-average pulls ~halfway back to prior %; full-ratchet ≈ prior × 0.95 reset; founderShare = 100 − protected − newInvestor → output: up/down-round banner + new-investor / old-investor (naive & after-clause) / founder-left stake cards + clawback note. _Persist: none (local; seeded from live midpoint)._ _Class: Indicative._
- **Investor MOIC / IRR** (#investor-moic) — inputs: amount invested (live raise), post-money this round (live mid+raise), exit/sale value (live ×6), years-to-exit slider (1–12), future-dilution slider (0–70%) → computation: entryPct = inv/post; exitPct = entry × (1−futureDilution); exitProceeds = exit × exitPct; MOIC = proceeds/inv; IRR = MOIC^(1/years)−1; simplistic payback = years/moic → output: entry-stake, stake-at-exit, MOIC, gross-IRR cards (tone by 3x / 25% thresholds) + exit-proceeds + recovery note. _Persist: none (local; seeded from live values)._ _Class: Indicative._
- **EV → Equity Value Bridge** (#ev-ebitda-bridge) — inputs: enterprise value (live DCF EV), total debt, cash & equivalents (live cash), minority interest → computation: netDebt = debt − cash; equityValue = EV − netDebt − minority → output: stepped bridge rows (+EV, −debt, +cash, −minority) + equity-value-to-shareholders card with net-debt/cash position. _Persist: none (live EV + cash, local debt/minority)._ _Class: Indicative._
- **ARR-Multiple Valuation** (#arr-multiple) — inputs: annual recurring revenue (live run-rate), YoY growth (live), net-revenue-retention slider (70–150%), gross-margin slider (30–95%) → computation: multiple = max(0.5, 6x anchor + growthAdj ((g−30)/30×2) + nrrAdj ((nrr−100)/10×0.6) + marginAdj ((gm−70)/10×0.4)); valuation = ARR × multiple; conservative/base/premium tiers (×0.75 / ×1 / ×1.25) → output: quality-adjusted valuation card + tier bar chart; >10x caveat. _Persist: none (live ARR/growth + local sliders)._ _Class: Indicative._
- **Discounted-Payback Period** (#discounted-payback) — inputs: up-front investment (live FCF ×2), discount-rate slider (1–40%, live default), horizon slider (3–15 yrs) → computation: per-year cf = baseFcf × (1+growth)^(y−1); pv = cf/(1+rate)^y; cumulative discounted & undiscounted; payback = interpolated year where cumulative crosses investment (Infinity if never) → output: discounted-payback vs simple-payback cards + per-year cash-flow / PV / cumulative-PV table (crossing year highlighted). _Persist: none (live FCF/growth + local inputs)._ _Class: Indicative._

---

Notes:
- Every tool is calculator-style and renders client-side. Inputs auto-seed from the live financial snapshot (`computeFinancialSnapshot(store)`) and the active/draft capital raise, but slider/field state is transient `useState` and does NOT persist — except the Dilution Waterfall, the only tool that writes durable records to the KV-synced `store.featureData` (key `val-dilution-waterfall`).
- Core engine helpers live in `src/lib/finance.ts`: `dcfValuation` (5-yr DCF + Gordon-growth terminal value, terminal growth capped at discount−1%), `dilution`, `computeFinancialSnapshot`.
- No backend valuation API exists; all outputs are clearly labeled indicative / sanity-check, with disclaimers on 409A (needs independent appraiser) and secondary-sale tax (confirm with CA).

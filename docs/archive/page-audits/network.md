## B2B Network & Trade Graph (`/network`) — 32 tools

Link every buyer and supplier into one trade graph — confirm invoices both ways, reconcile ledgers, score counterparties, and discover GST-verified partners — all derived from data already in Headroom. Stakeholders: owner, ops, finance. Backend: KV-synced via `useFeatureState` (each tool persists to its own KV key); a live counterparty list is derived in-memory from `store.transactions` + `store.invoices` (inflow/outflow/txns/invoiced per name) and feeds the Overview and most tools' name pickers — never persisted.

The page is a 33-tab switcher (Overview + 32 numbered tools). Below, one bullet per rendered tool, in tab order.

- **Overview** — live counterparty list + KV reads (`net-directory`, `net-trade-refs`, `net-disputes`) → counts buyers (inflow/invoiced>0), suppliers (outflow>0), linked partners, confirmed refs, open disputes; renders 4 KPI cards, a 3-feature explainer, and a top-8 live-counterparty table (money in/out, invoiced, txns). _Persist: live store (read-only)._ _Class: KV._
- **Buyer–Supplier Directory** — name, GSTIN (validated via 15-char `GSTIN_RE`), role (buyer/supplier/both), state; plus "import from books" chips that auto-assign role from inflow/outflow → editable directory with per-row link/unlink toggle (counterparty recon/relationship registry) and role filter → directory table. _Persist: `net-directory`._ _Class: KV._
- **Two-Sided Invoice Confirmation** — open (unpaid) invoices from store + per-invoice status (sent/confirmed/disputed) → counts open/confirmed/awaiting + confirmed value; per-row Confirm/Dispute/Reset (invoice confirmation, both ledgers agree) → status table + KPIs. _Persist: `net-invoice-confirm` (status map); invoices read-only._ _Class: KV._
- **Counterparty Reconciliation** — selected party (pulls their invoices+txns as "my ledger") + pasted statement text parsed `ref,amount` per line → exact-amount greedy matching, my/their totals + difference, flags "not in my books" / "not on their statement" (counterparty recon) → side-by-side match table. _Persist: none (in-memory; party + textarea)._ _Class: Indicative._
- **Trade-Reference Book** — referring party, GSTIN, relationship months, avg days-to-pay, credit extended, note → request→confirm lifecycle, aggregates confirmed count, avg relationship, total vouched credit (credit-signal scorecard input) → reference table for loan/credit-limit applications. _Persist: `net-trade-refs`._ _Class: KV._
- **Network Credit-Signal Scorecard** — live graph + confirmed refs (`net-trade-refs`) + invoice overdue rate → diversity (inverted Herfindahl of buyer revenue share, 25%), counterparty depth (buyers×8+suppliers×6, 25%), confirmed-references (×25, 20%), on-time invoicing (1−overdue/total, 30%) → composite 0–100 + Strong/Moderate/Thin band with factor bars (credit-signal scorecard). _Persist: none (derived); reads live store + KV refs._ _Class: Indicative._
- **Supplier Discovery Shortlist** — supplier name, GSTIN (validated), category, state, ONDC flag, GST rating 0–5, min order, notes; search box → list sorted by GST rating desc, filtered by name/category/state (buyer-supplier directory / sourcing) → ranked prospect cards with star rating + ONDC badge. _Persist: `net-discovery`._ _Class: KV._
- **Dispute Log & Mediation Tracker** — party, invoice ref, disputed amount, reason (preset list), note → open→mediating→resolved lifecycle + per-dispute settlement proposal (shows concession vs original); aggregates open count, value at stake, resolved (counterparty recon / dispute) → dispute cards with age. _Persist: `net-disputes`._ _Class: KV._
- **Top-Counterparty Concentration** — live graph + buyers/suppliers toggle → per-counterparty value (inflow+invoiced or outflow), top-1 share, top-3 share, HHI; warns if top-1 > 30% (concentration) → ranked bars + warning banner. _Persist: none (derived from live store)._ _Class: Indicative._
- **Payment-Behaviour Rating** — store invoices grouped per customer → overdue rate + worst aging; score = 100 − overdueRate×60 − min(40, worstDays/3), graded A/B/C/D (payment-reliability scorecard) → private per-buyer grade table. _Persist: none (derived from invoices)._ _Class: Indicative._
- **Shared-Balance Confirmation Generator** — selected party + as-on date + manual adjustment; firm details from store → open AR balance (unpaid invoices for party + adj), Dr/Cr direction → auto-drafted year-end balance-confirmation letter, copy-to-clipboard (counterparty recon / audit). _Persist: none (in-memory)._ _Class: Indicative._
- **Partner Onboarding Checklist** — new party + GSTIN (validated) → runs each through a fixed 8-step KYB/verification/terms/ledger-linking checklist with per-step toggles and % complete bar (onboarding) → progress cards. _Persist: `net-onboarding`._ _Class: KV._
- **Trade-Terms Agreement Tracker** — party, credit days, credit limit, early-pay disc %, late penalty %/mo, effective-from, review-on, note → draft→agreed lifecycle, flags terms due for review within 14 days (trade-terms registry feeding aging/reminders) → terms table. _Persist: `net-trade-terms`._ _Class: KV._
- **Joint-Reconciliation Statement Export** — selected party + as-on date; pulls party invoices (debit) + txns (credit/debit by sign) from store → chronological statement of account with running balance, debit/credit/closing totals; export CSV + copy (counterparty recon) → statement table with running balance. _Persist: none (derived); party in-memory._ _Class: Indicative._
- **Counterparty Payment-History Timeline** — selected party → chronological feed of that party's invoices + payments (in/out/invoice) from store, with money-in/out, event count, relationship months since first seen (payment-history) → vertical timeline. _Persist: none (derived from store)._ _Class: Indicative._
- **Network Referral Tracker** — referred-by, new party, expected value, reward type (discount/cash/credit-note/none), reward amount → pending→converted→rewarded lifecycle; aggregates pipeline value, conversion, rewards owed (referral/network growth) → referral table. _Persist: `net-referrals`._ _Class: KV._
- **Shared Price-List Manager** — SKU, item, unit, price, GST% → versioned catalog (version date bumps on add/remove); computes incl-GST price, catalog list value; export CSV with version header (price-list / dispute prevention) → item table + KPIs. _Persist: `net-price-list` (items) + `net-price-list-version`._ _Class: KV._
- **Partner SLA Scorecard** — partner, on-time %, quality %, responsiveness % (all clamped 0–100), orders → weighted score (delivery 40% + quality 40% + responsiveness 20%), graded A/B/C/D (supplier SLA scorecard) → per-partner scorecards with metric bars. _Persist: `net-sla`._ _Class: KV._
- **Group-Buy / Consortium Calculator** — solo price, group price, min-qty tier + pool members (name, qty) → checks if pooled qty clears tier, effective price, per-member solo vs group cost and savings, total pool saving (group-buy / volume tier) → member breakdown table. _Persist: none (in-memory; members seed with "My firm")._ _Class: Simulated._
- **Warm-Intro / Connection Requester** — connector (existing partner), target, reason/context, tone (formal/friendly); firm name from store → composes a ready-to-send intro-request message; copy-to-clipboard (intro/network growth) → message preview. _Persist: none (in-memory)._ _Class: Indicative._
- **Partner Risk Watchlist** — party, risk level (low/medium/high), distress signal (preset list), action; exposure auto-pulled from party's open invoices → flags counterparties, inline risk re-grading; aggregates count, high-risk count, high-risk exposure (early-warning / counterparty risk) → watchlist cards. _Persist: `net-watchlist` (exposure snapshotted at add from live invoices)._ _Class: KV._
- **Networking Event / Meeting Log** — party, date, channel (call/video/in-person/event), summary, follow-up → CRM-style interaction log with follow-up done toggle; counts interactions + open follow-ups (relationship CRM) → meeting cards. _Persist: `net-meetings`._ _Class: KV._
- **Mutual-Credit Netting Calculator** — per partner: they-owe-me, I-owe-them → net position, gross vs net settlement, payments avoided, settlement reduction %, who-pays direction (mutual-credit netting) → netting table + KPIs. _Persist: `net-netting`._ _Class: KV._
- **Partner-Tier Scheme** — editable tier bands (Bronze/Silver/Gold/Platinum: min volume + perk, seeded with defaults) → assigns each live counterparty a tier by total trade value (inflow+outflow+invoiced), counts per tier (partner-tier loyalty scheme) → partners-by-tier table (top 20). _Persist: `net-tier-scheme` (band config); tiering derived from live store._ _Class: KV._
- **Payment-Terms Benchmark** — per partner: agreed days, actual days + a sector reference (days) → per-partner slippage (actual−agreed) and vs-sector gap; network avg agreed/actual/slippage, sorted worst-first (terms benchmark / renegotiation) → benchmark table. _Persist: `net-terms-bench` (entries); sector ref in-memory)._ _Class: KV._
- **Co-Marketing / Joint-Campaign Planner** — partner, title, channel (WhatsApp/Email/ONDC/etc.), my budget, their budget, date → planned→live→done cycle; totals my/their/combined committed spend (co-marketing / shared budgets) → campaign cards + KPIs. _Persist: `net-co-market`._ _Class: KV._
- **Introductions Ledger** — direction (given/received), connector, to-whom, note → outcome (pending/deal/dropped) per intro; computes given vs received reciprocity balance and deal count (intros given/received ledger) → ledger table. _Persist: `net-intros-ledger`._ _Class: KV._
- **Collaborative-Forecast Sharing** — supplier, month, forecast qty, last actual → % change vs last actual; totals forecasts shared, total forecast qty, suppliers covered (demand-forecast sharing / bullwhip) → forecast table. _Persist: `net-forecast-share`._ _Class: KV._
- **Partner NPS** — partner, score 0–10, comment → categorizes promoter (≥9)/passive(7–8)/detractor(≤6) and computes Net Promoter Score = (promoters−detractors)/n × 100 (partner satisfaction) → NPS KPIs + entry table. _Persist: `net-partner-nps`._ _Class: KV._
- **Partner Spend-Share Trend** — selected supplier; store outflow transactions grouped by month (last 12) → that supplier's share of monthly spend, latest share, month-on-month pp delta, latest spend (concentration / spend-share trend) → monthly share bars. _Persist: none (derived from store transactions)._ _Class: Indicative._
- **Joint-Venture P&L Split** — JV partner, revenue, cost, my-share % (clamped 0–100), note → profit (revenue−cost), my P&L (profit×share), their P&L (remainder) per deal (JV P&L split / settlement) → split table. _Persist: `net-jv-split`._ _Class: KV._
- **Partner Payment-Reliability** — store invoices grouped per buyer → on-time % (paid / (paid+overdue)), avg days late, reliable flag (≥80% on-time and ≤7d avg late); sorted least-reliable first (payment-reliability) → reliability ranking table with bars. _Persist: none (derived from invoices)._ _Class: Indicative._

## Receivables (`/receivables`) — 23 tools

Track outstanding invoices and chase overdue payments while scoring debtors, provisioning losses, and forecasting collections. Stakeholders: finance, sales. Backend: KV-synced (reads live invoices).

- **Overview** — live `store.invoices` (split into pending/paid) → aging buckets via `agingBucket(daysOverdue)` (current ≤0, 30d ≤30, 60d ≤60, 90d >60) with per-bucket count+amount, total outstanding, list/kanban views, per-invoice chase (mailto reminder via `chaseMessage`)/mark-paid/delete, paid list, and a Customer Payment DNA leaderboard (score = pay-rate × 60% + speed component `max(0,40−avgDaysLate×2)`, banded Excellent/Good/Fair/Poor) → outstanding overview + per-customer reliability. _Persist: live store (invoices via addInvoice/updateInvoice/deleteInvoice)._ _Class: Backend._
- **Customer Risk Scoring** (`risk-score`) — per-customer invoice groups → exposure (open sum), payRate (paid/total), avgDaysLate (paid invoices), worstOverdue (open max) → score = payRate×0.45 + lateScore `max(0,30−avgDaysLate×0.6)` + overdueScore `max(0,25−worstOverdue×0.4)`, banded Low/Medium/High/Severe → ranked risk table + total/at-risk exposure. _Persist: live store (read-only)._ _Class: Indicative._
- **Factoring / Discounting Estimator** (`factoring`) — selected open invoices (face) + advance rate %, discount % p.a., service fee %, tenor days → advanced = face×adv; discountCost = advanced×rate×(days/365); serviceFee = face×fee; netProceeds = face−totalCost; effectiveCostPct = totalCost/face; annualisedPct = (totalCost/advanced)×(365/days) → proceeds waterfall + effective/annualised cost. _Persist: none (local component state)._ _Class: Simulated._
- **Cash Application** (`cash-app`) — live `store.transactions` (revenue inflows, positive, unapplied) matched against open invoices via normalised name/invoice-number + amount: exact (name/num hit AND |Δ|≤1), likely (name hit OR amount within 2%), none → suggested/unmatched lists; Apply records invoiceId→txnId link. _Persist: KV `receivables-cash-applied` (useFeatureState)._ _Class: KV._
- **Concentration Risk** (`concentration`) — open invoices grouped by customer + alert threshold % → per-customer share, top1, top3, HHI = Σ(share%²) (>2500 highly concentrated) → breach alert + AR-by-customer bars. _Persist: none (threshold local state)._ _Class: Indicative._
- **AR Confirmation Mailer** (`ar-confirm`) — open balances grouped by customer + per-customer contact + as-of date + firm name → builds auditor-style positive-confirmation letter with invoice breakdown → opens mailto/WhatsApp draft, logs send timestamp. _Persist: KV `receivables-ar-contacts` + `receivables-ar-confirm-sent` (useFeatureState)._ _Class: KV._
- **DSO Trend** (`dso-trend`) — invoices over trailing 6 months → per-month: AR open at month-end ÷ that month's billed credit sales × days-in-month = DSO → current/MoM-delta/6-mo-avg + bar chart. _Persist: live store (read-only)._ _Class: Indicative._
- **AR Turnover** (`ar-turnover`) — invoices + window days → netSales (billed in window), avgAR proxy = (openAR + min(openAR,billed))/2, turnover = netSales/avgAR, annualised ×(365/days), implied DSO = 365/annualised, graded Strong/Healthy/Slow/Weak → turnover ratio + DSO. _Persist: none (window local state)._ _Class: Indicative._
- **ECL Provisioning** (`ecl-matrix`) — open invoices bucketed by aging + editable loss % per bucket → ecl = gross×rate/100 per bucket; net carrying = gross−ecl; blended = eclTotal/grossTotal (simplified Ind-AS 109/IFRS 9 provision matrix) → provision matrix table. _Persist: KV `rec-ecl-rates` (useFeatureState)._ _Class: KV._
- **Credit Utilization** (`credit-util`) — open exposure per customer + editable per-customer credit limit → util = exposure/limit×100, headroom = limit−exposure, status ok/near(≥80%)/over(≥100%)/unset → utilization bars + over/near/unset counts. _Persist: KV `rec-credit-limits` (useFeatureState)._ _Class: KV._
- **Collection Forecast** (`cash-timeline`) — open invoices + per-customer avg pay-lag (learned from paid history) → expected pay date = due + lag, bucketed into 8 weeks (or overdue), expected8w sum → weekly cash-landing bar chart. _Persist: live store (read-only)._ _Class: Indicative._
- **Overdue Heatmap** (`overdue-heatmap`) — open invoices → per-customer × aging-bucket amount matrix (top 12 by total), cell intensity scaled by amount/maxCell, hue by bucket → customer × bucket heatmap. _Persist: live store (read-only)._ _Class: Indicative._
- **Dunning Funnel** (`dunning-funnel`) — open invoices placed by days-past-due into stages not-due/reminder(1–15)/follow-up(16–30)/escalation(31–60)/final-demand(60d+) → per-stage count+amount, actionable sum, per-stage "Chase" toast (queue prompt) → staged funnel bars. _Persist: live store (read-only); chase is a toast prompt only._ _Class: Indicative._
- **Promise-to-Pay** (`promise-to-pay`) — select open invoice + promised date/amount/note → logs promise; row state derived: kept (invoice paid), broken (date passed unpaid), upcoming (dueIn days); promisedAmt = sum of open promised → tracked-promises list + kept/broken/promised totals. _Persist: KV `rec-promise-to-pay` (useFeatureState)._ _Class: KV._
- **Dispute Tracker** (`disputes`) — select open invoice + disputed amount + reason → disputed = min(amount, invoice), chaseable = invoice−disputed; toggle open/resolved → quarantined vs still-chaseable totals + dispute list. _Persist: KV `rec-disputes` (useFeatureState)._ _Class: KV._
- **Early-Pay Discount** (`early-discount`) — open invoices + discount %, window days, net days → implied APR = (disc/(1−disc))×(365/(net−window))×100; per-invoice dso (since invoice date), eligible if dso ≤ window, discountAmt = amount×disc, netIfTaken; offered/cost-if-all-taken sums → APR + per-invoice offers. _Persist: none (params local state)._ _Class: Simulated._
- **Credit-Hold List** (`credit-hold`) — open invoices per customer (exposure, worst overdue) + overdue-days threshold + shared credit limits → flags tooOverdue (worst ≥ threshold) or overLimit (exposure > limit); hold unless cleared; override toggle → stop-shipping candidate list + held exposure. _Persist: KV `rec-credit-hold-cleared` (write) + reads `rec-credit-limits` (useFeatureState)._ _Class: KV._
- **Write-Off Policy** (`write-off`) — open invoices + doubtful-after days policy → candidates where daysOverdue ≥ threshold; tick to approve write-off; candidate/approved/pending totals → uncollectible candidate list (local intent-to-write-off audit trail). _Persist: KV `rec-writeoff-policy-days` + `rec-writeoff-approved` (useFeatureState)._ _Class: KV._
- **Payment Timeline** (`pay-timeline`) — invoices for selected customer → per-invoice lateness = max(0, days past due) (paid settlement approximated at today, no paidDate in model), avgLate (paid), onTime count → days-to-pay history bars + stats. _Persist: live store (read-only); selection local state._ _Class: Indicative._
- **Days Beyond Terms** (`days-beyond-terms`) — open invoices per customer → value-weighted DBT = Σ(dbt×amount)/Σamount, worst, count; portfolio weighted DBT across all → per-customer DBT ranking. _Persist: live store (read-only)._ _Class: Indicative._
- **Reliability Ranking** (`reliability-rank`) — all invoices per customer → onTimeRate = onTime/paid, overduePenalty = min(0.4, openOverdue×0.1), score = max(0, (onTimeRate−penalty)×100) → ranked reliability leaderboard. _Persist: live store (read-only)._ _Class: Indicative._
- **Overdue Interest** (`interest-accrual`) — open invoices + interest % p.a. + grace days → per overdue invoice: overdue = max(0, daysPastDue−grace), interest = amount×rate×(overdue/365) simple interest; total accrued + overdue principal → claimable-interest list (MSMED-Act framing). _Persist: KV `rec-interest-rate-pa` + `rec-interest-grace` (useFeatureState)._ _Class: Indicative._
- **Collection Target** (`collection-target`) — invoices + monthly target → collected = paid invoices dated this month, dueThisMonth = open invoices due this month, pct = collected/target, gap = max(0, target−collected) → progress bar + gap/due cards + check-progress toast. _Persist: KV `rec-collection-target` (useFeatureState)._ _Class: KV._

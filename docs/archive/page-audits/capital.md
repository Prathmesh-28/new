## Capital (`/capital`) — 5 tools

Founder-facing fundraising suite: run live equity/revenue-share raises and model runway, instruments, grants, and capital deployment. Stakeholders: owner, investor. Backend: `/api/capital` + KV.

Tabs (`capTab` array, line 75): `raises` (Raises), `runway` (Runway Planner), `safe` (SAFE / Note Modeller), `grants` (Grant / Subsidy Finder), `use-of-funds` (Use of Funds).

- **Raises** — track select (rev_share $10K–$500K / reg_cf up to $5M / reg_a_plus up to $75M) + target amount (₹), validated >0 → `addCapitalRaise` creates draft; Publish flips status to `active` (investor portal live); + Investor (active only) records investor email + amount, computes `equityPct = (amount / targetAmount) * 10` (flat indicative formula), sets investment status `pending`, increments `raisedAmount` via `updateCapitalRaise` → stats (active raises, total raised, total investors), per-raise progress bar (% funded, investor count) and investor list with amount/equity/status → output. _Persist: live store via AppContext (`addCapitalRaise`/`updateCapitalRaise`/`addCapitalInvestment`, `capitalRaises`/`capitalInvestments`)._ _Class: Backend._

- **Runway-Extension Planner** (#105) — cash on hand, monthly burn, target runway (months, default 18), cost-cut lever (%, clamped 0–100), capital-raise lever (₹); cash pre-filled from sum of all transaction amounts, burn pre-filled from last-90-day avg monthly outflow → `adjustedBurn = burn*(1-cut/100)`, `baseRunway = cash/burn`, `newRunway = (cash+raise)/adjustedBurn`, `hitsTarget`, and gap solvers: `cashNeeded = max(0, target*adjustedBurn - cash)` and `cutNeeded = (1 - (cash/target)/burn)*100` → 4 metric cards (current runway, adjusted burn, projected runway, vs target ±mo) + green/orange verdict banner listing the extra-raise or extra-cut needed to close the gap. _Persist: none (transient `useState`; reads live `store.transactions`)._ _Class: Indicative._

- **SAFE / Convertible-Note Modeller** (#106) — instrument toggle (SAFE/Note), investment, valuation cap, discount % (clamped 0–100), priced-round pre-money, pre-round FD shares (default 10M), plus note-only interest p.a. % (default 8) and term-to-conversion yrs (default 1.5) → notes accrue `principalPlusInterest = inv*(1+(intR/100)*yrs)` (SAFE = inv); `roundPPS = round/shares`, `discountPPS = roundPPS*(1-disc/100)`, `capPPS = cap/shares`, converts at lower of the two; `sharesIssued = amount/conversionPPS`, `effValuation = conversionPPS*shares`, `ownershipPct = sharesIssued/(shares+sharesIssued)*100`, `usedCap` flag → 4 cards (amount converting, conversion price/sh, shares issued, ownership) + narrative banner stating cap-vs-discount path and effective pre-money. _Persist: none (transient `useState`)._ _Class: Indicative._

- **Grant / Subsidy Finder** (#107) — MSME profile inputs: category (micro/small/medium), years in operation, and 7 toggles (Udyam, manufacturing, women-led, SC/ST, exporter, upgrading tech, DPIIT startup) → filters a hardcoded 8-scheme catalog (CGTMSE, PMEGP, CLCSS, Startup India Seed Fund, Stand-Up India, MSE-CDP/Export Promotion, State Capital-Investment Subsidy, State Power-Tariff/SGST Reimbursement) by per-scheme `test(profile)` predicates → matched-count header + cards (Central/State badge, benefit, "why you qualify") with empty-state Udyam nudge. _Persist: none (transient `useState`; static `GRANT_SCHEMES` array)._ _Class: Indicative._

- **Use-of-Funds Tracker** (#108) — total capital raised (₹) + add-allocation form (category, committed ₹, deployed ₹); validates category non-empty, committed >0, deployed ≤ committed → `totalCommitted`/`totalDeployed` sums, `uncommitted = raised - committed`, `remaining = committed - deployed`, per-line deployed % → 4 cards (committed, deployed, remaining, uncommitted color-flips red if negative) + over-committed warning banner + allocation table with progress bars and per-row delete. _Persist: KV — `useFeatureState("capital-use-of-funds", [])` for lines and `useFeatureState("capital-total-raised", "")` for the raised total._ _Class: KV._

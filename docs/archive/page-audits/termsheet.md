## Term Sheet (`/term-sheet`) — 18 tools

Model a fundraise and the deal mechanics around it (dilution, liquidation, control, vesting, conversion) and produce a ready-to-share, non-binding term sheet. Stakeholders: owner (founder), investor. Backend: KV-synced (only the readiness checklist persists via `store.featureData`; all other tools are stateless in-component `useState`).

- **Generator** — company, investor, investment, round type (priced / SAFE / convertible / rev-share), pre-money, valuation cap, discount %, interest % p.a., maturity months, new option-pool %, rev-share repayment multiple, liq-pref dropdown (1x non-participating / 1x participating / 1.5x non-participating / None), board-seat + pro-rata toggles → `termSheetMath()` in `@/lib/finance` computes post-money, investor stake %, founder % after, repayment total (rev-share/convertible), conversion note, price-per-share note → live computed-economics cards plus a printable (`window.print()`) non-binding term-sheet document keyed by round type, dated today, valid 30 days. Company prefilled from `store.firm`. _Persist: none (form state only; firm name read from store)._ _Class: Indicative._
- **Offer Comparator** — 2-3 editable offers (investor, investment, pre-money, liq-pref ×, participating, new pool %, board seats, pro-rata) → per offer: post-money = pre+investment, investor % = inv/post, founder % = 100 − investor − pool (pool created pre-money so it dilutes founders not the investor); "best" heuristics highlight highest pre-money, highest founder %, lowest liq-pref × (non-participating), fewest board seats → side-by-side comparison table with winning cell per row marked ✓. _Persist: none._ _Class: Indicative._
- **Liquidation Pref** — exit value, investor capital, investor ownership %, preference multiple (×), participation cap (×, 0 = uncapped), participating toggle → non-participating takes GREATER of preference or as-converted equity (no double-dip); participating takes pref + pro-rata of remainder, optionally capped at capX×investment; investor payout, return multiple, % of exit, common (founders/ESOP) payout → 4 metric cards + 2-bar investor-vs-common waterfall. Single class assumed. _Persist: none._ _Class: Indicative._
- **ESOP Top-up Impact** — founder %, prior-investor %, current pool %, target pool % (post top-up), post-money valuation → pre-money pool top-up = target − current; founders + prior investors scaled down (existing pool keeps shares) to absorb the increment; founder dilution and founder value diluted (post-money × dilution) → cards + before/after/change stakeholder table; validates inputs total ~100%. _Persist: none._ _Class: Indicative._
- **Clause Explainer** — static 7-clause library (liquidation pref, anti-dilution, drag/tag-along, ROFR, board composition, protective provisions, pro-rata, founder/reverse vesting) each tagged founder-friendly/neutral/watch → accordion expands to what-it-is / why-it-matters / how-to-negotiate. No numeric inputs/computation. _Persist: none._ _Class: Preview (static reference content)._
- **Anti-Dilution** — original price/share, investor preferred shares, pre-round shares outstanding (fully diluted), new round price/share, new money raised → compares No protection vs broad-based weighted-average (CP2 = CP1 × (A+B)/(A+C)) vs full-ratchet (conv price = new price); each yields adjusted conversion price, as-converted shares = origShares×origPrice/CP, bonus shares → table; warns when not a down round (no trigger). _Persist: none._ _Class: Indicative._
- **Pro-Rata Rights** — current ownership %, new round size, new round pre-money → pro-rata cheque = roundSize × ownership; ownership if maintained vs if skipped (diluted = ownership×pre/post); dilution lost → 4 cards + post-money line. _Persist: none._ _Class: Indicative._
- **SAFE vs Priced** — amount to raise, SAFE post-money cap, SAFE discount %, priced-round pre-money, next-round pre (SAFE converts) → SAFE ownership = max(raise/cap, raise/(discountPrice+raise)) reporting which basis (cap vs discount) binds; priced ownership = raise/(pre+raise); founder dilution each path → 4 cards + plain-language verdict (which dilutes less, with India FEMA/CCPS caveat). _Persist: none._ _Class: Indicative._
- **Vesting Schedule** — total grant shares, vesting period (years), cliff (months), months served → nothing vests before cliff, then linear monthly accrual = totalShares × min(m,totalMonths)/totalMonths; vested now, vested %, unvested, monthly accrual → cards + progress bar + sparse milestone table (cliff, each year, now, fully-vested); cliff warning. _Persist: none._ _Class: Simulated._
- **Term-Sheet Checklist** — 11-item default readiness checklist (valuation, 1x non-part liq-pref, weighted-average anti-dilution, board majority, pool sizing, narrowed vetoes, founder vesting, drag threshold, FEMA/CCPS, Section 56(2)(viib) angel-tax, lawyer review); toggle/reset items → done count, % progress bar, all-done banner. _Persist: `featureData["ts-readiness-checklist"]` via `useFeatureState` (localStorage + debounced backend push + cross-device sync)._ _Class: Backend (KV-synced)._
- **Multi-Class Waterfall** — exit value, common ownership % (founders+ESOP), 1-4 editable preferred classes (name, invested, pref ×, participating, seniority) → preferences paid in seniority order (lowest first) capped by remaining exit; class as-converted ownership approximated pro-rata to invested capital over (100−common)%; non-participating class takes greater of pref or as-converted, participating takes pref + share of residual; common = exit − total preferred → seniority-sorted payout table (with basis + % of exit) + common residual row. _Persist: none._ _Class: Indicative._
- **Board Composition** — founder seats, investor seats, independent seats, "independents lean founder" toggle → total, seats for majority = floor(total/2)+1, founder bloc, investor bloc; determines founder-controls / investor-controls / deadlock → 4 cards + colored seat-composition bar + verdict banner (with even-board deadlock note). _Persist: none._ _Class: Indicative._
- **Tranche Planner** — pre-money, 1-5 editable tranches (label, amount, milestone trigger) → total raise, post-money = pre + total, dilution if fully drawn = total/post; cumulative dilution as each tranche lands (all priced at one pre-money) → cards + per-tranche cumulative-in / cumulative-dilution table. _Persist: none._ _Class: Indicative._
- **Note Maturity** — principal, interest % p.a., term months, valuation cap, discount %, maturity pre-money → simple accrued interest = principal×rate×years, balance = principal+interest; three scenarios: (1) repay cash = balance, (2) convert at lower of cap or discounted price (pre×(1−disc)) → ≈ balance/(convVal+balance) stake, reporting binding basis, (3) extend +12 months → grown balance → 3 metric cards + 3 scenario rows. Simple (non-compounded) interest. _Persist: none._ _Class: Indicative._
- **Dilution Over Rounds** — starting founder %, eventual exit value, 1-5 editable rounds (name, new investor %, new pool %) → each round scales existing holders by (1 − investor% − pool%) so founder ownership compounds down; final founder %, total dilution, founder value at exit = exit × final% → cards + per-round before/(investor+pool)/after table with bars. _Persist: none._ _Class: Indicative._
- **Exit Proceeds Split** — exit value, 1-6 editable holders (name, ownership %, invested, pref ×, participating) → non-participating preferred converts if as-converted ≥ pref else takes pref; participating takes pref + pro-rata of remainder; preferences treated pari-passu (pro-rated if exit can't cover); per-holder preference paid, from-remainder, total payout, return multiple → table (with treatment label) + colored payout waterfall + ownership-total validity check. _Persist: none._ _Class: Indicative._
- **ESOP Value at Exit** — grant % (fully diluted at grant), strike price/share, implied price/share at grant, future dilution % before exit, exit valuation, vested at exit % → on notional 1,000,000-share table: diluted ownership = grant%×(1−futureDilution); gross = exit×ownership; strike cost = grantedShares×strike; net (full) = gross−strikeCost; net (vested) = net×vested%; implied gain multiple vs grant-date price; sensitivity over 0.25/0.5/1/2/4× exit → 4 cards + scenario table. Ignores taxes and liquidation prefs. _Persist: none._ _Class: Simulated._
- **Discount vs Cap** — investment, discount %, valuation cap, next-round pre-money → discount effective pre = pre×(1−disc), cap effective pre = min(cap, pre); investor takes whichever gives the lower (better) price; binding term (cap / discount / tie), effective pre-money, investor ownership = inv/(effPre+inv); compares no-terms / discount-only / cap-only → 3 cards + table with winning row ✓. Pre-money cap method. _Persist: none._ _Class: Indicative._

## Global & Cross-Border (`/global`) — 31 tools

FX, exports & FEMA toolkit for Indian SMB exporters/importers — multi-currency maths, LUT invoicing, FIRC/BRC tracking, customs landed cost, export-incentive estimators and FEMA compliance trackers. Stakeholders: owner, finance. Backend: KV-synced (`useFeatureState` → feature-data store; calculators are stateless). FX rates manual (no live feed) — `DEFAULT_RATES` editable in the converter and shared via the `glb-fx-rates` key.

Tab array carries 32 entries (Overview + 31 tools); the 31 tools below exclude the Overview landing page (which only summarises 4 KV-derived stat cards and links into other tools). UI filter tokens (receivable/payable, royalty/FTS/interest/dividend, RoDTEP/drawback, costplus/resaleminus, lut/igst, sell/buy, AA/EPCG, odi/fdi, rodtep purposes, etc.) are excluded per spec.

- **Currency Converter** (`fx-convert`) — amount + from/to currency (INR + 7: USD/EUR/GBP/AED/SGD/AUD/JPY), editable ₹-per-unit reference rates, swap button → INR-pivot conversion, cross rate (1 from = X to), INR equivalent. _Persist: `glb-fx-rates` (rates table; shared with consolidator, MC P&L)._ _Class: Indicative._
- **FX Gain / Loss** (`fx-gainloss`) — foreign amount, rate at invoice, rate at settlement, direction (receivable/payable) → invoice INR vs settle INR; realised forex gain/loss (AS 11 / Ind-AS 21), sign-flipped for payables → gain or loss to P&L. _Persist: none (local state)._ _Class: Indicative._
- **Export Invoice (LUT)** (`export-invoice`) — buyer, country, currency, FX rate, IGST %, line items (desc/qty/unit), with-LUT toggle → foreign-currency total, INR equivalent, IGST (0 under LUT else inrTotal×gst%), total payable, FEMA/LUT clause text; warns if firm marked GST-unregistered. _Persist: none (reads `store.firm`)._ _Class: Indicative._
- **FIRC / BRC Tracker** (`firc-brc`) — invoice ref, currency, amount, export date, remit date → table with 9-month FEMA realise-by deadline, days left, FIRC + eBRC status toggles, breach highlighting. _Persist: `glb-firc-brc`._ _Class: KV._
- **Letter of Credit** (`lc-tracker`) — LC no., issuing bank, currency, amount, expiry → per-LC card with UCP 600 7-doc checklist (toggles), docs-done count, expiry countdown, all-ready confirmation. _Persist: `glb-lc`._ _Class: KV._
- **Customs Duty** (`customs`) — currency, FOB goods value, FX rate, freight, insurance, BCD %, IGST % → CIF assessable value, BCD, Social Welfare Surcharge (10% of BCD), IGST (on assessable+BCD+SWS), total duty, total landed cost. _Persist: none (local state)._ _Class: Indicative._
- **Payment Fee Compare** (`payment-fees`) — currency, amount, mid-market rate, editable provider rows (name/flat fee ₹/FX markup %) → per-rail effective rate, FX cost, flat fee, all-in cost, you-receive; ranks cheapest, shows saving vs most expensive. _Persist: `glb-pay-rails` (provider list)._ _Class: Indicative._
- **Transfer Pricing** (`transfer-pricing`) — method (cost-plus CPM / resale-minus RPM), base (cost or resale price), markup/margin % → arm's-length transfer price or AE cost, embedded profit; Rule 10B/10C + Form 3CEB note. _Persist: none (local state)._ _Class: Indicative._
- **GST Export Refund** (`gst-export`) — route (LUT/IGST); LUT: export turnover, total turnover, net ITC → Rule 89(4) unutilised-ITC refund (export/total × ITC); IGST: IGST paid → IGST refund claimable. _Persist: none (local state)._ _Class: Indicative._
- **RoDTEP / Drawback** (`rodtep`) — scheme (RoDTEP/Drawback), FOB value ₹, rate % per HSN, optional value cap → raw benefit (FOB×rate), capped benefit, scrip/drawback value. _Persist: none (local state)._ _Class: Indicative._
- **FX Forward Cover** (`fx-forward`) — currency, amount, spot rate, forward points, tenor months, direction (sell/buy) → forward rate (spot+points), value at spot, value locked at forward, annualised premium %, pick-up/cost vs spot. _Persist: none (local state)._ _Class: Indicative._
- **FCY Balances** (`bank-consolidate`) — bank/account, currency (INR+7), balance → Nostro-style table of each balance × reference rate, total consolidated INR, net position by currency. _Persist: `glb-fcy-balances` (rows); reads `glb-fx-rates`._ _Class: KV._
- **SWIFT vs UPI Intl** (`swift-upi`) — currency, amount, mid rate, SWIFT flat+spread, UPI/fintech flat+spread → per-rail FX cost, flat fee, all-in cost, you-receive; cheapest flag + saving line. _Persist: none (local state)._ _Class: Indicative._
- **Packing Credit** (`packing-credit`) — drawdown ₹, rate % p.a., credit-period days, subvention % → gross interest (365-day simple), interest-equalisation saving, effective rate, net interest cost. _Persist: none (local state)._ _Class: Indicative._
- **EEFC Account** (`eefc-tracker`) — ref, currency, amount, credit date → held-by-currency chips, table with convert-by deadline (last day of next month), days left, converted toggle, breach highlight. _Persist: `glb-eefc`._ _Class: KV._
- **DTAA Withholding** (`dtaa-lookup`) — counterparty country (9: USA/UK/Singapore/UAE/Germany/Netherlands/Japan/Australia/France), income type (royalty/FTS/interest/dividend), payment ₹, gross-up toggle → hardcoded treaty rate, TDS to withhold (or grossed-up TDS deposited), net remittance; Form 15CA/CB, s.206AA notes. _Persist: none (`DTAA` const table)._ _Class: Indicative._
- **AA / EPCG** (`advance-auth`) — scheme (AA/EPCG), licence no., EO value, currency, EO-period-end date → per-licence card with fulfilled/obligation %, progress bar, days left, fulfilled-to-date input, met/defaulted/% status. _Persist: `glb-export-oblig`._ _Class: KV._
- **Country Sales** (`country-sales`) — reads live invoices; map each customer → country once → revenue grouped by destination market, invoice count, % share bars, total; untagged roll up as "Unmapped". _Persist: `glb-customer-country` (customer→country map); reads `store.invoices`._ _Class: Backend._
- **IEC / AD Code** (`iec-adcode`) — type (IEC/AD Code/Port reg./RCMC/LUT), number, issuer, renewal date → register table with renewal-status badges (expired / <30d to renew / valid). _Persist: `glb-iec-adcode`._ _Class: KV._
- **LRS / TCS** (`tcs-lrs`) — purpose (general/education-loan/education-other/medical), this remittance ₹, already-remitted-this-FY ₹ → cumulative LRS, ₹10L FY threshold, taxable portion above threshold, TCS rate (0.5/5/20%), TCS collected, total debited. _Persist: none (local state)._ _Class: Indicative._
- **SOFTEX Tracker** (`softex`) — invoice ref, client, currency, amount, invoice date → table with file-by deadline (invoice +30 days), filed/overdue/days-left status toggle, pending count. _Persist: `glb-softex`._ _Class: KV._
- **LUT Renewal** (`lut-renewal`) — LUT/ARN reference, FY filed for → derives current Indian FY (Apr–Mar), validity ends 31 Mar, days-to-expiry, covered/not-covered banner with RFD-11 reminder. _Persist: `glb-lut-no`, `glb-lut-fy`._ _Class: KV._
- **FEMA Calendar** (`fema-calendar`) — form (template picker: FLA/APR/FC-GPR/FC-TRS/Form ODI/ECB-2 with auto note), note, due date → date-sorted deadline list with done checkbox, overdue/days-left badges. _Persist: `glb-fema-cal`._ _Class: KV._
- **ODI / FDI** (`odi-fdi`) — kind (ODI out / FDI in), entity, currency, amount, event date → table with report-by deadline (event +30 days), reported/overdue/days-left status toggle. _Persist: `glb-odi-fdi`._ _Class: KV._
- **Country Risk** (`country-risk`) — country, then 1–5 sliders for payment / political / FX / legal → weighted composite (0.4/0.2/0.25/0.15), Low/Medium/High band per destination. _Persist: `glb-country-risk`._ _Class: KV._
- **GIFT City** (`gift-city`) — annual profit ₹, mainland tax %, holiday years, out-of block → annual mainland tax, ₹0 IFSC tax during holiday (Sec 80LA), holiday claimed, total headline tax saved over holiday. _Persist: none (local state)._ _Class: Indicative._
- **Incoterms Split** (`incoterms`) — Incoterm 2020 (10: EXW…DDP), cost legs ₹ (origin / main freight / insurance / destination / import duty) → per-leg seller/buyer badge from `SELLER_BEARS` table, seller-bears total, buyer-bears total. _Persist: none (`SELLER_BEARS` const)._ _Class: Indicative._
- **Multi-Currency P&L** (`mc-pnl`) — editable lines (label, revenue/cost, currency INR+7, amount) → each line × reference rate to INR, total revenue, total cost, net profit, margin %. _Persist: `glb-mc-pnl` (lines); reads `glb-fx-rates`._ _Class: KV._
- **WHT Recovery** (`wht-recovery`) — payer, country, currency, gross, WHT %, FX rate → per-row credit ₹ (gross×wht%×fx), total withheld abroad, FTC-yet-to-claim total, claimed toggle; Form 67 / FTC note. _Persist: `glb-wht-recovery`._ _Class: KV._
- **Realisation Aging** (`edpms-aging`) — shipping-bill ref, currency, amount, export date → ages open shipments into 0–90 / 91–180 / 181–270 / >270-day (FEMA breach) buckets with counts, table with age, realised toggle, breach highlight. _Persist: `glb-edpms-aging`._ _Class: KV._
- **Bank Charge Recon** (`bank-charge-recon`) — currency, invoiced amount, received amount, FX rate → charges deducted (foreign + %), INR value of charges, flagged if >3% with OUR-charges advice. _Persist: none (local state)._ _Class: Indicative._

## Voice & Vernacular (`/voice`) — 27 tools

Run the books by speaking, hear summaries aloud, and tune the app for any of 22 scheduled Indian languages or for low-vision use — built entirely on the browser's own Web Speech / MediaRecorder engines, with a typed fallback everywhere. Stakeholders: owner, all. Backend: mixed — most tools are ephemeral `useState` previews; the persistent ones use `useFeatureState` (KV-synced to `store.featureData`, debounced to backend, propagated across devices). Several read the live `store` (transactions/invoices/firm) read-only.

NOTE — browser-support gating: speech **input** (`SpeechRecognition`/`webkitSpeechRecognition`) is feature-detected once into `SPEECH_IN`; speech **output** (`speechSynthesis`) into `SPEECH_OUT`; audio recording (`MediaRecorder`+`getUserMedia`) into per-tool `CAN_RECORD`. When the relevant API is missing the tool shows a `FallbackNote` banner, disables the mic/play button, and accepts typed input — parsing/formatting is identical without the browser API. Tools needing speech-in (dictation/parse): Voice Capture, Dictation Pad, Expense Logger, Spoken Invoice, Voice Search, Reminders, Voice-to-WhatsApp, Speak Total, Ask Balance, Spoken Date, Work Log. Tools needing speech-out (TTS): Read Aloud, Audio Statement, My Day, Amount in Words, Payment Reminder, Audio Glossary, Speak Total, Ask Balance, Spell It Out, plus the Language test/UI-preview/Greeter play buttons. Greeting Recorder needs `MediaRecorder`. Number-formatting/transliteration/cheatsheet tools need no browser API.

### Tools

- **Overview** (`overview`) — inputs: none → behaviour: static dashboard of 6 capability cards (speech-in, TTS, 22 languages, accessibility, vernacular numbers, audio statements) each badged "Available"/"Fallback only" via live `SPEECH_IN`/`SPEECH_OUT` feature-detect; closing browser-support caveat. → output: read-only status grid. _Persist: none._ _Class: Preview._
- **Voice Capture** (`capture`) — inputs: spoken/typed one-line utterance e.g. "received 5000 from Sharma" (mic uses `en-IN`) → behaviour: `parseEntry()` extracts first number, infers direction (in/out via keyword regex), and party (after from/to/for/paid); reads live `store.transactions.length`. → output: non-posted draft txn card (direction/amount/party). _Persist: none (preview only — confirm in Transactions)._ _Class: Indicative._ Needs speech-in for mic.
- **Language** (`language`) — inputs: tap one of 22 languages; "Play sample" TTS button → behaviour: stores preferred language, passes matching BCP-47 to `speak()` for a test phrase. This key (`voice-language`) is read by ~14 other TTS tools to set locale. → output: selected language + locale label. _Persist: `voice-language` (KV)._ _Class: KV._ Sample play needs speech-out.
- **Read Aloud** (`reader`) — inputs: live `store.transactions`; speech-rate slider (0.5–1.5x) → behaviour: computes inflow/outflow/net, builds a spoken P&L script (lakh/crore worded), speaks it in the preferred-language locale; Stop cancels synth; script also shown for screen readers. → output: 3 summary cards + spoken/printed summary. _Persist: live store (read-only); rate is local `useState`._ _Class: Backend (reads synced txns)._ Needs speech-out.
- **Commands** (`cheatsheet`) — inputs: none → behaviour: static 3-group reference (capture / ask / navigate) of example phrasings the parsers understand. → output: read-only phrase cards. _Persist: none._ _Class: Preview._ No API needed.
- **Accessibility** (`access`) — inputs: Large-text + High-contrast toggles → behaviour: each toggle drives an inline live-preview card style; notes app-wide rollout is "wired separately." → output: preference toggles + live preview. _Persist: `voice-a11y-large-text`, `voice-a11y-high-contrast` (KV)._ _Class: KV (preview only — not yet applied app-wide)._ No API needed.
- **Lakh / Crore** (`numbers`) — inputs: amount field + Indian/International toggle → behaviour: `formatIndianGrouping()` (12,34,567 vs 1,234,567) and `lakhCrore()`/million labels; static side-by-side sample table. → output: formatted number + grouping label + comparison table. _Persist: `voice-number-indian` (KV) for the system toggle._ _Class: KV._ No API needed.
- **Audio Statement** (`audiostmt`) — inputs: typed lines + 4 auto-suggested lines built from live `store.transactions` (count/revenue/expense/net in lakh-crore) → behaviour: build a multi-line narration list (add/delete), concatenate, speak whole script in preferred locale; Stop cancels. → output: editable line list + spoken/printed narration. _Persist: `voice-audio-statement` (KV); suggestions read live store._ _Class: KV._ Playback needs speech-out.
- **Voice Auth** (`voiceauth`) — inputs: typed/spoken passphrase (min 6 chars) → behaviour: `hashPhrase()` SHA-256 (subtle crypto, weak btoa fallback) one-way hash stored locally; explicitly a STUB — no real voiceprint biometrics, gates nothing; re-enroll/clear. → output: stored-hash preview. _Persist: `voice-auth-hash` (KV)._ _Class: Simulated (self-described stub; needs server-side voice-liveness model)._ No browser API.
- **Dictation Pad** (`scratchpad`) — inputs: continuous dictation (preferred-language locale, `continuous`+final results) or typed text → behaviour: appends final speech chunks to a free-text notes area; copy/clear; word count. → output: synced notes blob. _Persist: `voice-scratchpad` (KV)._ _Class: KV._ Dictation needs speech-in.
- **Expense Logger** (`expense`) — inputs: multi-item utterance e.g. "200 tea, 1500 diesel, 300 packing" (mic `en-IN`) → behaviour: `parseExpenses()` splits clauses on comma/and/semicolon, extracts amount + cleaned label per clause, auto-categorises via `EXPENSE_CATEGORIES` keyword map (Travel/Food/Utilities/Rent/Salaries/Supplies/Maintenance/Uncategorised); totals. → output: non-posted per-item draft list + total. _Persist: none (preview only — confirm in Transactions)._ _Class: Indicative._ Mic needs speech-in.
- **Spoken Invoice** (`invoice`) — inputs: utterance e.g. "invoice Sharma 5000 for consulting" (mic `en-IN`) → behaviour: `parseInvoice()` extracts customer (after invoice/bill), amount, description (after for); computes indicative 18% GST line. → output: non-posted invoice draft card (taxable/GST/total). _Persist: none (preview only — rate/HSN/place-of-supply are placeholders; finalise in Invoices)._ _Class: Indicative._ Mic needs speech-in.
- **Voice Search** (`txnsearch`) — inputs: spoken/typed query e.g. "cash sales above 5000" (mic `en-IN`); live `store.transactions` → behaviour: parses above/below amount filters, in/out direction keywords, and residual free-text terms matched against description/category; filters live txns (cap 50; recent 20 when empty). → output: matched transaction list. _Persist: live store (read-only)._ _Class: Backend (reads synced txns)._ Mic needs speech-in.
- **UI Language** (`uipreview`) — inputs: tap one of 7 bundled languages (Hindi/Marathi/Tamil/Telugu/Bengali/Gujarati/Kannada) → behaviour: shows 6 core UI labels (`UI_STRINGS`) translated via hardcoded `UI_TRANSLATIONS` dict; per-label TTS button; notes other 22 languages "roll out as translation packs land"; defaults to the `voice-language` pref if translatable. → output: English→language label table. _Persist: reads `voice-language` (KV); preview lang is local `useState`._ _Class: Preview (bundled samples, not a live i18n switch)._ Label play needs speech-out.
- **My Day** (`digest`) — inputs: live `store.transactions`; system date → behaviour: filters today's txns by date, computes today in/out + overall balance, builds a time-of-day-greeted spoken digest (lakh/crore worded), speaks in preferred locale; Stop cancels; script printed for screen readers. → output: 3 today cards + spoken/printed digest. _Persist: live store (read-only)._ _Class: Backend (reads synced txns)._ Needs speech-out.
- **Reminders** (`reminder`) — inputs: spoken/typed reminder text (mic `en-IN`) + date picker → behaviour: saves reminder objects (text/when/created), sorted by due date, delete; explicitly notes these are personal notes shown here only — they do NOT fire push notifications yet. → output: synced reminder list. _Persist: `voice-reminders` (KV)._ _Class: KV (Indicative on notification delivery — no push wired)._ Mic needs speech-in.
- **Amount in Words** (`words`) — inputs: amount field (decimal) → behaviour: `numberToIndianWords()` spells rupees+paise in the Indian crore/lakh/thousand system ("Rupees … only"), capitalised; copy + read-aloud in preferred locale. → output: cheque/invoice-style worded amount. _Persist: none (local `useState`); reads `voice-language` for TTS locale._ _Class: Indicative._ Read-aloud needs speech-out.
- **Transliterate** (`translit`) — inputs: Roman-letter note (e.g. "ramesh ko 5000 dena hai") → behaviour: `transliterate()` longest-first phonetic Roman→Devanagari map (`TRANSLIT_MAP` — leaves digits/whitespace; explicitly a rough phonetic approximation, not linguistically exact); 3 example chips; copy. (The single Devanagari characters अ इ क etc. are this transliteration map's targets, not separate keys.) → output: Devanagari preview. _Persist: none (local `useState`)._ _Class: Indicative._ No browser API.
- **Payment Reminder** (`payreminder`) — inputs: live `store.invoices` (overdue/pending chips auto-computing days overdue) + manual party/amount/days; tone selector (gentle/firm/festive `REMINDER_TEMPLATES`); reads `store.firm.name` → behaviour: builds a polite spoken collection script (amount in lakh/crore); read-aloud in preferred locale / Stop / copy; nothing sent automatically. → output: reminder script + audio/clipboard. _Persist: none (script local); reads live store._ _Class: Backend (reads synced invoices/firm)._ Read-aloud needs speech-out.
- **Voice to WhatsApp** (`whatsapp`) — inputs: optional recipient number + dictated/typed message (continuous dictation in preferred locale) → behaviour: appends final speech chunks; builds a `wa.me` deep link with URL-encoded text and opens it in a new tab — a hand-off draft, NO background/API send. → output: opens WhatsApp share link. _Persist: none (local `useState`)._ _Class: Indicative (deep-link hand-off, not an automated send)._ Dictation needs speech-in.
- **Audio Glossary** (`glossary`) — inputs: search box → behaviour: filters a hardcoded 10-term `GLOSSARY` (ITC/TDS/EBITDA/working capital/AR/AP/gross margin/cash flow/GSTR-2B/reconciliation) by term/plain text; expand-to-read; per-term TTS button using preferred locale (note: explanation text is English for now). → output: expandable plain-language definitions. _Persist: none (local `useState`); reads `voice-language` for TTS locale._ _Class: Preview._ Read-aloud needs speech-out.
- **Speak Total** (`calc`) — inputs: spoken/typed amount string e.g. "200 plus 1500 and 300" (mic `en-IN`) → behaviour: `parseAmounts()` extracts all numbers; sums them (or subtracts the rest if "minus/less/subtract/deduct" appears anywhere); speaks the total in lakh/crore in preferred locale. → output: amount chips + total + spoken total. _Persist: none (local `useState`)._ _Class: Indicative._ Mic needs speech-in; spoken total needs speech-out.
- **Greeting Recorder** (`greeting`) — inputs: tone template (welcome/thanks/diwali/newyear `GREETING_TEMPLATES`, interpolating `store.firm.name`) → behaviour: TTS "hear script" in preferred locale; `MediaRecorder` via `getUserMedia` records an on-device audio greeting (Blob URL), playable/downloadable (`greeting.webm`)/discardable; nothing uploads; cleans up streams/object-URLs on unmount. → output: recorded audio clip + download link. _Persist: none (in-memory Blob URL only); reads `store.firm`._ _Class: Indicative (local recording only — no send/upload)._ Recording needs `MediaRecorder` (`CAN_RECORD`); hear-script needs speech-out.
- **Ask Balance** (`askbalance`) — inputs: spoken/typed question e.g. "what is my balance" (mic `en-IN`, auto-speaks answer); live `store` → behaviour: `answerQuestion()` classifies query (balance/in/out/count/party) and computes from live transactions (party lookup matches counterparty/description); answers in lakh/crore and reads back aloud in preferred locale. → output: textual answer + spoken answer. _Persist: live store (read-only)._ _Class: Backend (reads synced txns)._ Mic needs speech-in; read-back needs speech-out.
- **Spell It Out** (`spellout`) — inputs: code/IFSC/GSTIN/account number (upper-cased) → behaviour: splits to chars, maps letters to `NATO` phonetics (digits read as-is via `phonetic()`); read aloud char-by-char at 0.85x in preferred locale; copy phonetic spelling. → output: per-char phonetic chips + audio/clipboard. _Persist: none (local `useState`)._ _Class: Indicative._ Read-aloud needs speech-out.
- **Spoken Date** (`spokendate`) — inputs: spoken/typed date phrase e.g. "yesterday", "3 days ago", "15 march", "15/03/2025" (mic `en-IN`) → behaviour: `parseSpokenDate()` resolves today/yesterday/tomorrow/N-days-ago/month-name/dd-mm[-yyyy] against the system date. → output: resolved long date + ISO + copy. _Persist: none (local `useState`)._ _Class: Indicative._ Mic needs speech-in.
- **Work Log** (`quicklog`) — inputs: spoken (single-shot, preferred locale) or typed activity entry → behaviour: auto-timestamps each entry (ISO `at`), newest-first list, per-row + clear-all delete. → output: synced timestamped diary. _Persist: `voice-work-log` (KV)._ _Class: KV._ Speak needs speech-in.

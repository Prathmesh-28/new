## Budgeting & FP&A (`/budgets`) — 17 tools

Plan, allocate, phase, reforecast and stress-test budgets against live transaction actuals. Stakeholders: owner, finance. Backend: KV-synced (per-tool `useFeatureState` keys + the shared `budgets` store collection persisted via `addBudget`/`updateBudget`/`deleteBudget`).

- **Budget Manager (core grid)** — create/edit/delete budget category (label, category, monthly limit ₹, colour) via `AddBudgetModal`; each budget validated (`amount > 0`) → spend vs limit computed from current-month negative-amount transactions matched by `category`, with `pct` (capped 100), `overspend`, `warn` (≥80%), `remaining`, and a month-over-month delta vs prior month → per-card progress bars + summary cards (Total Budget, Spent This Month, alert counts: `N over, N near`) + overall spend/limit bar. _Persist: `store.budgets` (CRUD via AppContext)._ _Class: Backend._
- **Zero-Based / Rolling Budget Builder** (`#zero-based`) — per-period (YYYY-MM) line items (category, label, justified ₹); add/remove lines, "Roll forward prior month" copies prior month's lines with new ids → each line's justified amount compared to live per-category actuals (outflows in period window `-01`..`-31`); totals = Period Budget, Actual (live), Variance (budget − actual) → cards + line table. _Persist: KV `zbb-periods`._ _Class: KV (computation reads live transactions)._
- **Department Budget Allocation & Approval** (`#dept-alloc`) — set top-down budget pool ₹, allocate to departments (name, amount ₹, category) with status workflow draft→submitted→approved/rejected (+reopen) → unallocated/over-allocated = pool − sum(allocated); each row shows live current-month per-category spend with over-flag → pool/allocated/unallocated cards + table. _Persist: KV `dept-budget-pool` + `dept-allocations`._ _Class: KV (live spend overlay)._
- **Capex Budget & Approval Tracker** (`#capex`) — capital items (asset/project, planned ₹, target date) with status planned→approved→completed (+reopen) and editable actual `spent` → variance = planned − spent, overrun flagged when spent > planned; totals = Planned, Approved (non-planned), Actual Spent, Overruns count → cards + table. _Persist: KV `capex-items`._ _Class: KV._
- **Annual Budget Builder** (`#annual-builder`) — annual ₹ per line (category, mode even|seasonal) → spreads across 12 months: even = annual/12, seasonal = India festival-weighted curve `SEASONAL[12]` normalised; monthly totals, grand total, monthly average, peak month → stat cards + 12-month spread table with totals row. _Persist: KV `bud-annual-lines`._ _Class: KV (deterministic spread)._
- **Budget-vs-Actual Variance Report** (`#variance-report`) — pick month → each `store.budgets` line vs live per-category actual outflows in that month; variance = monthlyLimit − actual, var% = variance/limit, sorted worst-variance first, over flagged when variance < 0; totals = Budgeted, Actual, Net Variance, Lines Over → cards + table. _Persist: live store (budgets + transactions); `period` is local UI state, not persisted._ _Class: Backend (live read, no own KV)._
- **Flexible Budget Recalc** (`#flexible-budget`) — cost lines (fixed ₹ + variable ₹/unit), planned vs actual volume → static budget = Σ(fixed + var×plannedVol), flexed = Σ(fixed + var×actualVol), volume effect = flexed − static → cards + per-line static/flexed table. _Persist: KV `bud-flex-lines` + `bud-flex-planned-vol` (actual volume is local state)._ _Class: KV._
- **Cash Budget Planner** (`#cash-budget`) — opening cash ₹ + per-month planned inflow/outflow rows (one per month, sorted) → running closing = opening + Σ net; net = inflow − outflow per month; surfaces projected closing + lowest balance (red if negative) → cards + month table. _Persist: KV `bud-cash-opening` + `bud-cash-rows`._ _Class: KV._
- **Headcount / Manpower Budget** (`#headcount-budget`) — roles (dept, headcount, monthly CTC ₹, start month) → fully-loaded cost = base × (1 + `PF_ESI_LOAD` 0.13 employer PF+ESI); totals = headcount, monthly base, monthly loaded, annual loaded (×12) → cards + role table. _Persist: KV `bud-headcount`._ _Class: KV (statutory-load assumption is indicative ~13%)._
- **Project Budget Tracker** (`#project-budget`) — projects (name, client, budget ₹) with editable `spent` → used% = spent/budget, remaining, overrun flagged when spent > budget; totals = Total Budget, Total Spent, Overruns count → cards + table. _Persist: KV `bud-projects`._ _Class: KV._
- **Budget Utilization Gauges** (`#utilization-gauge`) — for each `store.budgets`, live current-month per-category spend → consumption% (conic-gradient ring), pace vs expected (`dayOfMonth/daysInMonth`); flags >100% over, >expected+10% pacing-ahead, else on-pace. _Persist: live store (budgets + transactions); no own KV._ _Class: Backend (live read)._
- **Forecast-vs-Budget Reforecast** (`#reforecast`) — per budget: annual budget = monthlyLimit×12; YTD actual = live calendar-year per-category outflow; run-rate = YTD/monthsElapsed; projected rest = runRate × monthsRemaining × (1 + adjust%); reforecast = YTD + projected; variance = annualBudget − reforecast → cards + table with user trend-adjustment input. _Persist: KV `bud-reforecast-adjust` (reads live budgets + transactions)._ _Class: KV (run-rate projection — Indicative)._
- **Marketing Budget Allocator** (`#marketing-roi`) — channels (prior spend ₹, revenue ₹) + marketing pool ₹ → ROAS = revenue/spend, weight = roas/Σroas (fallback equal-split), recommended = pool × weight; sorted by ROAS desc; blended ROAS = Σrev/Σspend, top channel → cards + table. _Persist: KV `bud-mktg-budget` + `bud-mktg-channels`._ _Class: KV (ROI-weighted allocation — Indicative recommendation)._
- **Cost-Cutting Simulator** (`#cost-cutting`) — last-3-months live per-category outflow → monthly average; per category set cuttability easy/medium/hard → modeled saving = monthlyAvg × `CUT_PCT` (0.30/0.15/0.05); totals = monthly spend, monthly saving, annualised saving (×12) → cards + table with % of total. _Persist: KV `bud-cut-levels` (levels only; spend read live)._ _Class: KV (savings %s are modeling assumptions — Simulated)._
- **Budget Reallocation Tool** (`#reallocation`) — requires ≥2 budgets; queue from→to transfer moves (amount ₹, distinct budgets) → net delta per budget, revised limit = monthlyLimit + delta; total-before vs total-after must reconcile (green when equal, pool conserved); shows queued moves list → cards + revised-limit table. _Persist: KV `bud-realloc-moves` (reads live budgets; does NOT mutate store budgets)._ _Class: KV (preview/simulation — does not write back to budgets)._
- **Quarterly Phasing Planner** (`#quarterly-phasing`) — annual ₹ per line auto-phased even/4 across Q1–Q4, each quarter editable → phased = Σ quarters, flags lines where phased ≠ annual; quarter totals + grand total → Q1–Q4 cards + editable table with totals row. _Persist: KV `bud-phasing-lines`._ _Class: KV._
- **Contingency Reserve Planner** (`#contingency`) — last-6-months live monthly outflow totals → mean, std, coefficient of variation; suggested buffer% = clamp(cv×100, 5–30), manual override wins; reserve = mean × usePct, annual = ×12 → cards + 6-month bar chart. _Persist: KV `bud-contingency-pct` (stats read live)._ _Class: KV (volatility-sized buffer — Indicative)._

## Settings (`/settings`) — 30 cards/tools

Owner/super-admin-only workspace configuration: plan, security, team roles, document/invoice/tax defaults, locale, integrations. Stakeholders: owner, finance, admin. Backend: `/api/users`, `/api/account/*`, `/api/whatsapp/*`, `/api/push/test`, firm fields on AppStore, plus the synced `store.featureData` KV bag (localStorage + debounced backend sync via `useFeatureState`). Gated to `super_admin`/`owner`; everyone else redirects to `/dashboard`.

- **Plan & Billing** (`BillingCard`) — shows current plan tier and lets you upgrade to Growth (₹999/$39) or Pro (₹2,999/$99); region currency switches INR/USD, downgrades show "included," warns if Razorpay keys unset → live Razorpay checkout (UPI/cards/netbanking) when configured. _Persist: Backend (`/api/billing`, plan on user)._ _Class: Backend (Razorpay-gated; Simulated if `RAZORPAY_*` env unset)._
- **App Lock** (`AppLockCard`) — set/clear a 4-digit launch+resume PIN, plus optional Face ID/fingerprint fast-unlock on supported devices → app requires PIN/biometric to open. _Persist: live store (`lib/appLock`, `lib/biometric`; device-local)._ _Class: Backend (device-local secure store)._
- **Push Notifications** (`NotificationsCard`) — "Send test" fires a test push to every registered device in the tenant → confirms FCM delivery; warns if no devices or `FCM_SERVER_KEY` unset. _Persist: none (action only; tokens registered on native launch)._ _Class: Backend (FCM-gated; mock response if key unset)._
- **Privacy & Data** (`PrivacyCard`) — DPDP consent ledger toggles (essential/marketing/lending_partners/analytics; essential locked), JSON data export (right-to-access), and password-confirmed account-deletion request (right-to-erasure); lists grievance officer email. _Persist: Backend (`/api/account/consent`, `/api/account/export`, `/api/account/deletion-request`)._ _Class: Backend._
- **Role & Permission Matrix** (#170) — tick what each team type (Finance/CA/Sales/Ops) may do across 6 perms (view cash, edit txn, approve pay, manage invoices, view reports, manage team) → a grant table, per-role granted count shown. _Persist: KV (`settings-permission-matrix`)._ _Class: Indicative (grant table not enforced in app logic)._
- **Approval Policy** (#171) — add maker-checker rules: payments above a ₹ threshold require approval from a chosen role, with optional note; rules sorted by threshold, deletable → defines sign-off requirements. _Persist: KV (`settings-approval-rules`)._ _Class: Indicative (rules stored, not enforced on payments)._
- **Financial Year & Books Lock** (#172) — pick FY start month (default March/April-March) and lock books up to a date (or unlock) → entries on/before lock date treated as filed/closed. _Persist: KV (`settings-books-lock`)._ _Class: Indicative (lock advisory; not enforced on edits)._
- **Audit Log & Login History** (#173) — read-only list of recent sign-ins and security-relevant changes (login/permission/lock/policy), prepends current session; falls back to session only when empty. _Persist: KV read-only (`settings-audit-log`); current session synthesized in-memory._ _Class: Indicative (no events written by app yet)._
- **Invoice Defaults** (#174) — set invoice prefix, next number, payment terms (0–90 days), and default footer note; live preview of next number → pre-fills new invoices. _Persist: KV (`set-invoice-defaults`)._ _Class: Indicative (defaults stored; consumption by invoice flow not wired)._
- **Currency & Locale** (#175) — choose number grouping (Indian lakh/crore vs international), decimal places (0/2), and ₹ symbol position; live sample. _Persist: KV (`set-currency-locale`)._ _Class: Preview (sample only; `formatCurrency` not driven by it)._
- **Document Branding** (#176) — logo URL (with live image preview + load-error guard), authorised signatory, and footer line → stamped on invoices/statements/PDF exports. _Persist: KV (`set-document-branding`)._ _Class: Indicative (stored; PDF stamping not wired)._
- **Payment Reminder Cadence** (#177) — toggle auto-reminders; set days-before-due, days-after-due, on-due flag, and channel (WhatsApp/email/both) → default schedule for chasing new receivables. _Persist: KV (`set-reminder-cadence`)._ _Class: Indicative (schedule stored; not driving sends)._
- **Number Format & Rounding** (#178) — rounding rule (none/nearest/up/down), round-to step (₹1/5/10), and display unit (full/thousands/lakhs); live example. _Persist: KV (`set-number-rounding`)._ _Class: Preview (example only; totals not rounded by it)._
- **Theme & Density** (#179) — appearance (system/dark/light), layout density (comfortable/compact), and reduce-motion toggle → visual prefs meant to follow user across devices. _Persist: KV (`set-theme-density`)._ _Class: Indicative (stored; not applied to live theme/density)._
- **E-Invoice & E-Way Bill Defaults** (#180) — toggle IRN/e-invoice for B2B, toggle e-way bill with ₹ threshold + transport mode (road/rail/air/ship), and auto-generate-on-save flag → behaviour for GST docs. _Persist: KV (`set-einvoice-defaults`)._ _Class: Indicative (no IRP/e-way integration)._
- **Bank Account Defaults** (#181) — add settlement accounts (nickname, bank, masked last-4, IFSC), set/remove primary → primary printed on invoices and pre-selected for payouts. _Persist: KV (`set-bank-accounts`, `set-bank-primary`)._ _Class: Indicative (stored; not consumed by invoice/payout flows)._
- **Email & SMS Sender Identity** (#182) — set from-name (defaults to firm name), reply-to email, 6-letter DLT SMS sender ID (sanitised), and cc-self toggle; live preview → applied to outgoing invoices/reminders/statements. _Persist: KV (`set-sender-identity`)._ _Class: Indicative (stored; no live mail/SMS sender wiring)._
- **Data Retention** (#183) — keep-records window (3/5/8/10 yrs; statutory 8-yr note), include-attachments-in-archive, warn-before-purge toggles; shows archival cutoff date. _Persist: KV (`set-data-retention`)._ _Class: Indicative (no auto-archival job)._
- **Dashboard Default & Export Format** (#184) — default landing view (overview/cashflow/receivables/alerts), default date range (30d/90d/FY/all), and export format (PDF/xlsx/CSV); live summary. _Persist: KV (`set-workspace-defaults`)._ _Class: Indicative (stored; not driving landing/export)._
- **Late-Fee & Overdue Interest** (#185) — toggle late fees; pick type (%/month, %/annum, flat), rate or flat amount, and grace days; example charge on ₹1,00,000. _Persist: KV (`set-late-fee-policy`)._ _Class: Indicative (policy stored; not applied to overdue invoices)._
- **Tax-Code Defaults (HSN/SAC & TDS)** (#186) — default HSN/SAC code (numeric, ≤8 digits) and item type (goods/services); toggle TDS with section (194C/J/H/Q) and rate → pre-fills line items / deductions. _Persist: KV (`set-tax-code-defaults`)._ _Class: Indicative (defaults stored; not consumed by invoice/payment flow)._
- **Locations & Branches** (#187) — add places of supply (name, city/state, optional GSTIN), set/remove primary → invoices and reports taggable per branch GSTIN. _Persist: KV (`set-locations`, `set-locations-primary`)._ _Class: Indicative (stored; tagging not wired)._
- **Customer-Statement Template** (#188) — send frequency (weekly/fortnightly/monthly), show-opening-balance and include-ageing toggles, intro line and sign-off; live summary → composes periodic customer statements. _Persist: KV (`set-statement-template`)._ _Class: Indicative (template stored; statement send not wired)._
- **Your Team** (`/api/users`) — list members with role badges; invite by email + assignable role (with live role-scope preview), change member role inline, remove member; emails a temp password on invite. _Persist: Backend (`/api/users` GET/POST/PATCH/DELETE)._ _Class: Backend._
- **Stakeholder Views & Permissions** — "Preview as" any assignable role (navigates to that role's landing with an exit banner) and per-role page-access matrix (tick TAB_CATALOG pages by group, reset-to-default) → controls which tabs each role can open. _Persist: live store (`setPreviewRole`, `roleTabs`/`setRoleTabs`/`resetRole` via AppContext)._ _Class: Backend (role-tab config drives nav gating)._
- **Business Profile** — edit business name, industry (select), and runway safety-threshold slider (7–60 days) → used in credit underwriting and advisor reports. _Persist: Backend (`updateFirm`: name/industry/safetyThresholdDays on firm)._ _Class: Backend._
- **Your Tenant ID** — read-only tenant ID with copy-to-clipboard → shared with CA/CFO/banker to link account into their Advisor Portal "My Clients." _Persist: none (display of `tenant_id` from `/api/users`)._ _Class: Backend (read-only identifier)._
- **GST Settings** — toggle GST-registered; set GSTIN (≤15 chars) and primary output rate (0/5/12/18/28%) → estimates monthly GSTR-3B output tax (revenue × rate) in tax calendar/forecast. _Persist: Backend (`updateFirm`: gstRegistered/gstNumber/gstRate)._ _Class: Backend._
- **WhatsApp Alerts** — connect a phone (with country code) for a 7am cash digest and NL queries, or disconnect; shows connected number and command reference (cash/runway/alerts/invoices). _Persist: Backend (`/api/whatsapp/status`, `/register` POST/DELETE)._ _Class: Backend (Twilio WhatsApp API; needs `TWILIO_*` env)._
- **What each role can do** — read-only reference grid of every assignable role with badge, read-only flag, blurb and scope bullets → helps owner pick the right role. _Persist: none (static `ASSIGNABLE_ROLES` reference)._ _Class: Preview (informational)._

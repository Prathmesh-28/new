## Collections (`/collections`) — 28 tools

Active accounts-receivable command centre: chase overdue invoices, score payers, model recoveries and post-bad-debt provisions — all derived from the live invoice book. Stakeholders: finance, sales. Backend: `/api/collections` + KV (`store.invoices` from the synced app store; durable tool records via `useFeatureState` → `store.featureData` KV namespace, debounced to backend and live-synced across devices).

- **Collections (active AR chase)** — open invoices (`status !== "paid"`) → per-invoice aging via `getAging` (current / 1–30 / 31–60 / 61–90 / 90+ from `differenceInDays(today, dueDate)`), KPI row (total overdue, accounts overdue, avg days overdue, critical 60d+), clickable aging-bucket summary (count/amount/bar), sortable account table, 60d+ critical tip → chase list. Sub-tools: **Reminder modal** (pick template soft/firm/final × channel WhatsApp/email/SMS → opens prefilled `wa.me`/`mailto:`/`sms:` deep link, marks contacted) and **Mark contacted** (in-session `Set`). _Persist: none (contacted set is component state; reminders open the user's own app, server does not deliver)._ _Class: Backend (reads live invoices) + Indicative._
- **Profitability** — all invoices grouped by customer → totalInvoiced, totalPaid, collectionRate (paidCount/invoiceCount), avgDaysToCollect, overdueAmount, blended score → A/B/C tiered table + 4 KPI cards. _Persist: live store._ _Class: Backend._
- **CLV** — invoices per customer + margin% & lifespan-years sliders → AOV, order frequency from invoice-date gaps, ordersPerYear=365/avgFreqDays, CLV = AOV × orders/yr × lifespan × margin → ranked table with Platinum/Gold/Standard tiers (top 20% / top 50%) + top-20% CLV share. _Persist: live store (slider inputs are component state)._ _Class: Indicative (projection)._
- **Risk Score** — invoices per customer → overdueRate, avgDaysLate, recency penalty → riskScore = 40%×overdueRate + 35%×min(avgLate/90,1) + 25%×recency → High ≥65 / Medium ≥35 / Low → table + bucket counts. _Persist: live store._ _Class: Indicative._
- **Statement** — pick a customer → builds a running-balance ledger (invoice = debit, payment = credit), totals invoiced/received/outstanding/overdue, firm header → copy-to-clipboard plaintext statement of account. _Persist: live store; output via `navigator.clipboard`._ _Class: Backend + Indicative (simplified, no TDS/credit-note/actual payment dates)._
- **Dunning** — open invoices → days overdue mapped to a ladder (D+1 gentle / D+7 / D+15 / D+30 final), shows highest step crossed per invoice, per-step counts, channel toggle → Send opens prefilled WhatsApp/email/SMS deep link with tone-matched dunning message. _Persist: live store; messages open user's own app._ _Class: Backend + Indicative._
- **DSO Trend** — invoices bucketed into last-6-month buckets → monthly DSO ≈ (open AR for month ÷ month sales) × 30, MoM delta, bar chart + worst-payers table (avg days late on open invoices, top 8). _Persist: live store._ _Class: Indicative (DSO approximation)._
- **Promise-to-Pay** — log customer commitment (customer/amount/promised-by date/note) → auto-flags breach when promise date passes while open; mark kept/broken, Chase via WhatsApp; KPIs open/broken/kept/promised-value. _Persist: KV key `collections-promise-to-pay`._ _Class: KV._
- **Agents** — add reps with collection target; route each overdue account to a rep via dropdown → per-rep progress = assigned overdue value ÷ target; unassigned count. _Persist: KV keys `collections-agents` + `collections-agent-assignments`._ _Class: KV._
- **Settlement** — pick open account, choose settle (discount% slider) or write-off (=100%), add reason → computes recoverable/loss, submit for approval; approve/reject lifecycle; summary of pending / approved recovery / bad-debt-or-discount loss. _Persist: KV key `collections-settlements`._ _Class: KV + Indicative (write-off journal = Dr Bad-debt / Cr Debtors described, not posted)._
- **CEI (Collection Effectiveness Index)** — invoices bucketed by due-month over 6 months → CEI = collected ÷ collectible (invoices that fell due that month) × 100, overall + latest, Excellent ≥80 / Healthy ≥60 grade + bar chart. _Persist: live store._ _Class: Indicative._
- **Bad-Debt (Provision)** — open invoices grouped by aging bucket + editable %-doubtful-by-age policy (default 0/0/10/25/50) → provision = outstanding × rate per bucket, totals + net realisable AR. _Persist: live store (policy % is component state)._ _Class: Indicative (Ind-AS 109 / provision-matrix style; Dr Bad-debt expense / Cr Provision described, not posted)._
- **Payment Plan** — pick open account, set installment count / interval days / first-due date → splits balance into equal installments (rounding remainder on final one so it sums exactly), schedule table, copy-to-clipboard plan. _Persist: live store; output via clipboard._ _Class: Indicative._
- **Late Interest** — open overdue invoices + annual-rate slider (default 18%) → simple interest = principal × rate × days÷365 per invoice, totals principal/interest/accounts. _Persist: live store._ _Class: Indicative (MSME delayed-payment interest; statutory is 3× RBI rate compound — rate is user-set)._
- **Forecast** — open invoices weighted by aging-keyed recovery probability (current 0.95 → 90d+ 0.25), bucketed into next-6-week buckets by due week (overdue → this week) → expected = Σ(amount × prob), face value, risk-adjusted shortfall + bar chart. _Persist: live store._ _Class: Indicative (projection)._
- **Worklist** — open invoices → priority = 40%×value + 35%×age(cap 90d) + 25%×recovery-risk, each scaled 0–100 → ranked chase list, top-5 highlighted, focus value. _Persist: live store._ _Class: Indicative._
- **Early-Pay (Discount)** — open AR + discount%/pay-within/net-days inputs → per-invoice discounted amount & customer saving, implied annual cost = (d÷(100−d))×(365÷days saved); cash-if-all-take-it. _Persist: live store._ _Class: Indicative._
- **Legal Notice** — pick overdue account + grace days → auto-fills a formal demand-notice draft (firm name, customer, invoice ref, amount, due date, days overdue, pay-within) → copy-to-clipboard. _Persist: live store; output via clipboard._ _Class: Indicative (boilerplate, "not legal advice")._
- **KPI Board** — whole invoice book → DSO (open AR ÷ avg daily credit sales over 90d, with invoice-share fallback), CEI (collected ÷ (collected+overdue) single-period proxy), ADD (DSO − Best-Possible DSO), Best-Possible DSO (current AR only) + open/overdue/collected values and explainer. _Persist: live store._ _Class: Indicative (proxy formulas)._
- **Disputes** — log a contested/short-paid invoice (pick invoice, disputed amount capped at invoice total, reason code) → quarantines disputed amount, computes still-chaseable clean balance; open/resolved toggle; KPIs open disputes / disputed value / clean value. _Persist: KV key `col-disputes`._ _Class: KV._
- **Concentration** — open invoices grouped by customer + alert-threshold slider → each customer's share of open AR, top-3 share, Herfindahl HHI (Σ share², <1500 diversified / >2500 concentrated), red alert for customers exceeding threshold + share-bar table. _Persist: live store (threshold is component state)._ _Class: Indicative._
- **Defaulters** — open past-due invoices grouped by customer → overdue value, overdue-invoice count, worst days overdue → leaderboard ranked by overdue value (medals top 3) + share-of-total. _Persist: live store._ _Class: Backend._
- **Behavior** — pick a customer → timeline of every invoice with days-late (unpaid: due→today; paid: invoice/due date proxy), avg days late, on-time rate. _Persist: live store._ _Class: Indicative (paid-late is a proxy; store has no explicit payment date)._
- **A/B Templates** — edit two reminder variants (subject+body), log which variant sent to a customer, toggle paid → per-variant sent/paid/rate and current winner. _Persist: KV keys `col-ab-variants` + `col-ab-results`._ _Class: KV._
- **Letter Series** — pick overdue invoice → stage auto-selected by days overdue (reminder D+1 / second D+30 / final D+60), suggested-stage hint, generates escalation letter text → copy or print (opens print window). _Persist: live store; output via clipboard/print._ _Class: Indicative._
- **Interest Invoice** — pick overdue invoice + annual rate (default 18%) → interest = principal × rate × days÷365, generate debit-note record; list of saved notes + total billable. _Persist: KV key `col-interest-invoices`._ _Class: KV + Indicative (MSME interest; confirm contract/statutory rate)._
- **NACH Mandates** — register an e-NACH/auto-debit mandate per customer (UMRN, debit cap, frequency monthly/quarterly/as-presented, next-debit date) → pending→active/rejected/cancelled lifecycle; active count + covered value/cycle. _Persist: KV key `col-nach-mandates`._ _Class: KV (control sheet only — not the NPCI register; no real debit fired)._
- **Ageing by Rep** — assign each customer a sales-rep owner → rolls open AR up by rep across aging buckets (current/1–30/31–60/61–90/90+) with grand total; unassigned roll up together. _Persist: KV key `col-customer-owners` (owner map); live store for invoices._ _Class: Backend + KV._

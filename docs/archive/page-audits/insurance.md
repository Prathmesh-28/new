## Insurance & Protection (`/insurance`) — 33 tools

Track, size, price and protect every business and personal cover in one place — policy register, gap analysis, premium estimators and claims tracking. Stakeholders: owner, finance. Backend: KV-synced (per-feature `useFeatureState` keys; ephemeral tools hold state in React only). Premium figures INDICATIVE (no IRDAI quote feed) — all rates/loads are hardcoded illustrative constants.

(Overview is a dashboard/launcher only — 4 KPI cards from `ins-policies` + revenue and a 10-tool jump grid; not counted below.)

- **Policy Register & Renewals** — insurer, type (17 `POLICY_TYPES`), policy no., sum insured, premium (incl. GST), start/renewal dates → adds to register; sorts by days-to-renewal; computes lapsed (<0d) / urgent (≤30d) / active status badges per policy → table + add/remove. _Persist: `ins-policies`._ _Class: KV._
- **Coverage-Gap Analyzer** — register policy types held + auto store signals (revenue from positive txns, payroll category presence, open receivables = unpaid invoices) → runs 8 fixed risk checks (fire, burglary, public liability, group health if payroll, PA if payroll, trade-credit if receivables>0 with high/med severity at >25% revenue, BI if revenue>0, cyber) → lists gaps not in register vs covered chips. _Persist: `ins-policies` (read)._ _Class: KV._
- **Sum-Insured Calculator** — building + plant + stock + furniture, turnover (auto from revenue), gross-margin %, BI indemnity months → asset SI = sum of four; BI SI = turnover × margin% × months/12; recommended = assets + BI → itemized rows + total. _Persist: none (read store revenue)._ _Class: Indicative._
- **Group-Health Estimator** — head counts per 4 age bands (factors 0.7/1.0/1.6/2.6), cover/head, family-floater toggle (×1.45), maternity toggle (×1.12) → base premium = Σ(n × cover/1L × ₹1100 × ageFactor), ×loads, +18% GST → net/GST/gross + per-life cost. _Persist: none._ _Class: Indicative._
- **Business-Asset Cover Calculator** — per-line asset name, sum insured, peril rate (% p.a.) → total SI; net premium = Σ(value × rate%); +18% GST → KPIs + schedule table; add/remove lines. _Persist: `ins-asset-schedule`._ _Class: Indicative (+KV for schedule)._
- **Trade-Credit Estimator** — insured credit turnover (auto = open receivables), rate (‰), cover % per invoice, largest-buyer exposure → net premium = turnover × rate/1000; +18% GST; max indemnity = turnover × cover%; concentration % = topBuyer/turnover with >25% warning. _Persist: none (read invoices)._ _Class: Indicative._
- **Claims Tracker** — insurer, claim type/peril, claim amount, date → logs claim (status starts "intimated"); editable settled amount; status dropdown across 6 stages (intimated→surveyor→documents→approved→settled→rejected, settled auto-fills settled=claimed); claims-to-premium ratio = totalSettled/registerPremium. _Persist: `ins-claims` (reads `ins-policies` for ratio)._ _Class: KV._
- **Premium vs Cover** — per-quote insurer, sum insured, premium, deductible → rate-on-line = premium/SI × 100; premium+deductible exposure; picks BEST = lowest ROL → ranked table + add/remove. _Persist: `ins-quotes`._ _Class: KV._
- **Key-Man Estimator** — key person name + method (profit: profit × contribution% × years | salary: salary × multiple | loan: loan outstanding) → recommended sum assured; indicative net premium = SA/₹1cr × ₹35000; +18% GST → SA + premium cards. _Persist: none._ _Class: Indicative._
- **Risk-Exposure Scorecard** — register + claims + store signals → 0–100 protection score: core covers held (≤40), employee health (≤15), receivables protection (≤15), no-lapsed freshness (≤20, −10/lapse), renewal hygiene (≤10); band (≥75 well / ≥50 partial / <50 under-protected); breakdown bars + open-claims note. _Persist: `ins-policies` + `ins-claims` (read)._ _Class: KV._
- **Premium-Due Calendar** — register policies with renewal dates → buckets renewals into rolling 12 months; per-month count + premium total; next-12 total, avg/month, undated count → horizontal bar chart. _Persist: `ins-policies` (read)._ _Class: KV._
- **CSR Comparator** — per-insurer claims received, claims paid (validated ≤ received), avg settle days → CSR = paid/received × 100; sorts desc, flags TOP; color bands (≥95 green / ≥85 yellow / <85 red) → table; user enters published IRDAI figures. _Persist: `ins-csr`._ _Class: KV._
- **No-Claim-Bonus Tracker** — per-policy name, base premium, claim-free years → NCB% via motor slab [0,20,25,35,45,50] capped at index; saving = base × NCB%; shows next-year NCB; total saving across policies → table. _Persist: `ins-ncb`._ _Class: KV._
- **Deductible Optimizer** — base premium, base deductible, expected claims/year, premium fall % per doubling → for multipliers [0.5,1,2,4,8]: premium = base × (1−sens)^log2(m), expected retained = deductible × freq, total annual cost; picks OPTIMAL = min total cost → table. _Persist: none._ _Class: Indicative._
- **Business-Interruption Estimator** — turnover (auto), gross-profit %, indemnity months, increased cost of working, premium rate % → BI SI = GP × months/12 + addl; net premium = SI × rate%; +18% GST → SI/net/GST/gross cards. _Persist: none (read revenue)._ _Class: Indicative._
- **Marine / Transit Calculator** — mode single (consignment value + freight) or open/annual (dispatch turnover), cover % (default 110 = CIF+10%), rate (‰) → base × cover% = SI; net premium = SI × rate/1000; +18% GST → SI/net/GST/per-shipment-or-annual cards. _Persist: none._ _Class: Indicative._
- **Professional-Indemnity Estimator** — profession (7-key rate map 0.6–1.4), indemnity limit, annual fees, retroactive years → net premium = limit × baseRate% × (1 + feeLoad capped 0.5 + retro×0.08); +18% GST → limit/net/GST/gross cards. _Persist: none._ _Class: Indicative._
- **Cyber-Insurance Need Scorer** — 7 weighted yes/no factors (sum to 100), PII records count → score = Σ checked weights; suggested limit = max(₹25L, records×150) × (1 + score/100); band (≥60 high / ≥35 moderate / <35 lower). _Persist: none._ _Class: Indicative._
- **Vehicle / Fleet Insurance Tracker** — per-vehicle reg no., type (6 `VEHICLE_TYPES`), IDV, premium, expiry → total IDV/premium; expiring-≤30d count; per-row lapsed/urgent/active status → KPIs + table; add/remove. _Persist: `ins-fleet`._ _Class: KV._
- **Workmen-Comp Estimator** — occupation risk class (5-band rate map 0.2–2.0%), annual wage bill (auto from payroll outflow), headcount, medical-extension toggle (+15%) → net premium = wages × rate% × medLoad; +18% GST; per-worker → 4 cards. _Persist: none (read payroll txns)._ _Class: Indicative._
- **Premium-Financing EMI Calculator** — annual premium, down-payment %, interest rate % p.a., tenure months → down payment; principal; reducing-balance EMI; total paid; interest = total − premium → cards + interest-as-%-of-premium note. _Persist: none._ _Class: Indicative._
- **GST-on-Premium ITC Checker** — cover type (10-rule map: yes/conditional/no), premium excl. GST → GST = base × 18%; gross; ITC claimable = GST if eligible="yes" else 0; eligibility badge + s.17(5) note (group-health & personal-vehicle conditional/blocked). _Persist: none._ _Class: Indicative._
- **Health Top-Up / Super-Top-Up Optimizer** — target total cover, base cover (= deductible), eldest age, super-top-up toggle → top-up cover = target − base; age-loaded per-1L rates (direct 1900, base 2100, top-up 320 super / 480 regular, all ×ageLoad incl. GST); direct vs stacked premium; saving + % → cards, saving banner, breakdown. _Persist: none._ _Class: Indicative._
- **OPD & Wellness Benefit Tracker** — annual OPD limit, benefit head (9 `OPD_HEADS`), amount, date → logs usage; used/remaining/utilisation% vs limit; by-head breakdown; utilisation progress bar → KPIs + table; add/remove. _Persist: `ins-opd-claims` + `ins-opd-limit`._ _Class: KV._
- **Coverage Adequacy by Life-Stage** — age, income, dependents, loans, savings, existing life & health cover → life need = income × age-multiple (20/18/14/10/6) × (1 + deps×0.15) + loans − savings; life gap vs held; health need by age band × (1.5 if deps); health gap; life-stage label → recommended + shortfall cards. _Persist: none._ _Class: Indicative._
- **Riders Comparator** — per-rider name (8 suggested), annual premium, benefit/cover, keep toggle → cost-per-₹1L cover = premium/(benefit/1L); totals over kept riders (count, added premium, added cover) → table with toggle + add/remove. _Persist: `ins-riders`._ _Class: KV._
- **Insurance TCO** — premium, deductible, co-insurance %, typical claim size, claim probability %, horizon years → OOP if claim = deductible + (claim−deductible)×coins; insurer pays = claim − OOP; expected annual OOP = prob × OOP; annual TCO = premium + expected OOP; multi-year TCO → cards + cost-split breakdown. _Persist: none._ _Class: Indicative._
- **Surrender-Value Estimator** — plan type (endowment/ULIP), annual premium, policy term, years paid, fund value (ULIP) → ULIP: 5-yr lock-in → discontinuance value (fund − min(₹6000, 6%)) if locked else fund; endowment: nil if <2yrs, else GSV = (premium × (paid−1)) × factor% (30/50/65/80/90 by elapsed ratio) → paid/surrender/gain-loss cards + lock-in warning. _Persist: none._ _Class: Indicative._
- **Group vs Individual Cost Compare** — lives, average age, cover/head, employer-share % → age-loaded per-1L rates (group 900, individual 1450 ×ageLoad); group vs individual gross (×1.18); saving + %; per-head group; employer outlay = group × share% → cards + saving banner. _Persist: none._ _Class: Indicative._
- **Multi-Policy Renewal Planner** — register policies with renewal date + premium → buckets premium into rolling 12 months; total, count, peak month → bar chart per month with counts; empty state if none. _Persist: `ins-policies` (read)._ _Class: KV._
- **Sum-Insured Inflation Indexer** — current SI, cost-inflation % p.a., project years (0–20), years since last revaluation → indexed projection SI × (1+infl)^y per year; true value now = SI × (1+infl)^elapsed; shortfall + under-insurance % if not revalued; target SI at horizon → warning banner + projection table. _Persist: none._ _Class: Indicative._
- **Insurance Spend Budget** — annual revenue (auto), target spend % of revenue, extra premiums not in register → budget = revenue × target%; actual spend = register premium + extra; actual % of revenue; variance = budget − spend (headroom/over) → cards + within/over-budget banner. _Persist: `ins-policies` (read) + read revenue._ _Class: KV._
- **Claim Document Readiness** — toggle 8 fixed checklist items (intimation, FIR, policy copy, repair estimate, photos, purchase bills, surveyor cooperation, KYC/bank) → ready count + % progress bar; all-done banner. _Persist: `ins-claim-readiness`._ _Class: KV._

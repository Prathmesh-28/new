## Alerts (`/alerts`) — 23 tools
Centralises every cash, compliance, operational and risk warning into one configurable alerting hub. Stakeholders: all. Backend: `/api/alerts` + KV.

- **Active Alerts** — unread alerts from `store.alerts` → sorted by severity (critical→high→medium→low), grouped into Critical/High/Warning/Info sections; each card lets you log a free-text action note + Resolve (moves to history with the note) or Dismiss (mark read) → triaged live alert feed. _Persist: live store (`/api/alerts`)._ _Class: Backend._
- **Resolved (History)** — read alerts from `store.alerts` → lists dismissed/resolved items at reduced opacity, shows `actionTaken` note, per-item delete → audit trail of cleared alerts. _Persist: live store (`/api/alerts`)._ _Class: Backend._
- **Safety-Buffer Configure** — `safetyThresholdDays` (slider 7–60, save validates 1–180) → buffer = (monthlyBurn/30) × days, shows ₹ buffer + severity-channel legend (critical=in-app+email+WhatsApp, warning=in-app+email, info=in-app) → persisted threshold via `updateFirm`. _Persist: live store (firm)._ _Class: Backend._
- **Smart Threshold Alert Builder** — metric (balance/burn/runway/revenue30/expense30) + condition (below/above) + value → live metric computed from store (balance=Σ bankAccounts, burn=monthlyBurn, runway=balance÷daily-burn, revenue30/expense30 from 30-day category sums); each rule evaluated live, breach shows Breached/OK + a "rules breached now" banner → user-defined metric watch. _Persist: `alert-threshold-rules`._ _Class: KV._
- **Compliance Due-Date Alerts** — obligation name + next due date + recurrence (once/monthly/quarterly/annual), plus 8 statutory presets (GSTR-3B/-1, TDS pay, PF&ESI, TDS return, advance tax, ROC AOC-4/MGT-7, ITR) → days-to-due banded (Overdue/≤3d/this-week/Upcoming/Scheduled), "Filed → next" rolls recurring date forward by cycle, urgent counter for ≤7-day items → escalating statutory deadline reminders. _Persist: `compliance-due-items`._ _Class: KV._
- **Cash-Low / Overdraft Alert** — optional minimum-balance floor (₹) → from live balances/burn computes total balance, runway, overdrawn accounts, days-to-floor; emits critical/high/medium warnings (overdrawn acct, negative aggregate, runway ≤14/≤30, below floor, days-to-floor ≤30) + per-account balance table → proactive liquidity warning. _Persist: `liquidity-min-floor`._ _Class: Backend (live store data) + KV (floor input)._
- **Fraud / Anomaly Alerts** — outlier sensitivity σ slider (1.5–4) → heuristics over non-transfer txns: outsized payments (>mean+σ·sd), new payees (counterparty first-seen ≤30d), round-trips (party with both in+out flow), manually-flagged txns; lists all findings as a review queue → anomaly review feed. _Persist: none (σ is local `useState`)._ _Class: Indicative._
- **Snooze / Mute Alerts** — alert type (from distinct live `store.alerts` types) + mute window (1h/4h/8h/1d/3d/1wk) → adds time-boxed mute rule, computes how many live unread alerts are suppressed, lists active mutes with remaining time + Unmute; auto-expires, never deletes the alert → category notification suppression. _Persist: `alr-mute-rules`._ _Class: KV._
- **Alert Digest Scheduler** — enable toggle + frequency (daily/weekly) + delivery hour (0–23) + channel (email/WhatsApp/both) → live "next digest" preview of unread alerts grouped by severity (first 6 + overflow count); Save shows scheduled/disabled toast → periodic roll-up config + preview. _Persist: `alr-digest-enabled`/`-freq`/`-hour`/`-channel`; preview from live store._ _Class: Preview (settings persist to KV; no actual scheduled send wired)._
- **Escalation Rules** — severity tier (critical/high/medium/low) + recipient (name/phone/email) + channel (WhatsApp/email/call) → per-tier recipient list with live "N active now" count per severity from `store.alerts`; tiers with no recipient fall back to in-app only → severity-based routing config. _Persist: `alr-escalation-rules`; live counts from store._ _Class: KV (routing not actually dispatched)._
- **Overdue Receivables Alerts** — optional overdue-AR ceiling (₹) → ages open `store.invoices` into buckets (current/1–30/31–60/61–90/90+), totals overdue, flags when total exceeds ceiling, lists overdue invoices sorted by days → AR aging + drift alert. _Persist: `alr-recv-threshold`; aging from live invoices._ _Class: Backend (live store) + KV (threshold)._
- **Payment-Due Alerts** — look-ahead window (days, default 14) → from `store.obligations` shows overdue + upcoming within horizon (loan/tax/payroll/other), totals due, overdue count, colour-bands each by days-to-due → upcoming-outflow pre-funding view. _Persist: `alr-payable-window`; obligations from live store._ _Class: Backend (live store) + KV (window)._
- **KPI Target Alerts** — KPI (revenue30/gross-margin%/expense-ratio%/recurring-revenue%) + goal (atLeast/atMost) + value → live KPI from rolling 30-day txns; each target shows Missing/On-track + an "off track" summary list → operating-KPI pass/miss monitor. _Persist: `alr-kpi-targets`; KPIs from live store._ _Class: Backend (live store) + KV (targets)._
- **Low-Stock Alerts** — safety multiplier slider (1–3×) on reorder level → over `store.inventory` computes trigger=reorderLevel×buffer, flags out-of-stock + low, estimates re-order cost (shortfall×unitCost); summary cards + flagged SKU table → inventory replenishment alert. _Persist: `alr-stock-buffer`; inventory from live store._ _Class: Backend (live store) + KV (multiplier)._
- **Large-Transaction Alerts** — amount threshold (₹, default 100000) + direction (out/in/either) → filters non-transfer txns ≥ threshold in direction, sorts by abs amount, caps at top 50; lists matches with +/− amounts → fixed-rupee large-movement flag. _Persist: `alr-largetxn-amount`/`-dir`; txns from live store._ _Class: Backend (live store) + KV (settings)._
- **Budget-Overrun Alerts** — warn-% slider (50–100, default 80) → compares 30-day outflow per category against `store.budgets` monthly limits, flags over-limit + approaching (≥warn%), per-budget progress bar + over-by amount → category budget overrun monitor. _Persist: `alr-budget-warn`; budgets/txns from live store._ _Class: Backend (live store) + KV (warn%)._
- **Customer Concentration Alerts** — concentration ceiling slider (10–80%, default 30) → over `store.invoices` computes each customer's share of open AR + all-time invoiced, flags any above ceiling, lists top 20 → receivables concentration-risk warning. _Persist: `alr-concentration-pct`; invoices from live store._ _Class: Backend (live store) + KV (ceiling)._
- **Priority Inbox** — severity filter (all/critical/high/medium/low) → triage queue of live unread alerts ordered by severity then recency, per-item dismiss, "Clear all <tier>" bulk mark-read → fast morning-sweep triage. _Persist: live store (`markAlertRead`)._ _Class: Backend._
- **Licence Expiry Alerts** — licence name + expiry date, plus 10 presets (trade licence, FSSAI, Shops & Est., Fire NOC, prof. tax, GST reg., ISO, insurance, domain/SSL, IEC) → days-to-expiry banded (Expired/≤15d/Renew-soon/Valid), urgent counter for ≤45-day items → fixed-expiry registration tracker. _Persist: `alr-licence-items`._ _Class: KV._
- **EMI Coverage Alerts** — coverage window (days, default 30) → sums loan-type `store.obligations` due in window, compares to live bank balance, computes balance-after-EMIs, flags shortfall; balance/EMIs-due/after cards + EMI list → instalment funding-shortfall check. _Persist: `alr-emicover-window`; balance/obligations from live store._ _Class: Backend (live store) + KV (window)._
- **Recurring-Spend Watch** — optional monthly ceiling (₹) → from recurring expense/payroll txns takes latest charge per counterparty, totals committed monthly + annualised, flags creep above ceiling; lists each recurring charge → subscription/commitment creep watch. _Persist: `alr-recurring-ceiling`; txns from live store._ _Class: Backend (live store) + KV (ceiling)._
- **Tax Set-Aside Alerts** — effective tax-rate slider (0–40%, default 25) → over last 90-day txns computes profit (revenue−expenses), provision=profit×rate, nets off tax-category paid, derives still-owed; warns if still-owed > live bank balance → tax-reserve provisioning aid. _Persist: `alr-taxsetaside-rate`; txns/balance from live store._ _Class: Indicative (rough provisioning estimate)._

## Sales & CRM (`/sales`) — 32 tools

A WhatsApp-enquiry-to-collected-cash CRM for India's SMB sales teams: lead capture, Kanban pipeline, GST-correct quoting, commissions, targets and customer analytics. Stakeholders: sales, owner. Backend: KV-synced (many tools read live invoices/transactions from the shared store).

- **Overview** — reads deals (KV) + leads (KV) + live `store.invoices` → open pipeline, weighted forecast (Σ value × `STAGE_PROB`), closed-won, overdue follow-up count, outstanding AR; quick-jump buttons + AR nudge to Customer 360 → KPI dashboard. _Persist: reads `sales-deals` + `sales-leads` + live store._ _Class: KV._
- **Pipeline Board (Kanban)** — title, customer, rep, value, source, expected-close inputs → adds Deal at `enquiry`, ‹›-moves through `enquiry→quoted→negotiation→won→lost`, columns total per stage, open pipeline + weighted forecast (value × stage probability) → 5-column board. _Persist: `sales-deals`._ _Class: KV._
- **Deal Tracker** — reads deals → flat list sorted by value desc, inline stage `<select>`, expected-close aging (days overdue if past date and not won/lost) → sortable table. _Persist: `sales-deals`._ _Class: KV._
- **Quote → Order** — buyer, GSTIN (15-char regex validated), order discount %, line items (name/qty/rate/GST slab 0/5/12/18/28) → per-line gross→after-discount→GST→total, subtotal/taxable/GST/grand totals, generates `upi://pay` collect link on accept (firm name from store) → quotation + sales-order confirmation. _Persist: none (local component state)._ _Class: Simulated (order/UPI link is in-memory, not stored or charged)._
- **Commissions** — flat-rate %, rep, deal value, margin %, scheme (flat vs tiered) → commission = flat% or tiered (4% <₹2.5L · 6% ₹2.5L–₹10L · 8% >₹10L); totals revenue closed, total commission, effective payout % → table + KPIs. _Persist: `sales-commissions`._ _Class: KV._
- **Customer 360** — select customer (derived from live invoices + incoming transactions) → lifetime value (collected + incoming txns), total billed, outstanding, overdue, per-customer invoice list with status → profile dashboard. _Persist: none (reads live store)._ _Class: Backend (live invoices + transactions)._
- **Sales Forecast** — reads deals + editable per-stage probability overrides (default 10/35/60/100/0%) → weighted = Σ value × prob, closed-won, open pipeline, per-stage bars → forecast view. _Persist: reads `sales-deals` (overrides are local state)._ _Class: KV._
- **Leads & Follow-ups** — name, phone, source, next-follow-up date, note → captures lead at `new` status, inline status select (new/contacted/qualified/dropped), overdue follow-up count, tel:/wa.me action links → lead table. _Persist: `sales-leads`._ _Class: KV._
- **Win / Loss** — deal, value, outcome (won/lost), reason (preset win/loss reason lists) → win rate = won ÷ total, won/lost counts, value won, top loss-reason tally → KPIs + table. _Persist: `sales-winloss`._ _Class: KV._
- **Target vs Actual** — rep, monthly target ₹, achieved ₹ → per-rep attainment % with colour bands (≥100 green / ≥70 yellow / else red), team target/achieved/attainment → progress bars. _Persist: `sales-targets`._ _Class: KV._
- **Rep Leaderboard** — reads deals → groups by rep, sums won value/count and open value/count (excludes lost), sorts by won value desc, medals top 3 → ranked table. _Persist: reads `sales-deals`._ _Class: KV._
- **Discount Approval** — list price, cost, discount asked %, commission %, floor margin %, approval threshold % → net price, commission, net margin ₹/%, flags below-floor (block) and needs-approval (route to owner) → margin calculator + verdicts. _Persist: none._ _Class: Indicative._
- **Territory Planner** — territory, rep, pincodes, accounts, potential ₹ → totals territories/accounts/potential, avg accounts per rep → table + KPIs. _Persist: `sales-territories`._ _Class: KV._
- **Activity Log** — contact, type (call/whatsapp/visit/email/meeting), outcome (connected/no-answer/follow-up/closed), duration, note → prepends timestamped entry; totals activities, calls, minutes, connect rate (connected+closed ÷ total) → log table. _Persist: `sales-activities`._ _Class: KV._
- **Quote Expiry** — quote ref, customer, value, valid-until (default +15d) → sorts by validity, classifies live/expiring(≤3d)/expired, live quote value, expiring-soon + expired counts → tracker with status badges. _Persist: `sales-quote-expiry`._ _Class: KV._
- **Cross-Sell** — select a product (mined from live invoice descriptions) → co-occurrence: products appearing in the same customer's basket as the selected product, ranked by count (top 8) → "also bought" suggestions. _Persist: none (reads live invoices)._ _Class: Backend (live invoices)._
- **Churn Risk** — reads live invoices per customer → risk score: inactivity (days since last due date: >90→50, >60→30, >30→15) + overdue dues (+30) + one-time-buyer (+20), capped 100, level high≥60/med≥30/low; revenue at risk = billed of med+high → ranked list. _Persist: none (reads live invoices)._ _Class: Backend (live invoices)._
- **NPS & Feedback** — customer, score 0–10, comment → NPS = %promoters(9–10) − %detractors(0–6); promoter/passive/detractor counts and per-entry bucket → KPIs + feedback table. _Persist: `sales-nps`._ _Class: KV._
- **Sales Playbook** — seeded 10-step deal checklist + custom steps → toggle done, progress %, reset-for-new-deal → onboarding/deal checklist. _Persist: `sales-playbook`._ _Class: KV._
- **Renewals** — customer, product/contract, value, renewal date (default +30d), status (active/renewed/lapsed) → sorts by date, due-≤14-days alert, active value, due-soon count, renewed value → renewal tracker. _Persist: `sales-renewals`._ _Class: KV._
- **Referrals** — referrer, new customer, deal value, reward %, status (pending/closed/paid) → reward = value × reward%, closed value, rewards due (closed) vs paid → referral table. _Persist: `sales-referrals`._ _Class: KV._
- **Source ROI** — reads deals + editable per-source monthly spend → per-source leads, won count, conversion %, won value, cost/lead, ROI (won value ÷ spend); blended ROI/spend/won totals → channel ROI table. _Persist: `sales-source-spend` (reads `sales-deals`)._ _Class: KV._
- **Rep Scorecard** — reads deals → per-rep totals, won/lost, win rate (won ÷ closed), won value, open value, avg won deal, sorted by won value → scorecard table. _Persist: reads `sales-deals`._ _Class: KV._
- **RFM Segments** — reads live invoices per customer → R (recency: ≤30d=3/≤90d=2/else 1), F (frequency: ≥5=3/≥2=2/else 1), M (monetary vs max total: ≥50%=3/≥20%=2/else 1); score→segment Champion≥8/Loyal≥6/At risk≥4/Hibernating → segmented table + tally. _Persist: none (reads live invoices)._ _Class: Backend (live invoices)._
- **Incentive Sim** — expected revenue, quota, flat rate %, base rate % (to quota), accelerator % (above) → flat cost = rev×flat; accelerator cost = belowQuota×base + aboveQuota×accel; attainment %, picks cheaper plan, cost as % of revenue → scheme comparison. _Persist: none._ _Class: Simulated._
- **Account Plan** — account, annual goal ₹, owner, objective, next step, status (active/won/stalled) → total goal value, won goal value → key-account plan cards. _Persist: `sales-account-plans`._ _Class: KV._
- **Rate Card** — SKU, list price, GST slab; editable per-row Tier-1/Tier-2 discount % (default 5/10) → Tier net = list×(1−tier%)×(1+GST%) → GST-aware price-list table. _Persist: `sales-rate-card`._ _Class: KV._
- **Pipeline Velocity** — reads deals + editable avg cycle days → velocity/day = (open deals × win rate × avg deal size) ÷ cycle days; win rate, avg deal, monthly projection (×30) → velocity dashboard. _Persist: reads `sales-deals`._ _Class: KV._
- **Conversion Funnel** — reads deals → counts deals that "reached or passed" each flow stage (enquiry→quoted→negotiation→won), % of enquiries (of top), step drop-off % per stage, lost count → funnel bars. _Persist: reads `sales-deals`._ _Class: KV._
- **Revenue / Customer** — reads live invoices per customer → invoices count, avg invoice, collected (paid), total billed, % of total revenue, sorted by billed desc → concentration-risk table. _Persist: none (reads live invoices)._ _Class: Backend (live invoices)._
- **Quote Acceptance** — reads deals → "quoted" = reached ≥quoted stage (incl. lost); acceptance = won ÷ decided (won+lost); count + value-weighted acceptance (won value ÷ quoted value), still-open count → acceptance dashboard. _Persist: reads `sales-deals`._ _Class: KV._
- **Seasonal Pattern** — reads live invoices → buckets amount + count by calendar month, peak month, average of active months, above-average highlighting → revenue-by-month bars. _Persist: none (reads live invoices)._ _Class: Backend (live invoices)._

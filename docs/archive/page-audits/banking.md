# Banking & Cash (`/banking`) — 32 tools

Give an SMB owner a single India-first console for every rupee across every bank — consolidated balances, statement reconciliation, rail/limit guidance, fee and idle-cash recovery, and India-specific banking workflows (NACH, positive-pay, BG/LC, OD/CC, cheque clearing). Stakeholders: owner, finance. Backend: KV-synced (reads `store.bankAccounts` / `store.transactions`; per-tool inputs persist via `useFeatureState`; nothing writes to the live ledger).

- **Overview** — reads `store.bankAccounts` (count, balances, status) → KPI cards (total cash, connected feeds `connected/total`, feed issues = `status==="error"`, largest balance), plus an "accounts at a glance" table with each account's balance, share `balance/totalBalance` %, status chip and last-sync; empty-state prompts linking from Data module. _Persist: live store._ _Class: KV._
- **Multi-Bank Balances** (`BalanceDashboard`) — reads accounts + adjustable concentration cap slider (10–100%, default 40) → sorts accounts largest-first, computes each share `balance/total`, flags accounts over the cap (DICGC ₹5L/bank note), KPIs (total, count, avg per account, over-concentrated count) and a warn callout to spread/sweep surplus. _Persist: live store (cap = local state)._ _Class: KV._
- **Reconciliation** (`ReconciliationWorkbench`) — account selector + pasted statement lines (`date, amount, narration`; Dr/Cr or minus = debit, parsed by `parseStatement`) + amount tolerance (₹) → greedy first-available match of statement lines vs `store.transactions` by amount within tolerance; outputs matched / on-statement-not-in-books / in-books-not-on-statement counts and lists. _Persist: live store reads; paste/tolerance = local state, no ledger write._ _Class: KV._
- **Daily Cash Position** (`DailyCashPosition`) — opening = sum of account balances; today's inflows/outflows from `store.transactions` filtered to today's date; user-added pending debits/holds (label, amount, clears-on) → available now = balance − pending holds; warn callout when holds exceed balance (returned-cheque risk). _Persist: `bank-pending-debits` (KV); balances live store._ _Class: KV._
- **Sweep Planner** (`SweepPlanner`) — account + buffer-to-retain + FD/sweep rate (% p.a., default 6.5) + current-a/c yield (% p.a., default 3) → sweepable = `max(0, balance − buffer)`, FD annual = `sweepable·fdR/100`, idle yield = `sweepable·ccR/100`, extra yield = difference; ok callout suggesting daily sweep-in/out. _Persist: live store (balance); rates = local state._ _Class: Indicative._
- **Virtual Accounts** (`VirtualAccountTracker`) — customer name + expected inflow → issues a deterministic synthetic VA number (`genVa`: hash of name+uuid → `VA` + 10 digits); tracks expected vs received per customer, "Mark received" sets received=expected; KPIs (VA count, total expected, total received). _Persist: `bank-virtual-accounts` (KV)._ _Class: Simulated (VA numbers are locally generated, not bank-issued)._
- **Bank-Fee Analyzer** (`BankFeeAnalyzer`) — scans `store.transactions` debits whose description matches `FEE_KEYWORDS` (charge/chrg/fee/neft chg/rtgs chg/imps/amc/min bal/gst on/commission/penal…) + benchmark bps input (default 15) → total fees, fees as bps of total debits, expected fees = `debits·bps/10000`, overcharge, fees-by-type bar breakdown; warn callout to negotiate with RM. _Persist: live store reads; benchmark = local state._ _Class: KV._
- **Payment Rail** (`PaymentRailChooser`) — amount + urgent checkbox → filters static `RAILS` (UPI ≤₹1L free 24x7; IMPS ≤₹5L ₹5–15+GST; NEFT no-limit batch ₹2–25+GST; RTGS ≥₹2L ₹20–50+GST) by per-txn min/max, then ranks (urgent: prefer instant by order upi>imps>rtgs>neft; else cheapest upi>neft>imps>rtgs); recommends one rail + comparison table with eligibility ticks. _Persist: none (static table + local state)._ _Class: Indicative._
- **Cheque Register** (`ChequeRegister`) — cheque no., party, amount, type (issued/received), date → adds cheque at status `issued`; click status chip cycles `issued→presented→cleared→bounced→cancelled`; KPIs (pending count, issued-pending outflow, bounced count); warn callout citing NI Act Sec 138 on bounced cheques. _Persist: `bank-cheques` (KV)._ _Class: KV._
- **Charge Recovery** (`ChargeRecoveryTracker`) — charge description, amount, raised-on date → logs dispute at `open`; per-row "Recovered"/"Rejected" buttons set status; KPIs (open count, amount-in-flight = open total, recovered total); notes RBI TAT on failed-txn reversals. _Persist: `bank-charge-disputes` (KV)._ _Class: KV._
- **Idle-Balance Alert** (`IdleBalanceAlert`) — operating buffer per account + achievable yield (% p.a., default 6.5) → per account: idle = `max(0, balance − buffer)`, days-since-activity from latest matching txn date, foregone annual = `idle·rate/100`; totals + warn callout pointing to Sweep Planner. _Persist: live store (balances/txns); buffer/yield = local state._ _Class: KV._
- **Positive Pay** (`PositivePayRegister`) — adjustable threshold (default ₹5L) + cheque no., payee, amount, date → cheques ≥ threshold flagged as needing Positive Pay; per-row Confirm toggle; KPIs (logged, need-PP, not-confirmed); warn callout citing RBI ₹50k mandate and return risk. _Persist: `bank-positive-pay` + `bank-positive-pay-threshold` (KV)._ _Class: KV._
- **NACH Mandates** (`MandateTracker`) — UMRN/ref, party, amount, frequency (monthly/quarterly/yearly), next-debit → tracks recurring auto-debits; equivalent monthly outflow = sum of active mandates × frequency factor (1, 1/3, 1/12); Pause/Resume/Cancel/Remove actions; KPIs (active, total, equiv monthly outflow). _Persist: `bank-nach-mandates` (KV)._ _Class: KV._
- **BG / LC Limits** (`GuaranteeLimitTracker`) — adjustable sanctioned non-fund limit (default ₹50L) + facility type (BG/LC), beneficiary, amount, expiry → utilised = sum of facilities, available = `max(0, limit − utilised)`, utilisation %, per-row days-to-expiry (red <0, amber ≤30); warn callouts at >90% utilisation and for facilities expiring within 30 days. _Persist: `bank-bg-lc` + `bank-bg-lc-limit` (KV)._ _Class: KV._
- **OD/CC Interest** (`OdInterestCalculator`) — sanctioned limit, amount drawn, rate (% p.a.), days drawn → utilisation = `drawn/limit`, daily interest = `drawn·rate/100/365`, period/monthly(30d)/annual interest, headroom = `limit − drawn`; warn callout at >90% utilisation re penal interest. _Persist: none (local state)._ _Class: Indicative._
- **Statement Import** (`StatementImporter`) — pasted statement lines (`parseStatement`) auto-categorized via `IMPORT_RULES` (salary/tax/bank-charge/transfer/vendor; else income if credit, otherwise other) → by-category count+total breakdown, total credits/debits, parsed line table; explicitly does not write to the ledger. _Persist: none (local paste)._ _Class: KV._
- **Beneficiaries** (`BeneficiaryWhitelist`) — name, account number, optional IFSC (validated `^[A-Z]{4}0[A-Z0-9]{6}$`) → dedupes by account, stores unverified; manual "Mark verified/unverified" toggle (penny-drop name-check by user); KPIs (whitelisted, verified, awaiting); warn callout to verify before paying. _Persist: `bank-beneficiaries` (KV)._ _Class: KV (verification is manual, not a real penny-drop)._
- **Transfer Planner** (`FundTransferPlanner`) — target balance per account → computes surplus (`balance − target` >0) and deficit accounts, greedily generates minimum top-up moves from largest-surplus to largest-deficit; KPIs (below target, surplus, transfers) + suggested-moves list; ok callout if all met / no surplus. Requires ≥2 accounts. _Persist: live store (balances); target = local state._ _Class: KV._
- **Min-Balance Check** (`MinBalanceChecker`) — adjustable penalty per ₹1,000 shortfall (default 60) + per account: name (datalist of accounts), required AMB, maintained AMB → shortfall = `max(0, required − maintained)`, penalty = `(shortfall/1000)·penaltyPer1000`; KPIs (breaching count, est. penalty/month); warn callout to top up / switch to ZBA / close redundant accounts. _Persist: `bank-mab` + `bank-mab-penalty` (KV); maintained AMB entered manually._ _Class: Indicative._
- **Savings Interest** (`SavingsInterestEstimator`) — average balance + savings rate (% p.a., default 3) + months → quarterly-compounded maturity = `p·(1+r/400)^(months/3)`, interest, effective annualized yield, indicative TDS (10% u/s 194A if interest >₹40k); ok callout comparing to liquid fund/sweep FD. _Persist: none (local state)._ _Class: Indicative._
- **Payment Date** (`PaymentDatePicker`) — intended date + extra holiday dates (against `BANK_HOLIDAYS_2026` set + Sundays + 2nd/4th Saturdays) → rolls forward up to 40 days to next working day, listing each skipped day with reason; KPIs (effective working date, days skipped); ok callout if already a working day. _Persist: none (static holiday list + local state)._ _Class: Indicative._
- **Balance Confirmation** (`BalanceConfirmationGenerator`) — account + entity/holder name + as-on date → drafts a bank balance-confirmation request letter (for statutory audit) with provider, account name and book balance pre-filled; Copy-to-clipboard button. _Persist: live store (account/balance); entity/date = local state._ _Class: KV._
- **Forex Spread** (`ForexSpreadTracker`) — per deal: currency, foreign amount, INR received, reference rate, date → bank rate = `inrReceived/foreign`, spread (paise/unit and %), cost vs reference = `(refRate − bankRate)·foreign`; KPIs (count, total spread cost, avg spread %); note that >~0.5–1% spread is high. _Persist: `bank-fx-deals` (KV)._ _Class: KV._
- **Duplicate Payments** (`DuplicatePaymentDetector`) — adjustable match window (1–30 days, default 7) → groups `store.transactions` debits by `roundedAmount|counterparty`, flags groups with ≥2 txns where consecutive dates fall within the window; potential over-payment = `amount·(count−1)` summed; per-group txn lists; note re legitimate repeats. _Persist: live store reads; window = local state._ _Class: KV._
- **Counterparty Netting** (`CounterpartyNetting`) — per party: receivable (they owe) + payable (you owe) → net = `receivable − payable`, gross-to-settle = sum of both legs, net-to-settle = sum of `|net|`, cash movement saved = gross − net; per-row action (collect/pay/square-off net); ok callout on savings. _Persist: `bank-netting-parties` (KV)._ _Class: KV._
- **Interest Certificates** (`InterestCertificateTracker`) — per cert: bank, type (fd/savings/loan/od), FY, amount → splits into taxable interest income (fd+savings) and deductible interest paid (loan+od); per-row Received/Pending toggle; KPIs (pending count, income, paid); warn callout to collect before filing. _Persist: `bank-interest-certs` (KV)._ _Class: KV._
- **A/C Opening Docs** (`AccountOpeningChecklist`) — entity type (proprietorship/partnership/company) selects a static RBI-KYC `ENTITY_DOCS` list → checkbox progress per `entityType:key`, completed count and % bar; ok callout at 100%. _Persist: `bank-acopen-checklist` (KV)._ _Class: Preview (static checklist)._
- **Cash Runway** (`CashRunwayMeter`) — cash = sum of balances + adjustable window (1–12 months, default 3) → from `store.transactions` in window: net burn = `(outflow − inflow)/months`, gross burn = `outflow/months`, runway months = `cash/netBurn` (∞ if cash-positive), runway days; tiered ok/warn callout (<3 mo = tight). _Persist: live store; window = local state._ _Class: KV._
- **Deposit Slip** (`CashDepositSlip`) — account + depositor + date + note counts per `DENOMS` (500/200/100/50/20/10) → per-denom value = `denom·count`, total notes and total amount; Copy-slip builds a text pay-in slip to clipboard. _Persist: live store (account); counts = local state._ _Class: KV._
- **Clearing Tracker** (`ClearingTracker`) — instrument (local-cheque CTS T+1 / outstation ~T+3 / NEFT-inward same-day / cash@CDM same-day), ref, amount, deposit date → expected credit via `addWorkingDays` (skips Sat/Sun) per `CLEAR_TAT`; cleared if past; KPIs (still clearing, funds in float = uncleared total, cleared); per-row "Nd to go"/"Clears today"/"Cleared"; note holidays ignored. _Persist: `bank-clearing-tat` (KV)._ _Class: Indicative._
- **OD Renewal** (`OdRenewalReminder`) — per facility: bank, type (cc/od), sanctioned limit, renewal date + adjustable lead-time slider (15–90 days, default 45) → days-to-renewal, due if `days≤leadDays`, overdue if `days<0`; KPIs (facilities, total limit, due-within-window); warn callout to collate financials/stock statements 3–6 weeks ahead. _Persist: `bank-od-renewals` (KV); leadDays = local state._ _Class: KV._
- **Spend by Bank** (`SpendByBank`) — groups all `store.transactions` by resolved account name (or "Unassigned") → per bank: debit/credit/count/net; KPIs (total outflow, accounts with activity, busiest account), outflow-distribution bars (`debit/totalDebit`) and a full per-bank table. _Persist: live store reads only._ _Class: KV._

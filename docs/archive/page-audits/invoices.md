## Invoicing & Order-to-Cash (`/invoices`) — 32 tools

GST-compliant invoicing, UPI/WhatsApp collections, and a deep order-to-cash toolbox (quotes, credit control, GST/TDS/TCS computation, e-invoice JSON, AR ageing). Stakeholders: owner, finance, sales. Backend: `/api/invoices` + KV.

Core invoice register (backend-persisted) and global actions:

- **New Invoice** (`NewInvoiceModal`) — customer name/GSTIN/email/WhatsApp, header GST rate (0/5/12/18/28), due date, line items (description, HSN/SAC, qty, unit price, per-line GST) → `POST /api/invoices`; modal preview totals invoice-level (subtotal × header rate), backend recomputes per-line → new invoice with `invoice_number`, `irn`, totals; mirrored into shared store as AR. _Persist: Backend (`/api/invoices`)._ _Class: Backend._
- **Invoice list + row actions** — live `GET /api/invoices` table (number, customer, amount +GST%, due/aging, status badge) with: **Download PDF** (`GET /api/invoices/:id/pdf`, blob), **Send by email** (`POST /api/invoices/:id/send`, draft/sent only with email), **UPI/card link** (opens `UpiQrModal`), **WhatsApp remind** (`POST /api/invoices/:id/remind`, only when aging≠current), **Mark paid** (`PATCH /api/invoices/:id {status}`). Header KPIs: Pending / Overdue / Paid(all-time) sums. _Persist: Backend._ _Class: Backend._
- **UPI QR** (`UpiQrModal`) — invoice id → `POST /api/invoices/:id/upi-link` → server-built UPI deep link + QR image (BIP-21 `upi://pay`, amount = invoice total). _Persist: Backend (generated, not stored)._ _Class: Backend._
- **Auto-Collect** (`collection` tab, `CollectionAutoPanel`) — filters live invoices to overdue (aging≠current, not paid/cancelled) → per-row & "Remind All" call `POST /api/invoices/:id/remind` (WhatsApp + one-tap UPI link); "Sent" state is in-memory only → overdue count badge + total, auto-marks paid on collection via webhook. _Persist: Backend (reminders); session set (sent flags)._ _Class: Backend._

Billing-tools selector (each `useFeatureState` KV unless noted; computations are client-side):

- **Quotation** (`quote`) — customer, valid-until, line items → `computeDoc` per-line GST → numbered `QT-YYYY-NNN`; Convert flips status to "converted" (no auto-invoice, manual re-entry). Note: no GST liability until converted. _Persist: KV `invoice-quotations`._ _Class: KV._
- **Proforma** (`proforma`) — customer, advance %, items → per-line totals + advance payable = total × advance%; numbered `PI-YYYY-NNN`; "Mark converted" flag. Not a tax invoice (no buyer ITC until final invoice). _Persist: KV `invoice-proformas`._ _Class: KV._
- **Recurring / Subscription Billing** (`recurring`) — customer, amount, GST, freq (monthly/quarterly/yearly), next-run → est. MRR (monthly=full, quarterly÷3, yearly÷12, incl GST), due-to-generate count; "Generate now" advances next-run by freq and increments counter (no real invoice posted), pause/resume/delete. _Persist: KV `invoice-recurring`._ _Class: Indicative (cycle simulated; not wired to cron)._
- **Pay Links** (`paylink`, `PaymentLinkBuilder`) — VPA (defaults from `store.firm.upiVpa`), payee name, pick live unpaid invoice or manual amount → client-side `buildUpiLink` (`upi://pay?pa&pn&am&cu=INR&tn`) + hosted card URL `pay.headroom.app/c?…`; copy/open. No funds touch Headroom; mark-paid manual. _Persist: none (links built client-side)._ _Class: Indicative._
- **Credit/Debit Note** (`creditnote`, `CreditDebitNoteManager`) — type credit/debit, against-invoice (prefills customer/GST), taxable, GST → gstAmt = round(taxable×rate%), total; numbered `CN/DN-YYYY-NNN`; net-credit/net-debit summary. Note: credit notes reportable in GSTR-1 by 30 Nov post-FY to reverse output tax; debit notes raise liability in issue month. _Persist: KV `invoice-cdnotes`._ _Class: KV._
- **Credit Limit** (`creditlimit`, `CreditLimitManager`) — customer, limit, hold-if-overdue-days → exposure (outstanding + overdue) computed live from unpaid invoices; utilisation% bar; ON HOLD when outstanding>limit or any past-due. _Persist: KV `invoice-credit-limits` (exposure from live backend)._ _Class: KV._
- **Multi-Currency** (`multicurrency`, `MultiCurrencyInvoicing`) — overseas customer, currency (USD/EUR/GBP/AED/SGD/AUD), FCY amount, ₹/unit invoice rate → INR value; numbered `EXP-YYYY-NNN`; enter realisation rate to book FX gain/loss = FCY×(realRate−invRate); net G/(L) summary. Exports under LUT zero-rated (0% IGST). _Persist: KV `invoice-fx`._ _Class: KV._
- **Approval** (`approval`, `ApprovalWorkflow`) — threshold (₹, default 100000); live invoices ≥ threshold listed → "Route for approval" creates pending maker-checker request; checker approve/reject. _Persist: KV `invoice-approval-threshold`, `invoice-approvals`._ _Class: KV._
- **Template Studio** (`template`, `TemplateStudio`) — logo text, primary/accent colours, font, terms, footer → live white invoice preview; reset to default. Claims applied to future PDFs/shares. _Persist: KV `invoice-template-theme`._ _Class: Preview (PDF application not verified here)._
- **Delivery Challan** (`challan`, `DeliveryChallan`) — consignee, purpose (Rule 55: approval/job-work/branch transfer/exhibition/other), vehicle, items → goods value via `computeDoc`; numbered `DC-YYYY-NNN`; "To invoice" sets flag (manual tax-invoice raise). _Persist: KV `invoice-challans`._ _Class: KV._
- **Late-Fee/Interest** (`latefee`, `LateFeeApplier`) — annual rate% (default 18), flat fee, grace days → for live past-due invoices: simple interest = principal × rate% × max(0, daysLate−grace)/365, fee if days>0, payable = principal+interest+fee; "Apply" stores charge (re-invoice manually). _Persist: KV `invoice-late-interest-rate`, `-flat-fee`, `-grace-days`, `-applied`._ _Class: Indicative (computed live; charge not posted to backend)._
- **Ageing Buckets** (`ageing`, `AgeingBuckets`) — live unpaid invoices bucketed by days-past-due: Not due / 1–30 / 31–60 / 61–90 / 90+ → per-customer matrix, bucket totals, total outstanding, overdue total, % overdue. _Persist: none (read-only from backend)._ _Class: Backend (derived)._
- **Bulk (CSV)** (`bulk`, `BulkInvoiceGenerator`) — paste/upload CSV `customer,gstin,description,qty,rate,gst,due_date` → validates (customer/description present, qty>0, rate>0, GST∈0/5/12/18/28), one `POST /api/invoices` per valid row → created count; invalid rows skipped. _Persist: Backend (posts real invoices)._ _Class: Backend._
- **PO Matcher** (`pomatch`, `PoMatcher`) — PO number, PO amount, match-invoice (prefills customer), tolerance% (default 2) → variance = invoice total − PO; status matched / over-billed / under-billed / unmatched within tolerance band. _Persist: KV `invoice-po-match`._ _Class: KV._
- **TDS & Round-off** (`tds`, `TdsRoundOffHelper`) — taxable, GST, TDS section (194C 1%/2%, 194J 10%/2%, 194H 5%, 194I 2%, 194Q 0.1%), "TDS on GST-inclusive" toggle (CBDT Circular 23/2017 — only if GST not shown separately) → round-off = round(total)−total, TDS = round(base × secRate%) on taxable (or rounded total), net payable = rounded − TDS. Full GST still paid to govt; buyer deposits TDS vs PAN (26AS). _Persist: none._ _Class: Indicative (calculator)._
- **Dispute Tracker** (`dispute`, `DisputeTracker`) — pick disputed invoice (prefills customer/amount), reason (price/short-supply/quality/duplicate/tax error/not received/other) → log with status open→in-review→resolved/written-off; open count + value-in-dispute KPIs. _Persist: KV `invoice-disputes`._ _Class: KV._
- **Payment Terms** (`terms`, `PaymentTermsLibrary`) — seeded Net 15/30, 2/10 Net 30, Due-on-receipt; add name, net days, early-pay days/disc%, late rate% → "Due if today" = today+netDays; set default (pre-fills new-invoice due date). _Persist: KV `invoice-payment-terms` (seeded)._ _Class: KV._
- **Milestone Billing** (`milestone`, `MilestoneBilling`) — customer, contract value, GST, milestone stages (name + %, must total 100) → per-stage base = contract×% and +GST; "Bill now" flags stage billed (manual tax invoice). GST due per stage at earlier of invoice/payment. _Persist: KV `invoice-milestones`._ _Class: KV._
- **Advance/Retainer** (`advance`, `AdvanceAdjustment`) — customer (datalist from live invoices), advance received → Receipt Voucher (GST on advance for services); adjust against invoice with remaining-balance guard; received/adjusted/unadjusted-liability KPIs. _Persist: KV `invoice-advances`._ _Class: KV._
- **e-Invoice JSON** (`einvoicejson`, `EInvoiceJsonGenerator`) — your GSTIN + state code, pick live invoice → builds NIC IRP schema 1.1 payload (TranDtls/DocDtls/SellerDtls/BuyerDtls/ItemList/ValDtls); intra-state (buyer state==seller) → CGST+SGST split, inter-state → IGST; PIN/place are placeholders; copy/download .json. e-invoicing mandatory AATO > ₹5 crore. _Persist: KV `invoice-irp-supplier-gstin`, `-state`._ _Class: Backend (data) + Preview (offline upload payload)._
- **Statement of A/c** (`statement`, `StatementOfAccount`) — select customer → running ledger (debit=invoice, credit=paid, balance) from live invoices; billed/received/outstanding KPIs + closing balance. _Persist: none (read-only from backend)._ _Class: Backend (derived)._
- **Partial Payments** (`partial`, `PartialPaymentTracker`) — pick live open invoice, amount (≤ outstanding+0.5 guard), mode (UPI/NEFT-RTGS/Cheque/Cash/Card) → records installment vs GST-inclusive total; per-invoice paid/outstanding/%-paid bars + payment log. _Persist: KV `invoice-partial-payments` (against live invoices)._ _Class: KV._
- **Invoice Margin** (`profit`, `InvoiceMarginAnalyzer`) — enter cost per live invoice → margin = taxable value (subtotal, GST-excluded pass-through) − cost; per-invoice margin% + blended margin% across costed invoices. _Persist: KV `invoice-line-costs`._ _Class: KV._
- **TCS u/s 206C** (`tcs`, `TcsCalculator`) — section (206C(1H) goods >₹50L cumulative, scrap, timber, 206C(1F) motor vehicle >₹10L), sale/receipt, prior receipts (1H only), has-PAN toggle → 1H taxes only receipts beyond ₹50L cumulative, 1F only if sale>₹10L; rate = PAN rate or higher 206CC no-PAN rate; TCS = round(taxable×rate%) collected over and above sale, total to invoice = sale+TCS. _Persist: none._ _Class: Indicative (calculator)._
- **GSTR-1 Summary** (`gstr1`, `Gstr1Summary`) — live invoices auto-classified: B2B (buyer has GSTIN), B2CL (no GSTIN & total >₹2.5L), B2CS (≤₹2.5L) → table-wise count/taxable/tax (GSTR-1 tables 4/5/7) + rate-wise breakup; Export CSV. Place-of-supply/HSN need manual review. _Persist: none (read-only) + CSV export._ _Class: Backend (derived)._
- **Smart Due-Date** (`duedate`, `DueDateSuggester`) — select customer, default days (default 30) → avg days-to-pay from settled invoices (paid_at − created_at); suggested due date = today + (avgDays or fallback). _Persist: KV `inv-duedate-default` (history from backend)._ _Class: Backend (derived)._
- **Duplicate Check** (`duplicate`, `DuplicateDetector`) — match window days (default 14) → groups live invoices by customer (lowercased) + identical rounded GST-inclusive total where consecutive gap ≤ window → flags suspected double-billing. Heuristic; verify before cancelling within IRN window. _Persist: KV `inv-duplicate-window` (data from backend)._ _Class: Backend (derived)._
- **Discount + GST** (`discount`, `DiscountTaxCalculator`) — line items, discount type (% or flat ₹, capped at gross) → discount spread proportionally per line (factor = (gross−disc)/gross), GST charged per-line on post-discount value (Sec 15 CGST Act), total rounded to nearest rupee with round-off ledger entry. Pre-supply discounts only; post-supply needs credit note. _Persist: none._ _Class: Indicative (calculator)._

_Note: tab tokens `all` / `pending` / `paid` are pure UI-state filters over the same backend list and are excluded from the tool count._
